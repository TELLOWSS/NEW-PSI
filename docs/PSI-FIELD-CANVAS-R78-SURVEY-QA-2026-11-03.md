# NEW-PSI 78차 — 설문 인텔리전스 UI/UX 검증 및 통합 릴리스 게이트
작성: 2026-11-03 · 후보: Draft PR #212, 70~78차 통합 · 기준: 운영 main `2eb76a33`

## 1. 현행 기능 분석
`SurveyIntelligence.tsx`는 근로자의 Q1~Q5 자필 기록과 공종별 관리자 기준을 구분해 인식 격차·빈발 위험어·실천 약속 구체성을 보여준다. 기준 표본 수가 부족하면 결론을 보류한다. 이 화면은 70~77차 공통 디자인 CSS가 선언돼 있으나 실제 PC/모바일 탐색·필터·다크모드의 브라우저 실기능 검증에서 제외돼 있었다.

## 2. 78차 구현
- 위험성평가 설문 필터(공종/기간)의 명시적 접근성 이름 추가. 기본값/변경/초기화 코드는 변경하지 않는다.
- 첫 화면 헤더/공종·기간 필터/3개 KPI 카드에 `data-psi-survey` 스코프를 부여하고 Field Canvas 스타일 적용. 위험 상태를 뜻하는 기존 rose/amber/emerald 의미색은 보존한다.
- 320·390px 모바일: 필터 2열 + 초기화 버튼 한 줄, 3개 KPI 세로 흐름 및 가로 넘침 억제. 768·1440px: 3개 지표 나란히 배치.
- 버튼 최소 44px, 키보드 초점/다크모드 대비/요약 텍스트 읽기 순서 개선.

## 3. 수용 검증
1. 기존 전체 제품·타입·단위 테스트 및 R70~77차 브라우저 회귀시험 PASS.
2. Chromium 실제 사용자 경로: PC는 사이드바, 모바일은 '더보기 → 근로자 의견 분석' 선택. 페이지 제목과 필터 공종·기간의 접근성 이름, 첫 화면 지표 3개, 필터 변경 후 초기화 반환 검사.
3. 320/390/768/1440px에서 화면 가로 넘침 0, 버튼 실제 높이 44px 이상, CSS 지표 레이아웃 1열/3열 정확성 검사.
4. 390px 다크모드 재접속·스크린샷, 원본 데이터 불변, 표본 부족/위험 없음 단정 금지.
5. QA 실패하면 원인 수정·재검증 전 병합/배포 금지. 브라우저 합성 QA와 실기기 Android/Samsung Internet 점검은 구분.

## 4. 안전·출하 경계
- 원본 위험성평가 기록, 관리자 기준치, 조치율 계산, Q1~Q5 의미, 분석 데이터 및 공식 위험등급 불변.
- 외부 AI/유료 API 호출 추가 없음. SMART TBM은 별도 제품.
- Vercel Hobby 사용량을 고려해 70~78차 기능을 1회 main 병합/Production 배포로 묶는다. 배포 전 팀/프로젝트/커밋/모든 품질검증 재확인, 후에는 공식 주소 커밋 일치 확인.
- 실기기 촬영·네트워크 오프라인·PDF 인쇄 품질·현장 근로자 교육 효과는 합성 QA만으로 검증되었다고 하지 않는다.
