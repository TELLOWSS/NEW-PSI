# NEW-PSI 증빙 추적·제출 관리 프로토콜 (2026-11-01)

## 범위
근로자 위험성평가 자필 원본, OCR 판독 원문과 번역, 관리자 교육·현장 조치·실천·재점검 및 수정 이력을 구분하여 검토하기 위한 기능이다. SMART TBM과 별도 사진점검 프로그램을 변경하지 않는다.

## 증빙 구분
- 자필 이미지: 내보낼 때 기록에 연결된 사진이며, 촬영 원본·실제 작성 시각·그 시각의 존재를 따로 확인한다.
- OCR 판독과 번역: 내보내기 당시 저장값이다. 자필 원본과 별도 대조하고, 수정 전 버전을 임의로 재구성하지 않는다.
- 교육 이력: 교육일지와 참석·이해 확인으로 보강한다. 교육 사실만으로 실제 착용을 인정하지 않는다.
- 현장 조치 이력: 담당자·임시통제·조치기한·완료 확인·증빙을 구분한다. 완료 입력은 작업재개 허가가 아니다.
- 실천 관찰: 특정 시점의 기록으로만 간주하며, 확인 불가를 안전 실천 완료로 평가하지 않는다.
- 저장된 이벤트 시각: 사용자/기기 입력값이므로 실제 발생시각·서버 수신시각의 독립 인증이 아니다.

## 관리 절차
1. 실제 자필 원본 및 관련 근거를 확인하고, 없는 자료를 임의로 보완하지 않는다.
2. OCR·한국어 번역·관리자 수정 이유·확인자·조치 기록을 구분해 검토한다.
3. 사고시각 이전 필터를 적용할 때는 이벤트 시각별 목록을 선별할 뿐, 현존 이미지·번역이 그 시점에 존재했다고 단정하지 않는다.
4. 기록 상세 화면에서 관리자가 직접 ZIP을 생성해 내려받는다. 자동 외부 공유/근로자 MMS 전송은 하지 않는다.
5. 출력 ZIP의 전체 SHA-256을 별도 접근권한 있는 관리대장에 기록하고, 최초 보관 시점과 작성자를 별도 관리한다.
6. 제출 전 ZIP 내부 해시 목록과 별도 보관 SHA-256을 함께 대조하고, 실제 제출 자료의 개인정보 최소화·근거 연결을 확인한다.
7. ZIP 생성 이후 관리 절차에 따라 접근권한·보관기간·파기 및 감사기록을 관리한다.

## 패키지
record/snapshot.json: 내보내기 당시 문항별 원문·번역·조치·검수 상태.
record/timeline.txt: 기록된 이벤트 시각순 추적표.
assets/: 저장된 자필 이미지와 조치 사진.
manifest.json 및 SHA256SUMS.txt: 각 파일별 해시와 크기.
전체 ZIP SHA-256: 파일 밖에서 별도로 보관해야 독립 대조가 가능하다.

## 법적·기술적 한계
이 버전은 브라우저/기존 운영 저장소에서 수정 가능한 기록을 내보낸다. WORM 불변 저장, 공인타임스탬프, 전자서명, 독립 서버 수신시각 인증, 법적 증거능력 보장을 구현한 것이 아니다. 패키지 내부 파일과 해시가 모두 조작되면 내부 검사만으로는 발견하기 어렵다.

## 후속 고도화(미구현)
서버 수신시각을 분리한 append-only 저장, 업로드 최초 파일 해시·버전 관리, 독립 보관/감사 로그, 역할 기반 권한, 제출 목록 결재, 보존 정책 및 현장 법무 검토.
