# 기업별 교육 초안 (2026-09-30)

기업 계정 확인 화면에서 기업을 선택한 뒤 교육 초안의 제목, 현장명, 한국어 원문을 등록·조회·수정할 수 있습니다. owner/admin/reviewer는 편집하고 viewer는 조회합니다. 목록과 이력은 버튼으로 요청하며 기업 변경 또는 로그아웃 시 메모리 상태를 폐기합니다.

## 보안과 데이터 범위

- `/api/saas/access?resource=training-drafts`로 기존 서버리스 함수 안에서 처리합니다. 전체 함수는 4개를 유지합니다.
- 검증한 사용자 토큰과 활성 기업 소속을 사용하며 서비스 키 대체 경로는 없습니다.
- 새 `psi_tenant_training_drafts`와 `psi_tenant_training_draft_events`에만 저장합니다. 기존 교육/근로자 자료의 자동 배정은 없습니다.
- 두 테이블에 FORCE RLS, 기업별 복합 키, 역할별 컬럼 권한을 적용했습니다. 수정 이력은 당시 원문 전체를 트리거로 같은 트랜잭션에 보관합니다. 직접 수정·삭제 권한은 없습니다.
- 수정 버전 조건으로 동시 변경을 보호하고, 등록 요청 UUID로 재시도 중복 등록을 차단합니다. 조회는 25건씩, 이력은 최근 100건까지 제공합니다.
- 초안의 공개 배포, 번역, 음성 생성, 교육 이수·근로자 서명은 이번 범위에 포함되지 않습니다. 기업별 근로자 연결과 배포 권한을 검증한 뒤 별도 구현해야 합니다.

## 마이그레이션

`supabase/migrations/20260930010000_tenant_training_drafts.sql`은 기존 tenant identity foundation 이후 한 번 적용하는 추가 스키마입니다. 테이블 이름이 이미 존재하면 중단하여 기존 구조를 덮어쓰지 않습니다. 고객 자료를 삭제하거나 이관하지 않습니다.

## 검증

실제 PostgreSQL 엔진(PGlite)에서 두 기업의 양방향 격리, 조회자·익명 차단, 검토자·관리자 편집, 소속 중지, 변경 버전 충돌, 이력 위조 차단, 복합 키, 등록 중복 및 이력 실패 시 원문 롤백을 확인합니다. API 경계 테스트와 초기 화면 역할 검증도 포함합니다.

실제 기업 계정과 테스트 근로자 자료가 아직 없어 운영 환경의 사용자 로그인부터 교육 초안 저장, 근로자 교육·서명까지 이어지는 실사용 검증은 완료하지 않았습니다. shared-saas 출시 게이트와 기존 교육 경로의 안전 차단은 유지합니다.

## 후속 대상자 연결

기업별 신규 근로자 명단과 초안의 지정 대상자 연결을 추가했습니다. 대상자는 고유 ID로 최대 200명을 보관하며 다른 기업·이용 중지·중복 지정은 DB에서 차단합니다. 대상자 변경은 원문과 함께 버전 이력으로 남깁니다. 공개 배포·근로자 서명은 활성화하지 않았습니다. 상세 사용법과 현재 검증은 [기업별 근로자·대상자 관리](TENANT_TRAINING_AUDIENCE.md)를 참조하세요.
