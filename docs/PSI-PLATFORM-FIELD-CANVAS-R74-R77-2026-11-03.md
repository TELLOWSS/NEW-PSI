# NEW-PSI FIELD CANVAS — 74~77차 운영 화면 통합 디자인 적용·검증서
작성일 2026-11-03 · 대상 PR #212 · 상태: 개발 후보 / Vercel 배포 보류

## 1. 작업 근거와 현행 구조
GitHub `main` 69차와 PR #212 70~73차를 기준으로 검토했다. 70~73차에서 공통 Shell과 기본 대시보드에 도입한 네이비·청록·오프화이트 토큰이 교육·OCR·설문·리포트 개별 화면에서는 기존 하드코딩된 파랑/보라·다중 그림자·큰 반경과 경쟁하고 있었다. 특히 교육 환류의 상태카드, OCR의 3갈래 시작 동선, 월간 보고서 제작 전 안내, A4 스튜디오 단계 이동에서 정보 위계를 통일할 필요가 있었다.

## 2. R74 교육 환류
- 교육 환류 메인 히어로: 검토 완료/검토 필요/언어 수를 수치 임의변경 없이 표시. 모바일에서는 숫자 카드 세 개를 압축 배치.
- `촬영 → 관리자 검증 → 교육 환류` 흐름 강조. `교육 전파`와 `현장 조치 완료`의 의미는 절대 혼동하지 않는다.
- 원페이지·개인 보호 리포트·운영주기 추적은 기존 실제 라우트와 상태값을 유지. CTA 크기 최소 44px 및 키보드 포커스 강조.

## 3. R75 위험성평가 원문/OCR
- 사용자에게 3갈래 시작 화면(신규 문서/백업/기존 기록)을 보여주되 실제 행동 전 외부 유료 AI를 호출하지 않는다.
- 첫 번째 경로만 브랜드 주 행동으로 표시하고, 나머지는 중립 카드. 숫자·백업 여부와 원문 확인 안내를 보존.
- 유료 OCR 별도 승인, 50MiB 미만 JSON, 분석 중 검토, 기록 수정 로직 불변.

## 4. R76 설문 위험성평가 분석
- 근로자 자기기입 Q1–Q5 인지 분석의 기존 3가지 지표·표본 부족 안내·관리자 기준 위험도 저장 규칙은 보존.
- 필터·헤더·차트 카드의 라운드, 대비, 화면 폭만 공통 규칙으로 정비. 차트 색깔은 수치/위험 상태를 뜻하므로 억지로 브랜드색 통일하지 않음.

## 5. R77 리포트·월간 계도·A4 출력자료
- 리포트 관리의 대상/진행률/최근 검증/보호 우선 수치 변경 없음. 시각적 레이아웃과 버튼 터치 면적 개선.
- 월간 계도는 승인 전 초안 표기 유지. 실제 보고서 `.guidance-print`에는 디자인 스타일을 적용하지 않고, `no-print` 상단 작업실만 통일.
- A4 스튜디오는 5단계(자료 모으기/AI 초안/5단계 검수/편집/출력확인) 메뉴와 상단 설명 패널만 재디자인. A4 PDF/원본/번역 및 미리보기 생성 규칙은 변경하지 않음.

## 6. 검증 및 수용기준
1. Vitest 정적 계약에서 권한·교육·OCR·보고서 위험 경계 확인.
2. GitHub 통합 QA: PC 1440/태블릿 768/모바일 390·320px(Chromium)에서 화면 표시, 대시보드→교육→보호 리포트, 교육→월간·A4, 대시보드→OCR→백업 이어하기 동작 검증.
3. 모든 주요 화면의 첫 카드가 뷰포트 내 맞고, 버튼은 최소 44px. 다크모드/키보드 포커스/축소된 모션 지원.
4. AI API 새 호출·외부 신규 이미지/폰트 다운로드·기존 DB 변경·승인 자동처리 없음.
5. 실제 인쇄 결과와 실제 Android/Samsung Internet 카메라·백업·오프라인 동작은 별도 현장 검증 대상으로 명시.
