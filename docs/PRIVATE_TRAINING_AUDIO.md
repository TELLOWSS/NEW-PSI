# 교육 자료 인증 및 음성 서명 주소

2026-09-30. 기존 gateway에 `training.material` POST 동작을 추가했다. 서명된 교육 링크와 세션·근로자에 연결된 본인 확인 토큰을 모두 확인한 뒤 서버 전용 클라이언트가 교육 자료를 읽는다. 인증 실패는 DB 조회 전에 차단하며 shared-saas 모드에서는 기업별 교육 연결이 완료되지 않아 503으로 차단한다. 이 변경이 기존 교육의 기업별 격리를 완료한 것은 아니다.

음성은 요청의 파일 주소를 사용하지 않는다. DB에 기록된 동일 프로젝트 `training_audio` 버킷 및 동일 세션 디렉터리의 파일만 일괄 서명한다. 외부 프로젝트, 다른 세션, 다른 버킷, 인코딩된 경로 탈출, 지원하지 않는 언어는 제외한다. 주소 유효기간은 최대 5분이며 교육 링크와 근로자 인증 만료를 넘지 않는다. DB 조회 후 만료 여부를 다시 확인한다. draft 또는 검수 미완료 자료는 발급을 차단한다. 검수 메타데이터가 없는 기존 교육은 호환성을 유지한다.

근로자 화면의 직접 training_sessions 조회를 제거했다. 실제 교육은 화면 표시 형태와 무관하게 본인 확인을 요구하며, 인증 제출이나 자료 불러오기 버튼으로만 자료를 요청한다. 음성 주소가 만료되면 재생 버튼을 눌렀을 때 다시 발급한다. 새로운 자동 polling은 없다. 관리자 세션 목록과 음성 업로드 응답도 공개 주소 대신 서명 주소를 반환한다. 관리자 목록을 오래 열어둔 경우 다시 목록을 불러와 주소를 갱신할 수 있다. 네 가지 서버리스 진입점은 유지한다.

## 적용 범위와 남은 전환

이번 변경은 접근 경로 준비 단계다. 기존 DB의 공개 URL 문자열은 파일 위치 식별자로 유지하며, training_audio 버킷 공개 설정과 기존 DB 권한은 변경하지 않는다. **기존 공개 음성 주소 자체의 접근은 아직 차단되지 않았다.** 기존 자료를 모두 변환하거나 삭제하지 않는다.

실제 등록 근로자의 본인 확인·자료 조회·언어 변경·5분 후 사용자 재생 갱신·서명 제출과 관리자 업로드·목록 복원을 검증해야 한다. 테스트용 기업 계정과 소속, 교육 링크가 아직 제공되지 않아 이 실제 흐름은 미검증이다. 확인 후 training_sessions의 브라우저 직접 권한을 축소하고 버킷을 비공개로 전환한다. 기업별 세션 소속과 근로자 토큰 연결 전에는 공용 SaaS 출시 차단을 유지한다.

## 검증

회귀 검사 90개 파일/699개 통과, verify:fast와 타입 검사 및 빌드 통과, 운영 의존성 취약점 0건. 새 검사는 링크·근로자·세션 바꿔치기, 만료, shared-saas 차단, 파일 경로 제한, 일괄 서명, 제공자 오류, 검수 차단, DB 읽기 후 만료, 응답 필드 제한, 인증 전 DB 접근 차단을 확인한다. 브라우저에서 잘못된 링크 복구 화면과 본인 확인 화면도 확인했다. 이 결과는 실제 고객의 교육 재생·제출 검증을 대신하지 않는다.
