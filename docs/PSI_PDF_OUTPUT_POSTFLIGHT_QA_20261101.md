# NEW-PSI 18차 · PDF 개인정보 가림 확대 검토 및 출력물 사후 검증

## 17차 운영판에서 발견한 실제 취약점
1. PDF 페이지 전체가 화면 폭에 맞춰 축소될 경우 작은 명찰·전화번호·문서의 인쇄글자를 식별하고 정확하게 가리기 어려움.
2. 17차는 **PDF로 내보내기 전 캔버스에서** 검정 픽셀을 확인했으나, 내보낸 PDF를 다시 렌더링했을 때 동일한 픽셀이 남았는지는 검사하지 않았음.

## 18차 구현
- 페이지 검토 화면에 **100%·150%·200% 확대**와 스크롤을 추가한다. 가림 영역 좌표는 화면 실제 크기에서 정규화해 원본 픽셀 기준으로 계산하며, 확대 표시값이 PDF 저장 영역을 변경하지 않아야 한다.
- 내부 검토 PDF 생성 후 **완성된 PDF를 PDF.js로 다시 열어** 기존 추출 텍스트/주석/첨부/폼 필드 검사를 유지한다.
- 각 검정 사각형 내부 3×3 위치의 픽셀을 재렌더링 화면에서 추출해 검정에 가까운 불투명한 픽셀인지 확인한다. 출력물 가림 오류가 확인되면 다운로드를 거부한다.
- 이전 17차 기능의 원본 PDF·별도 검토 PDF의 SHA-256 비교, 모든 페이지 검토 표시, 저장물 JSON 기록을 유지한다.
- 새 회귀 테스트에는 **정상 검정 픽셀/가림이 누락된 흰색 픽셀/복사 가능한 원문/주석/페이지 수 불일치**를 포함한다.

## 완료를 주장하지 않는 범위
- 단위 테스트는 모의 PDF 렌더러를 사용한다. 실제 Android·iPad·PC 기기로 확대/손가락을 이용해 검토·저장한 시험을 대체하지 않는다.
- 픽셀 내부의 9개 지점만 확인한다. 모든 픽셀 및 문맥상의 개인정보까지 자동으로 안전하다고 판정하는 것은 아니다.
- 검정 영역 밖에는 개인정보가 남을 수 있으며, 외부 제출에는 전체 육안 검토 및 독립 승인이 필요하다.
- PDF·사진 가림 도구와 12~13차 **운영 미적용** 서버 승인/현장 권한 구조는 아직 연결되지 않았다.
- 증빙용 원본의 보존·최초 생성 시점·법적 진정성은 출력물의 SHA-256만으로 증명되지 않는다.
