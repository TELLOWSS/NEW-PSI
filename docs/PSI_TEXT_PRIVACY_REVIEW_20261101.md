# NEW-PSI 15차 — 개인정보 가림 텍스트 내부 검토본

## 범위
14차의 선택한 원본 파일 ZIP과 별도로 **JSON·TXT만** 식별정보를 가린 검토용 ZIP을 생성한다. 원본 보전·증빙 출처 추적과 제출용 사본 작업을 분리한다. 사용자에게 실제 비식별화나 외부 제출 승인을 자동 인증하지 않는다.

## 동작
1. 관리자 상세 화면에서 현재 근로자 기록에 연결된 원본 증빙 ZIP을 선택하고 별도 보관한 ZIP 전체 SHA-256을 대조한다.
2. JSON/TXT 문서를 선택한다. 사진·PDF 파일은 **가림 텍스트 검토본에 포함하지 못한다**.
3. 현장 담당자가 원문에 등장하는 다른 이름·별칭·인적 식별 문구를 줄별로 추가한다. 현재 근로자 이름과 원본 기록 ID는 자동 가림 목록으로 포함한다.
4. 가림 결과를 완전한 개인정보 비식별화나 제출 승인으로 판단하지 않는다는 확인 후 별도 검토용 ZIP을 생성한다.
5. ZIP을 만들기 직전에 원본 ZIP 해시, 기록 ID, 선택한 원문 바이트 해시/용량을 다시 검증한다.
6. JSON은 식별 필드와 구조적으로 알려진 인적사항을 가리고, TXT는 패턴과 지정 문구를 가린다. 자동 처리: 한국 전화번호, 주민등록번호 형식, 이메일, UUID, JSON 인명·작성자·승인자·연락처 등 알려진 키. 텍스트 원문 안전관련 서술은 최대한 유지한다.
7. 출력에는 `REVIEW_TEXT_01.json` / `REVIEW_TEXT_02.txt` 등 비식별 이름과 새 `REVIEW_MANIFEST.json`, `SHA256SUMS.txt`를 포함한다. 상태는 항상 `LOCAL_TEXT_REVIEW_REDACTION_INCOMPLETE`이다.
8. 원본 ZIP은 수정하지 않는다. 새 ZIP 전체 SHA-256은 별도 관리대장에 기록할 수 있다.

## 개인정보 보호 한계
- **인명을 완벽하게 자동 탐지하지 않는다.** 다른 나라 이름, 초성·별명·오탈자·별도 인적 특징·작업 시각·위치 등이 남을 수 있다.
- 사진/PDF의 사람 얼굴, 문서, 이름표, 차량번호, EXIF/GPS 등의 정보는 이 기능으로 가려지지 않으며, 새 텍스트 ZIP에서 원천 제외한다.
- ZIP에 포함된 JSON 구조, 사건 기록, 시간·공종만으로 특정인이 재식별될 수 있다. 자동 검사 통과가 개인정보 보호 적합성 판단은 아니다.
- 임의 대체 문구가 문맥을 어색하게 만들 수 있으므로 보건안전 사실관계와 원본을 육안 대조한다. 조치 완료·교육 이행·책임판단을 추정하지 않는다.
- 관리자가 다운로드한 검토본은 **서버 승인·자료 반출·발송·외부 시점 인증이 아니다**.
- `P05` 현장별 SQL, `P03/P04` 서버 원본 수신, `P12` 독립 승인·반출 이력은 아직 운영 DB에 적용되지 않았다.

## 검증 수용 기준
- 근로자 이름·ID·일부 연락처/이메일·JSON 작성자 필드 가림 회귀 통과.
- 가림 검토본에 사진/PDF 및 선택하지 않은 파일이 **전혀 포함되지 않음**.
- 원본 무결성·근로자 기록 ID 불일치·ZIP 변조·중복/허용 외 경로 요청 거부.
- 타 언어 원문(중국어 등) 보존 및 생성 ZIP 내 누락 항목 검증.
- GitHub 릴리스 전체 검사와 브라우저 시나리오, Vercel 같은 SHA 운영 READY를 **별도로 판정**.

## 후속: 16차
- 이미지/PDF **실제 화면 기반 가림**을 시행하려면 사용자가 사각 영역을 선택해 원본 픽셀을 안전하게 소거하고, 메타데이터를 제거한 파일을 별도로 생성해야 한다.
- 이미지 크기/렌더링 비율, EXIF/좌표 제거, 픽셀 잔존·미리보기 차이, PNG/JPEG 품질, 회전·확대·손가락 사용성 등을 실제 기기에서 검사한다.
- 해당 이미지/PDF 가림 도구는 **15차에 구현되지 않았다**. 가림 없는 원본 이미지를 외부에 제출하지 않도록 별도 승인 절차가 필요하다.

**15차 완료 정의: 텍스트 패턴·필드 가림 사본 생성 코드 및 자동검증까지. 외부 제출 적합성·전체 이미지 가림·실현장 보안 검수는 미완료.**
