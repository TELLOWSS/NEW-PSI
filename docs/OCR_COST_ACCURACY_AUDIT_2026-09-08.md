# PSI OCR 비용·정확도 개선 검증서

기준일: 2026-09-08
정책 버전: OCR 1.3.0

## 결론 한눈에 보기

```text
업로드/촬영
   ↓  로컬 용량·형식·회전 점검
무료 Gemini 3.5 Flash-Lite 1차
   ↓  이름·공종·날짜·국적·Q1~Q5·번역 전수 검증
통과 ─────────────→ 로컬 기록/월별 백업
미달 ─→ 무료 Gemini 3.8 Flash 정밀 1회 ─→ 통과 또는 관리자 검토
무료 429 ─→ 예상비용 표시 ─→ 관리자 비밀번호 승인 ─→ 유료 1회만
404/401/403/400/5xx ───────────────────→ 유료 전환 금지
```

이번 운영 장애의 원인은 이미지나 필기 품질이 아니라 종료된 `gemini-2.5-flash` 폴백이었다. OCR 운영 체인에서 2.5를 제거하고 아래 GA 모델만 사용한다.

| 역할 | 모델 | 선택 이유 |
|---|---|---|
| 무료·유료 경제 1차 | `gemini-3.5-flash-lite` | 공식 문서가 문서 파싱·저비용 대량 처리 용도로 명시 |
| 자동 정밀 승격 | `gemini-3.8-flash` | 2026-09-02 기준 최신 GA Flash, 이미지/PDF·구조화 출력 지원 |
| 정밀 모델 가용성 폴백 | `gemini-3.7-flash` | GA이며 계속 지원 중인 안전 폴백 |
| 운영 금지 | Gemini 2.5, Preview Pro | 퇴역 위험 또는 비용·안정성 불확실 |

## 이번에 적용한 보호장치

- 핵심 OCR 생성 API를 최신 Interactions 형식으로 전환하고 `store:false`를 고정했다.
- 이미지에는 `high` 해상도를 사용하고 PDF에는 불필요한 과해상도를 강제하지 않는다.
- 생성 전에 `countTokens`와 문서당 비용 상한을 반드시 통과해야 한다.
- 가격표에 없는 미래 모델은 0원으로 오인하지 않고 호출 전에 차단한다.
- 모델 404는 다음 무료 GA 모델로만 전환한다. 모든 무료 모델이 실패하면 첫 파일에서 배치를 멈추고 남은 파일을 보존한다.
- 유료 전환은 무료 키의 공급자 429에서만 제안한다. 비밀번호 재확인, 문서 해시 결속, 짧은 만료시간, DB 일회용 승인, 유료 생성 1회 상한을 유지한다.
- 공급자 원시 JSON을 팝업에 노출하지 않고 관리자가 이해할 수 있는 오류 코드와 안내만 표시한다.
- Q1~Q5 원문·한국어 해석·외국인 모국어 해석을 일대일로 검사한다. 누락 결과는 버리지 않고 자동승인을 막아 관리자 검토 상태로 보존한다.
- 라틴 문자를 쓰는 베트남어·우즈베크어·인도네시아어를 영어 혼입으로 잘못 판정하지 않도록 수정했다.

## 현재 비용 예시

이미지 입력 1,120토큰, 최종 출력 1,000토큰을 가정한 단순 예시다. 실제 비용에는 사고 토큰과 실제 출력 길이가 반영된다.

| 모델 | 현재 유료 단가 | 예시 문서당 비용 |
|---|---:|---:|
| 3.5 Flash-Lite | 입력 $0.30/M, 출력 $2.50/M | 약 $0.00284 |
| 3.8 Flash | 2026-12-31까지 입력 $0.75/M, 출력 $3.75/M | 약 $0.00459 |

따라서 유료 승인 후 기본 자동 모드는 3.5 Flash-Lite 한 번만 호출하는 것이 최소비용 선택이다. 3.8 정밀 유료 호출은 관리자가 고정밀 모드를 선택하고 다시 승인한 문서에만 허용한다.

## 무료 운영의 현실적인 선택

Gemini 무료 티어는 금액이 0원이지만 무료 티어 입력·출력이 제품 개선에 사용될 수 있다고 공식 가격표에 표시된다. 근로자 이름·서명·국적이 포함된 원본을 판매용 서비스에서 처리할 때는 조직의 개인정보 처리 기준과 고지를 먼저 충족해야 한다.

완전한 무상·로컬 경로는 OpenCV 전처리와 PaddleOCR PP-OCRv5를 PC 보조 프로그램으로 묶는 방식이 유력하다. 다만 한국 건설근로자 실제 필기에서 가장 정확하다는 근거는 아직 없으므로 즉시 기본 엔진으로 단정하지 않는다. 비식별 PSI 정답셋으로 현재 Gemini 경로, PaddleOCR, Google Document AI를 같은 조건에서 비교한 뒤 채택한다.

## 모국어 품질 기준

“원어민에게 절대 이질감 없음”은 모델명만으로 보장할 수 없다. 판매 가능한 기준은 다음처럼 측정한다.

- 근로자가 선택한 `언어-지역-문자체계`가 국적 추정보다 우선
- 숫자·단위·장비명·보호구·부정·금지·의무·즉시 작업중지 의미 보존 100%
- 원어민이 승인한 건설안전 용어집과 번역 메모리 사용
- Q1~Q5 번역 누락 0건
- 중대 안전 의미 반전 0건
- 원어민 표본 검수 1차 통과율 95% 이상
- 신규 언어와 고위험 문장은 원어민 승인 전 자동 배포 금지

## 다음 검증 단계

1. 비식별 처리한 실제 PSI 100건으로 시작해 양식·필체·국적·회전·흐림별 정답셋을 만든다.
2. 이름·공종·날짜·Q1~Q5 필드 완전일치율, 문자오류율, 자동확정 오판, 검수시간, 성공 문서당 총비용을 측정한다.
3. 3.5→3.8 승격이 실제 정확도를 높이는지 A/B로 검증한다. 모델 자체 `ocrConfidence`는 정답이 아니다.
4. 로컬 OCR 후보가 개인정보·비용 이점을 유지하면서 품질 기준을 충족할 때 단계적으로 기본 경로로 전환한다.
