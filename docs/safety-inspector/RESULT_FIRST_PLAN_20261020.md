# 사진 한 장으로 필요한 답을 받는 점검 — 수정 기획·구현 명세

기준: 2026-10-20 / 기존 main 93f076a / 사용자 피드백에 따른 범위 정정.

## 문제와 완료 기준

법령 요지와 제재 금액은 최초 핵심 요구였는데 기존 구현은 이를 후속으로 미룬 채 촬영·분석 절차의 편의성을 완료 기준으로 삼았다. 이 문서는 FIRST_USE_PLAN의 법령을 선택 부가 정보로 취급한 우선순위를 대체한다. 메뉴·단계 수가 아닌 **사용자가 실제로 받는 결과**로 판단한다.

완료 기준은 사진과 짧은 설명에서 위험요인·즉시 조치·관련 법령 요지·조건별 법정상한을 한 결과 화면에서 보고, 확인 후 다음 사진 또는 보고서 저장으로 진행하는 것이다. 법령·금액을 찾으려고 상세 작업실이나 별도 법령 탭으로 이동하지 않는다.

## 기본 화면과 진행

1. 바로 촬영(실시간 미리보기·재촬영·사진 확인), 사진 선택 또는 PC Ctrl+V. 기기 내에서 사본을 최적화한다. 이 시점에는 점검 생성·서버 업로드·유료 분석을 하지 않는다.
2. 설명은 짧게 선택 입력한다. 사진 보관·외부 AI 안내를 확인하고 ‘사진 분석 · 법령·금액 보기’를 누르면 점검 생성→최적화 사본 업로드→설명 저장→명시적 API 호출을 연속 처리한다.
3. 결과 최상단에 상황·지금 할 일·관련 조문 요지·조건부 금액을 표시한다. 바로 아래에는 추가 관련 기준, 공식 원문 링크, 적용 조건을 표시한다. 전체 AI 관찰과 질문별 현장 확인은 펼쳐보는 보조 항목이다.
4. ‘확인하고 다음 사진’ 또는 ‘확인 · 보고서 저장’. 분석을 확인한 사진은 기존 서버 검토 절차를 사용한다. 보고서에 사진, 관찰·조치, 법령 요지·금액·공식 링크·자료 검토일·버전을 함께 고정한다. 인쇄/PDF와 요약 복사에도 포함한다.
5. 기존 기록·삭제·세부 조치·수동 ChatGPT 가져오기는 ‘저장 기록 · 상세 관리’에서 사용한다. 기존 기능의 회귀 시험은 정상 화면 전환을 통해 유지한다.

직접 진입: `/?mode=photo-inspector`. 관리자 인증을 그대로 사용하며 인증 우회나 테스트용 운영 분기를 추가하지 않는다.

## API 없이 바로 정보를 얻는 경로

- API OFF 또는 미연결: 설명을 바탕으로 관련 조치·법령·금액을 표시하고 **사진을 AI로 판독하지 않았음**을 명시한다. 최적화 사본 보관은 별도 명시 행동이다.
- 사진·보관 동의 없이도 설명 또는 주제 버튼으로 기준을 조회할 수 있다. 이 경로는 점검 생성·업로드·유료 호출을 하지 않는다.
- ‘현장 필수 법령 요지 · 금액 전체 보기’에서 수록 주제를 한 번에 볼 수 있다.
- 설명 기반 보고서는 관찰을 AI 분석으로 꾸미지 않고 ‘분석 없음’을 표시한다. 사진 검토 승인이나 개선 완료를 만들어 넣지 않는다.

## 법령과 금액의 실제 범위

14개 주제: 개구부·단부, 고소작업, 비계, 낙하·비래, 감전, 동바리, 굴착, 용접·화재, 전도·통로, 보호구, 법령 요지 게시, 안전보건교육, 안전보건표지, MSDS·경고표시.

AI는 법령·금액을 생성하지 않는다. 서버·브라우저가 같은 날짜 고정 공식 자료 목록을 사용한다. 입력 설명과 AI 관찰·법령 후보 키워드는 관련 기준을 찾는 신호이며 위반 확정 증거가 아니다. AI 가설과 개선 제안은 관찰 신호로 쓰지 않는다. 일치하지 않는 상황은 ‘기준 없음’이 아닌 ‘수록 자료에서 미분류’로 표시한다.

| 구분 | 수록 예시 | 표시 방식 |
|---|---|---|
| 사업주 안전조치 위반 | 법 제38조제1~3항 위반 성립 / 제168조제1호 | 5년 이하 징역 또는 5,000만원 이하 벌금 |
| 근로자 준수 의무 위반 | 법 제40조 / 제175조제6항제3호 | 300만원 이하 과태료, 사업주 책임과 구분 |
| 법령 요지 게시 의무 | 법 제34조 / 제175조제5항제3호 | 500만원 이하 과태료 |
| 정기·채용·변경 교육 | 법 제29조제1·2항 / 제175조제5항제1호 | 500만원 이하 과태료 |
| 유해·위험작업 특별교육 | 법 제29조제3항 / 제175조제2항제1호 | 3,000만원 이하 과태료 |

모두 **법정상한**이다. 실제 부과액, 과태료 1차·2차·3차별 기준, 가감액을 계산하지 않는다. 사진별 합산, ‘사진 한 장당 벌금’, 사망 결과·도급인 책임의 자동 적용을 하지 않는다. 사업장 전체 법령 게시용 완결 목록, 전체 법령·판례·감독사례 엔진으로 표시하지 않는다.

## 데이터·보고서 경계

새 보고서에 서버가 생성한 `legalReference`를 JSON 스냅샷에 포함하고 기존 정규 직렬화 SHA-256에 함께 반영한다. 클라이언트가 금액을 전달해 확정할 수 없다. 보고서에 선택된 증거사진만 법령 분류 신호로 사용한다. 기존 보고서는 당시 저장된 데이터를 그대로 읽고, 당시 미수록된 법령을 현재 기준으로 덧씌우지 않는다. 최종 현장 적용·법률 판단 상태는 UNVERIFIED/DRAFT를 유지한다.

사진은 기존 비공개 보관·최적화 증빙·삭제 절차를 재사용한다. DB schema·버킷 권한·원본 보존 정책 변경 없음. 유료 API는 업로드 시 자동 호출하지 않으며 사용자가 ON 상태에서 분석을 실행할 때만 호출한다. API 요금을 무료라고 안내하지 않는다.
