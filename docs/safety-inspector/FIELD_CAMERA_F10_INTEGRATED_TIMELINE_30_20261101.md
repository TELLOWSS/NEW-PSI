# NEW-PSI 30차 — F10 조치 경과 통합 타임라인 및 선택형 관리 보고서 (2026-11-01)

## 문제
25~29차에 F10 지연 조치, 담당자, 임시통제 기록, 재점검 예정일, 수정 전후 이력, 인계 및 CSV·A4 보고가 구현됐다. 다만 실제 관리자가 지난달부터 한 지적사항이 어떻게 바뀌었는지 알기 위해서는 별도 후속조치 이력, 임시통제 확인 기록, 재점검 이력을 각각 펼쳐 비교해야 했다.

이번 30차는 **조치기한 변경→임시조치 확인→재점검→다음 확인일**을 같은 대상·기기시각 기준으로 연결하고, 경과 이력을 보고서에 **선택하여 포함**하도록 한다.

## 기술 구조
- `lib/inspector/localRecheckProgress.mjs`: F10 기록의 `followup.history[]`와 `rechecks[]`를 **읽기 전용**으로 결합. 메인 점검 전체와 개별 조치는 독립 항목이다.
- 이벤트가 변경하기 전·후 조치 목표 기한, 임시 안전조치 변경 여부, 당시 후속 상태, 임시통제 확인 기록, 재점검 결과 및 당시 다음 확인 예정일을 표시한다. **조치 목표 기한과 재점검 확인일은 다른 필드이며 자동으로 일치시키지 않는다.** 최신 재점검 날짜가 공란이면 '미정'으로 유지한다.
- 기기 저장 이벤트 시각 순으로 배열하지만 기록 시각의 진위·실제 작업시간·업무의 선후 관계를 검증하는 공인 시각은 아니다. 같은 시각은 원래 이벤트 순서로 결정한다.
- 다음 사람 검토가 필요한 상황(기록 상태 상충, 과거 기한 변경의 사유 확인 불가)은 기존 F10 표시를 유지하며 자동 완료되지 않는다.
- 현장 직접 점검의 F10 관리 영역에 **경과 통합 타임라인**을 추가. 현재 우선순위 분류와 연결되며 대상별로 접어둘 수 있다. 화면에 표시되는 대상은 최대 30건이고, 30건 이상일 경우 필터로 좁히거나 보고서에서 전체 내역을 확인하도록 안내한다. 기록은 생략·삭제하지 않는다.
- 27차 CSV·A4 보고서에 **'조치기한 변경·임시통제 기록·재점검 경과 연결 포함'**이라는 별도 선택 체크박스를 추가. **기본값 꺼짐**. 선택하면 각 대상의 경과 이벤트를 구조화한 부가 CSV 섹션/인쇄용 타임라인으로 포함한다. 최대 이력 이벤트 1,500개 초과 시 조용히 일부를 누락하지 않고 저장을 차단하며 대상 필터를 좁히도록 안내한다.
- 기존 **담당자 이름 포함**, **상세 자유기입 포함** 체크박스는 그대로 분리. 타임라인을 켰다는 이유만으로 과거 사유·연락처·자유입력 내용을 노출하지 않는다. 상세를 별도로 체크한 경우에만 과거 기한 변경/재점검 사유도 포함된다. 사진 원본 바이트·전체 SHA-256은 어떤 경과 보고서에도 포함하지 않는다.
- CSV 수식 시작 문자 방어 및 HTML escape/CSP를 기존 출력기에 재사용. 보고 준비 직전 화면의 기록과 IndexedDB 저장 기록의 경과 내용까지 비교해, 다른 탭에서 기록이 바뀌었으면 거부한다.
- **데이터베이스 스키마·v17 JSON 백업 포맷 변경 없음**, 신규 서버 API 없음. 기존 후속조치/재점검 이력 자체는 수정하지 않고 집계 뷰로만 처리한다.

## 안전 경계
- `verified`, `temporary_checked`, `site_checked`는 사람이 입력한 기록일 뿐, 사진·AI가 실제 통제선 유지, 적법성, 위험 해소, 작업 재개를 승인했다는 의미가 아니다.
- 작업중지 필요성, 접근통제, 위험 제거, 재개 승인에는 현장의 별도 검토 절차가 필요하다.
- 보고서는 기본적으로 근로자별 점수·개인 분석 목적이 아닌 조치 대상 관리용 기록. 자유입력 항목을 선택했을 경우 개인정보가 존재할 수 있어 외부 제출 전 검토·적절한 보관이 필요하다.
- 기존 재점검 예정일의 출처와 기기 시각의 불확실성을 명확히 안내한다.

## 검증 방법
- 신규 `tests/localRecheckProgress.test.ts`: 여러 이력을 시각순으로 연결, 독립 기한 유지, 미정 날짜 보존, 과거 기록의 변경 사유 누락, 담당자·사진·SHA 기본 미노출, 개별 조치 독립, 오래된 기록 상태 불일치, 1,500 이벤트 상한.
