# Safety Inspector — 현장 작업실 UX·시각 디자인 보강

2026-10-20 / PR #29 후속 / 운영 main 미반영

## 사용자 흐름

첫 진입은 사진·사람의 검토·개선 증빙의 순서를 설명하고, 점검을 열면 소개 영역을 줄여 실제 작업 공간을 확보한다. 법령 검증 대기를 완료로 표현하지 않으며, 미확인 질문과 미결 조치에서 다음 행동을 안내한다. 자동 단계 넘김·가상 수치·자동 법령 결론을 추가하지 않는다.

## 구현

- 네이비·청록·미색 중심의 계층, 통일된 선형 아이콘, 자체 제작 SVG 건설현장·사진 프레임 도해. 외부 이미지 의존성 및 추가 폰트 의존성 없음.
- 실제 불러온 기록의 지표와 기록 검색·긴급/검토대기/미결 필터. 검색은 브라우저에서 수행하며 추가 서버 요청이나 페이지 커서 변경 없음.
- 단계마다 사진·검토·미결 상태를 표시하고, 다음 행동은 버튼으로 수동 선택한다. 좁은 화면에서 선택한 단계가 가로 탐색 영역에 보이도록 조정한다.
- 사진 선택 레일, 원본 확대, 보관 정보 접기. 확대는 native dialog와 키보드 순환·Escape 닫기를 제공하며 원본 바이트는 변경하지 않는다.
- 저장이 필요하거나 처리 중일 때만 하단 저장 동선을 표시한다. 페이지 전환 transform 바깥에 portal로 배치하여 스크롤로 사라지는 문제를 방지한다. 모바일 하단 탐색과 겹치지 않도록 배치하고, 저장하지 않은 이탈에는 브라우저 확인을 제공한다.
- 기한이 지난 미결 조치, 질문별 확인 근거, 검토용 보고서의 사진·미결·미확인 질문 요약. 미확인은 검토 수용·조치 확인 후에도 유지한다.
- 모바일 입력 글자 16px, 다크 테마, 동작 줄이기 설정, 인쇄시 제목 분리 방지. 키보드 포커스와 상태 전달은 텍스트를 함께 사용한다.

## 실제 로그인 검증에서 발견한 장애

사용자가 기존 관리자 자격정보 및 검증용 점검 1건 생성 시험을 승인했다. 기존 preview에서 로그인은 HTTP 503 `ADMIN_LOGIN_SECURITY_UNAVAILABLE`로 중단되었으며, 사진·점검·보고서를 생성하지 않았다. 실DB 조회로 해당 검증용 점검 0건을 확인했다.

실제 Vercel 로그: `security_store_configuration_unavailable`. PSI-Database의 `psi_consume_api_quota` 함수는 존재하고 service_role 실행 권한이 있으며, rollback-only 호출은 성공했다. 따라서 DB quota 함수를 제거하거나 로그인 제한을 우회할 문제가 아니다.

- Vercel 환경변수 목록은 403, 이 작업환경에 인증된 Vercel CLI 없음. 현재 권한으로 값을 확인·수정하지 않았다.
- 서버 URL의 기존 우선순위를 유지하면서 표준 `SUPABASE_URL` fallback 및 공백 처리를 지원한다.
- 설정 실패 로그에 `url` / `serviceRoleKey`라는 누락 분류만 남긴다. 실제 값·비밀번호·토큰·IP는 로그와 클라이언트 응답에 포함하지 않는다.
- 서비스 역할 키 대신 anon 키 사용, 인증 우회, 공개 버킷, 로그인 횟수 제한 해제는 추가하지 않는다.

운영 담당자는 Vercel `new-psi`의 해당 Preview 범위에서 URL(`VITE_SUPABASE_URL` / `NEXT_PUBLIC_SUPABASE_URL` / `SUPABASE_URL` 중 실제 사용하는 이름)과 서버 전용 `SUPABASE_SERVICE_ROLE_KEY`(또는 지원 alias)가 구성되어 있는지 확인해야 한다. 비밀 키는 Vercel 설정에서 직접 입력하고 대화나 저장소에 기재하지 않는다. 변경 후 재배포가 필요하다. 값의 내용은 이번 작업에서 확인하지 않았으므로 어떤 값으로 대체해야 한다고 추정하지 않는다.

## 검증

전체 회귀 114 files / 1,016 tests, verify:fast, TypeScript, production dependency audit(취약점 0), production build 통과. 이후 화면 공간·가로 단계 탐색 수정에 대해서도 타입·빌드 및 브라우저를 재확인했다.

실제 Chromium 138과 mock API에서 390×844 / 768×1024 / 1440×1080 업무 흐름, 실제 WASM 영어 OCR, 사진 확대의 Tab·Escape, 모바일 하단 저장 버튼의 실제 클릭 가능 위치, 로컬 검색의 추가 요청 없음, 미확인 질문 PDF 보존, 편집 후 페이지 커서를 확인한다. 다크 모드 캡처를 함께 점검했다. Android 실기기 검증 및 실배포 관리자→Storage 전체 경로와 구분한다.

테스트용 캡처는 비식별 fixture이며 검증 산출물 경로는 `artifacts/audit/inspector/`다. 외부 공개나 실제 현장사진을 포함하지 않는다.
