# 사진 점검 비주얼·편의 개선 (2026-10-23)

## 사용자 흐름과 기획

사진을 넣고 분석한 안전 전문가가 먼저 할 일을 확인하고, 필요한 근거만 대조한 뒤 다음 사진 또는 보고서로 진행한다. 위험명·연결 기준·위험명이 거듭 표시되던 핵심 화면을 조치 중심으로 재배치한다. 법령·금액과 사례·동향의 선택 위험 연결은 그대로 사용한다.

- 촬영 시작: 기존 그래픽의 카메라 아이콘과 건설 스케치를 재사용한다. 사진 촬영·선택을 명확히 구분하고 PC 붙여넣기 안내를 유지한다. 새 이미지 다운로드·라이브러리가 없다.
- 핵심 결과: 위험 제목을 한 번 표시하고 우선순위, 관찰 확신·한계, 먼저 할 일을 먼저 보여준다. 근거 위치·관찰·가능 위험은 ‘사진 근거·위험 설명’에서 펼친다. 사진 확대·대조는 그대로 사용할 수 있다.
- 여러 위험: 현재 번호/전체 개수와 이전·다음 버튼을 제공한다. 가장자리에서는 버튼을 비활성화한다. 고른 항목이 가로 목록 안에 보이도록 이동하며 다른 위험으로 바꾸면 직접 대조한 기준과 근거 펼침 상태를 초기화한다.
- 선택 복사: ‘이 위험·조치 복사’는 선택한 위험의 연결 관찰과 조치만 복사한다. AI 제안/전문가 대조 필요/위반·완료 확정 아님을 포함한다. 다른 위험·법적 금액·개인 식별자·사진 URL은 포함하지 않는다. 미수용 AI 상태에는 이 버튼을 표시하지 않으며 기존 전문가 의견 기반 복사·공유를 사용한다. 클립보드 권한 거절은 화면 내 상태로 안내한다.
- 모바일·접근성: 320/390/768/1440px, 밝은/어두운 화면, 44px 이상 조작 영역, 키보드로 근거 펼치기, 기존 탭 방향키와 포커스 표시를 확인한다. 색만으로 우선순위나 선택 상태를 전달하지 않는다.

## 데이터·비용 경계

이번 변경은 기존 API 응답의 화면 표현과 사용자 실행 클립보드 동작이다. 위험 전환·근거 펼침·복사는 서버 저장, 외부 AI 실행, 자동 검토·완료 확정 또는 상대에게 전송을 수행하지 않는다. DB/schema/RLS/Storage 삭제 엔진·분석 요청 식별자는 변경하지 않는다. 과거 저장 결과와 고정 보고서를 수정하지 않는다.

## 검증

`scripts/verify-inspector-quick.mjs`에 선택 위험 이동·복사 성공 및 거절·복사 내용 범위·근거 초기화·법령/사례 연결·미수용 시 차단 시나리오를 추가했다. `PSI_QUICK_DIST`로 별도 빌드 출력물을 직접 지정하여 이전 번들 혼입을 방지한다. 기존 촬영·붙여넣기·분석 실패 복구·삭제·보고서·조치·카드 공유 회귀 시나리오를 함께 실행한다. 실제 AI 호출 대신 표준 검증을 통과하는 합성 응답을 사용한다. 최종 CI, 운영 배포 SHA 및 검증 결과는 연결 PR에 기록한다.
