## 변경과 재사용

- 새 점검은 AI 없는 직접 점검으로 시작한다. AI 연결 확인은 사용자가 기존 AI 스위치를 켜거나 AI 사용 기록을 이어볼 때만 수행한다. AI 정밀분석·비용/동의 확인·실패 복구 자체는 유지한다.
- 사진 선택 뒤 기존 문서의 `workType`과 기존 사진별 `photoRiskTopics`를 짧은 선택으로 지정한다. 공종은 점검 전체, 위험은 현재 사진의 점검자 진술임을 명시한다. 공종으로 위험을 자동 판정하지 않는다. 모르는 항목은 비워 둘 수 있다.
- 법령 조회는 기존 `LEGAL_CARDS`, `legalForTopics`, `InspectorLegalResult`를 재사용한다. 기존 원문·검토 상태·법정상한·실제 적용 요건은 변경하지 않는다. 수록 사례/동향이 없으면 확인 필요로 표시한다.
- 새 저장 경로·메모 파싱 규칙·DB 테이블/컬럼·API·외부 수집을 추가하지 않는다. 기존 `savePhoto`가 사진·의견·공종·위험을 저장하고 기존 조치·보고서·공유로 이어진다. 원본 최적화·해시·동결 보고서·삭제·인증은 그대로 사용한다.
- 공종 수정도 미저장 이탈 보호와 자료 완료 무효화 대상이다. 저장 실패·사진 업로드 후 재시도 때 선택을 유지한다. 기존 사용자 정의 공종과 저장된 AI 설정을 이어보기에서 보존한다.
- 저장 결과가 열리면 위험 선택은 기존 결과 컨트롤에서 계속한다. 입력 폼에 위험 선택을 중복 노출하지 않는다. 기존 의견 입력의 수동 모드 라벨을 ‘점검자 의견’으로 명확히 한다.
