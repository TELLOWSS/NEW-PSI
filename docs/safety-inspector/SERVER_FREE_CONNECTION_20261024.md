# 무료 서버 연결 및 기기 공통 확인

Vercel에 GEMINI_API_KEY_FREE가 존재하지만 사진점검은 기존에 일반 GEMINI_API_KEY만 사용했다. 사진점검 모듈만 무료 전용 키를 우선 선택하도록 수정한다. 다른 PSI AI 기능의 키 선택·유료키·로그인 키는 변경하지 않는다.

관리자 ai-status에 실제 선택 키와 기존 Gemini 키 후보의 SHA-256 지문만 제공한다. 비밀값은 반환하지 않는다. 이는 키 이름만으로 무료 여부를 추정하지 않고 Google AI Studio의 기존 키와 대조하기 위한 메타데이터이다.

PSI_INSPECTOR_FREE_PROJECT_REGISTRATION은 비밀이 아닌 운영자 확인 JSON이다. version=1, provider, model, keySha256, projectId, verifiedAt, expiresAt를 포함한다. 실제 선택 키/모델과 일치하고 확인 시각이 미래가 아니며 유효기간 30일 이내인 경우에만 적용한다. 실제 청구 조회가 있으면 그 결과가 항상 우선하고, 검토 요금표 만료·미지원 모델은 기존대로 차단한다. 이 확인은 실시간 결제 검증이나 무과금 보증이 아니다. 외부에서 결제를 연결하면 조회 권한 없이는 즉시 감지할 수 없다.

서버 등록은 기기 공통으로 적용하고 화면에 서버 범위를 표시한다. 브라우저 등록을 반복할 필요가 없다. 해제는 해당 환경변수 삭제 및 재배포로 한다. 브라우저 쿠키 해제와 혼동하지 않도록 서버 등록 상태에서는 브라우저 해제 버튼을 표시하지 않는다.

실제 Google 프로젝트와 서버 키 지문이 일치함을 확인한 다음에만 이 설정을 등록한다. 키 원문·쿠키·서명 비밀은 문서·코드·출력에 보관하지 않는다. 기존 사진/보고서는 변경하지 않는다.
