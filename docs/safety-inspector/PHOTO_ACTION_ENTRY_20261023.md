# 사진 결과에서 조치 작성까지 동선 단축

## 사용자 문제와 구현 흐름

사진 결과를 확인한 전문가가 조치를 등록하려면 다음 사진으로 이동한 뒤 ‘조치 모아보기’를 펼치고 제안/사진을 다시 찾아야 했다. 결과 아래 ‘검토 저장 · 이 사진 조치 작성’을 둔다. 사용자의 명시적 클릭으로 현재 사진의 검토를 저장하고 조치 작성 폼을 펼쳐 이동한다. AI 미분석 자료에는 ‘이 사진으로 조치 작성’을 제공한다. 별도 AI 호출은 없으며 사진을 다시 업로드하지 않는다.

저장한 전문가 의견이 있으면 그 의견을, 없으면 해당 사진에 연결된 검토된 AI 제안을 처음 표시한다. 미수용 AI 제안은 기존 제안 생성 규칙에서 제외한다. 해당 제안이 없는 API OFF/설명 자료는 직접 작성으로 연다. 현재 사진만 먼저 선택하고 같은 문구의 다른 사진은 선택하지 않는다. 담당자·기한은 비워 두며 적용 범위 확인도 자동 체크하지 않는다. 사용자가 제안/제목/사진/담당/기한과 범위를 확인하고 저장하면 기존 ‘미조치’로 등록한다. 법령 판정·현장 안전 승인·완료 처리는 하지 않는다.

기존 조치 또는 개선 입력이 있으면 새 작성 폼으로 전환하기 전에 소실 확인을 받는다. 전환을 취소하면 현재 사진·이전 입력을 그대로 둔다. 조치 작성 화면의 닫기를 통해 미저장 조치만 정리하고 사진·저장한 검토는 유지한 채 보고서로 진행할 수도 있다. 검토 저장 실패, 설명 변경, 열지 않은 기존 분석은 이동하지 않는다. 같은 UUID로 사진 저장을 재사용하고, 조치 저장의 응답 유실 복구·중복 차단·30건 한도를 유지한다.

## 반복 입력 줄이기

현재 점검에 저장된 조치의 담당자 중 최근 다섯 명을 중복 없이 선택 버튼으로 제공한다. 다른 점검/기기 저장소에서 가져오거나 공종을 자동 추정하지 않는다. 오늘·내일·3일 뒤 버튼은 한국시간의 기기 달력을 기준으로 날짜를 계산하며 클릭할 때만 날짜 필드를 변경한다. 주말을 포함한 달력일임을 표시한다. 기기별 날짜 입력기 표기와 함께 선택 기한을 YYYY-MM-DD로 명시한다. 자정이 지나도 이미 입력한 기한은 자동으로 바뀌지 않는다. 담당/기한 변경 시 적용 범위 확인을 다시 받는다.

## 저장·모바일·검증 범위

기존 문서/사진/조치 API를 사용하며 신규 DB/schema/환경변수/의존성/유료 호출·사진 복제 저장소가 없다. 기존 보고서 스냅샷과 삭제 범위를 바꾸지 않는다. 작성 영역 이동 시 포커스를 조치 내용에 두고 모바일 버튼 44px 이상, 좁은 화면 줄바꿈·다크 모드를 유지한다. 인쇄에는 신규 입력 동작을 내보내지 않는다.

검증: 사진 일치·전문가 의견 우선·미검토/미수용 배제·없는 사진 직접 작성, 현재 점검 내 담당자 한정, 연말/윤년/잘못된 날짜, 브라우저의 직접 진입/수동 모드/두 사진 분리/미체크 저장 차단/실패 유지/소실 확인/담당·기한 선택/보고서·공유 회귀를 확인한다. 합성 API fixture와 실제 운영 인증 읽기 검증을 구분하며 결과·head CI·메인/배포 정보는 연결 PR에 기록한다.
