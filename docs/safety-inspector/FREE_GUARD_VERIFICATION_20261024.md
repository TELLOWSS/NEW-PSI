# 무료 API 보호 후속 검증

현재 운영은 실제 키 지문과 결합된 서버 운영자 확인을 이용한다. 무료 프로젝트 확인은 자동 Cloud Billing 감시와 다르며, 공급자 잔여 횟수도 조회하지 않는다. 이 상태를 UI에 명시하고 운영자 확인 및 요금 검토의 유효기한을 표시한다.

발견한 문제는 읽기 전용 청구 조회가 구성된 환경에서 조회 실패 시 이전 운영자 등록으로 되돌아가 분석을 허용할 수 있었다는 점이다. 조회가 구성됐는데 실패한 경우 unavailable/allowed=false로 반환하도록 바꾼다. 청구 연결을 감지한 다음 조회가 실패해도 수동 등록으로 자동 우회하지 않는다. 조회가 아예 구성되지 않은 기존 환경은 유효한 운영자 확인으로 계속 사용 가능하다. 권한·결제·자격 증명은 변경하지 않는다.

상태 응답의 billingCheck는 not-configured, verified, failed, not-run으로 확인 경로를 드러낸다. pricingExpiresAt은 서버에 고정된 모델 요금 검토 만료 시각이다. remainingRequests는 항상 null이며 앱의 점검당 20회 제한을 공급자 무료 한도로 표시하지 않는다.

검증에는 청구 미연결·연결·정지·판정 불명·조회 실패, 유효한 수동 등록이 있는 상태에서 조회 실패, 유료 감지 후 조회 실패, 키·모델 불일치·등록 만료·요금표 만료, 유료 키만 있을 때 대체 금지를 포함한다. 브라우저는 합성 API로 차단과 OFF 저장을 확인한다. 실제 운영 확인은 이미지·추론 없이 ai-status로 수행한다.

공식 참조:
- https://docs.cloud.google.com/billing/docs/reference/rest/v1/projects/getBillingInfo
- https://ai.google.dev/gemini-api/docs/billing

이 보호는 외부 관리자가 결제 설정을 변경하는 경합이나 조회되지 않는 공급자 정책 변경을 영구적으로 방지하는 무과금 보증이 아니다. 실제 확인 방식·유효기한·정책 범위를 그대로 표시한다. 배포·검증 증빙은 연결된 PR에 기록한다.
