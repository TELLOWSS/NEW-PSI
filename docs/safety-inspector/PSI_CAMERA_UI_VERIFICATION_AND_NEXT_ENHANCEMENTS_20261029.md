# PSI INSPECTOR 카메라 — UI 정리·검증 및 추가 고도화 (2026-10-29)

> 구분: **구현 코드 / 검증 기준 / 향후 고도화 제안**. 시안·합성 테스트를 실제 휴대전화 검증이나 AI 위험판정으로 혼동하지 않는다.

## 1. 문제 확인

기존 운영 \`main\`에서 카드형 분석 결과와 기존 기록관리 개선은 배포됐으나, PR #134 카메라 개편은 별도로 남아 있었다. 따라서 촬영 화면에는 예전 가이드와 좌측 상단 영상 상태 등이 보였다. 개발본 자체도 과거의 자유 부유형 구도 선택 규칙이 CSS에 남아 화면 크기별 배치가 불명확했다.

### 사용자 기준

- 320·390px **세로 촬영 중** 가이드 선택 UI가 미리보기 공간에 상시 걸쳐 있지 않아야 한다.
- 사진을 찍을 때는 영상·셔터가 우선, 구도 선택은 요청할 때만 잠깐 열려야 한다.
- 가로 844×390에서 제어부가 서로 겹치거나 화면 밖으로 나가면 안 된다.
- 3×3 격자/시스템비계/개구부/양중/전후 사진 겹침은 **구도 참고**일 뿐 실제 위험 자동 인식 결과가 아니다.
- 촬영 원본에는 격자·가이드선·참조 이미지가 합성되지 않아야 한다.
- 저장된 위험분석·전문가 검토·일괄 기록 정리는 변경하거나 손상시키지 않는다.

## 2. 이번 개발본에 적용한 개선

| 항목 | 설계·코드 변경 | 검증 기준 |
| --- | --- | --- |

| 선택 도크 | 셔터 상단에 붙인 소형 하단 도크 (별도 떠다니는 패널 제거) | 320×568 / 320×740 / 390×844 / 844×390에서 화면과 셔터에 겹치지 않음 |
| 한 번에 선택 | 시스템비계 / 개구부 / 양중 단축카드 3개, 선택 후 자동 닫힘 | 선택한 가이드와 영상 오버레이가 일치 |
| 부가 설정 분리 | 3×3 격자, 구도 해제는 바로 선택. 상세 촬영 요령·영상 진단은 접기 | 짧은 기본 높이, 필요 시 확장 |

| 시각 효과 | 선택 순간 초점 잠금·스캔 애니메이션 후 시각 방해 최소화 | 화면상 연출만 수행, 안전 위험을 확정하지 않음 |
| 접근성 | 텍스트 레이블, 44px 헤더 버튼, 선택 상태, 동작 축소 설정 | 키보드·스크린리더·움직임 축소에 대한 회귀 |
| 배포 절차 | 최신 기록관리·카드 기능을 보존하고 PR을 검증 후 병합 | main과 Vercel Production이 같은 변경 버전인지 확인 |

## 3. 자동 시뮬레이션 범위

- 사진 카메라 권한 허용·거부, 연결 지연, 네이티브 카메라 대체, 회전/방향, 원본 비율/화소.
- 네 해상도에서 **닫힌 구도 버튼의 헤더 포함**, 열린 도크가 화면 밖이나 셔터 영역에 걸치지 않는지 검증.
- 시스템비계·개구부·양중 선택 전환, 도크 자동 닫힘, 스캔 연출 시작, 안내 확장 및 격자 상태 유지.
- 합성 녹색 영상 촬영 결과의 실제 픽셀 확인: 가이드·참조 사진·격자 비포함.
- 전후 동일 구도 렌즈와 겹침 투명도, 이미지 로드 실패 대응, 사진 등록 전 저장상태 보호.
- 이전 PR #135·#136의 카드·보고서·기록 삭제 테스트 유지.
- **실기기 갤럭시/아이폰**에서의 회전 잠금, 카메라 승인 OS UX, 햇빛 가독성, 저사양 발열은 별도 실기기 검증이며 자동 시뮬레이션을 통과했다고 완료 처리하지 않는다.

## 4. 다음 고도화 백로그 — 우선순위

### P0 · 출시 안정성
1. Android Chrome / 삼성 인터넷 / iOS Safari에서 촬영 시작·복귀·방향 전환, 320×568 작은 화면 검증.
2. 카메라 권한 차단·재허용, 화면 회전 잠금, 통화·백그라운드 복귀, 앱 일시중단과 스트림 해제 검증.
3. 카메라 → 사진 분석 → 카드 → 조치 → 공유/저장까지 **같은 기록 ID**가 유지되는 종단간 회귀.

### P1 · 현장 사용성
1. 가로·세로 촬영 중 손가락 접근이 좋은 셔터/전후 카메라 버튼과 햅틱 피드백(지원 기기만).
2. 화면 비율에 따른 상단 헤더, 도크, 셔터 주변 안전영역의 자동 배치. 노치·내비게이션 바와 겹침 방지.
3. 다크/실외 고대비 모드·큰 글씨·장갑 사용을 위한 버튼 크기 설정.
4. 연속 촬영 보관 성공/실패 배지 및 사진 수량/순서 안내. 불필요한 확인 팝업 최소화하되 미저장 촬영 보호.

### P2 · 전문가용
1. **점검자 직접 표시 방식**의 위험 포인트/구역 주석(원본과 별도 저장, 좌표·작성자·시각 기록).
2. 촬영 전후 비교용 분할/슬라이드 인터랙션, 원본 비율 차이·촬영 위치 차이 경고.
3. 현장 양식에 맞춘 장비별 참고 프레이밍 프리셋. 사진 밖 방호시설의 미설치를 확정하지 않는다.
4. 합성 시뮬레이션 외에 표준 검증 세트와 리그레션 이미지 비교(Screenshot Diff), 성능 예산(FPS/메모리/배터리) 추가.

### P3 · 정식 AI 보조(별도 개발·검증)
1. 점검자 동의 하에 관심 영역 후보 위치 제안, AI 제안과 점검자 확정 구역을 명확히 구분.
2. 가이드 표시를 ‘대상을 AI가 인지했다’ 또는 ‘위법/위험 확정’으로 오인하지 않도록 충분한 UI·성능 검증.
3. 한국어·외국어 화면 안내와 장비별 현장 맥락 품질 검토.
