# PSI Inspector 모바일 UX 검증

기준: main `971d341e06d6bb9dc73f58762e25449888a18837` + 선행 공식 안전정보 PR #117 (`97959c5`). 이 변경은 #117 위의 별도 UX 브랜치다. 운영 main에는 두 변경 모두 아직 반영되지 않았다. 아래는 2026-10-27 로컬 합성 검증이며 원격 CI·Preview는 PR의 현재 상태를 별도 확인한다.

## 변경 전후 동선

| 구간 | 변경 전 | 변경 후 |
|---|---|---|
| 첫 진입 | 단계 안내·통합대장·점검 유형 설명을 지나 촬영 | 촬영·저장 기록을 먼저 노출. 기존 유형·통합대장·안내는 아래에 배치 |
| 점검 방식 | AI 전환이 비용·운영 설정 안에 접힘 | 기존 전환 한 개를 밖으로 이동. AI 없는 직접 확인 / 외부 전송이 있는 AI 정밀점검을 명시 |
| 법령·사례·동향 | 기존 탭, 출처 날짜는 접기 안 | 탭 유지. 공개일·검토일을 접기 요약에 표시. 기존 수록 검토일과 원문 확인 이력을 구분 |
| 조치 작성 | 긴급 위험·약정기한 차이를 긴 문장으로 안내 | 기존 안내를 긴급 현장 통제 검토 / 기한부 시정조치 두 항목으로 구분. 담당·기한·재점검 기능 재사용 |
| 저장 전 이탈 | 사진 선택 전 설명·로그아웃 경고 누락 | 설명·제목·조치 입력의 이탈 경고 및 로그아웃 취소 보호. 기준카드 읽기만 한 경우에는 불필요한 이탈 경고 제외 |

촬영 버튼의 문서상 위치(스크롤 전 y, CSS px): 320px 폭 1,220 → 577, 390px 폭 1,189 → 566, 768px 폭 1,317 → 568, 1440px 폭 1,218 → 592. 높이 844px에서 촬영·기록이 첫 화면에 들어왔다. 768px에서는 설명 영역 높이가 사진 영역을 늘려 촬영 버튼을 아래로 밀던 문제도 수정했다. 주요 버튼·탭·접기는 모바일에서 최소 44px, 방식 전환은 48px로 검사했다. 기존 PSI 색상·서체·컴포넌트를 재사용하고 첫 촬영 영역의 장식 그림만 숨겼다.

## 보존 경계

촬영·최적화·해시·보관·삭제·AI 분석·법령 연결·조치·재점검·공유의 기존 함수와 서버 경로를 재사용한다. 새 기능 버튼·점검 모드·DB 필드·인증 방식·API·자동 저장 서비스를 추가하지 않았다. 기존 AI 기본 설정과 실행 동의·비용 차단 조건도 유지한다. 새로운 사진이나 의견을 sessionStorage/localStorage에 저장하지 않고 기존 ID 기반 이어보기를 유지한다.

나비: 촬영 우선·방식 구분·입력 유지. 루미: 기존 디자인과 작은 화면 터치·넘침. 세이프: 긴급 통제와 기한, 검토일 의미 구분. 코어·키퍼: 기존 저장·인증 계약 보존. 프루프: 단위·합성 브라우저 및 별도 원격 CI 증거. 이는 검토 책임 구분이며 별도 에이전트 실행을 뜻하지 않는다.

## 검증 결과

- 전체 `npm run verify:ci`: 183개 파일·1,569개 테스트, 타입·정적 계약·high 이상 보안 게이트·빌드 통과.
- 최종 날짜 문구·읽기 전용 기준 조회 보호 보완 후 Inspector 영향 검사: 55개 파일·481개 테스트, 타입 검사 및 빌드 통과.
- `verify-inspector-mobile-ux.mjs`: 320·390·768·1440px 모두 통과. 단일 촬영·방식 전환, 가로 넘침 없음, 설명/조치 입력 이동·로그아웃 취소, 사진/조치 저장 실패 후 입력 유지·재시도, 수동 점검→법령·사례 탭→조치→보고서→새로고침→같은 점검 이어보기 확인. 각 흐름 AI 분석 0회, 사진 upload 1회, 점검 create 1회, 보고서 1회.
- 기존 촬영 합성 검사 6개 통과. 보고서 검토·의견·변경 설명·인쇄 6개 통과. 공유·인증 11개 통과. 제품 통합 7개 흐름 통과. 출처 상태·관리자 export/import·이력 보호 검사 통과.
- 기존 quick 브라우저 영향 6개(review-save, ai-off, api-unavailable, report-retry, direct-manual, text-only)도 실제 현재 동선으로 수정한 뒤 모두 재통과했다. AI 경로는 합성 응답으로만 검사했다.
- `check-psi-company-ownership.cjs` 최종 신규 파일 포함 1,195개 파일 검사 통과.
- 브라우저는 Chromium·합성 API 응답·합성 JPEG만 사용했다. 실제 관리자 비밀번호·현장 사진·근로자 기록·공유 토큰·유료 AI 호출은 사용하지 않았다.

실패를 숨기지 않았다. 최초 전체 검사의 기존 문자열 계약 2개는 실제 컴포넌트 호출 형태와 안전 문구를 맞춘 뒤 재통과했다. 768px 촬영 위치 실패는 사진 영역 상단 정렬로 수정했다. 기존 quick 브라우저 스크립트의 오래된 제목·촬영/보고서/직접 조치 선택자는 현재 사용자 동선으로 고쳤다. 데이터·호출 횟수·입력 유지 검증을 삭제하지 않았다. 출처 조회만 한 화면의 불필요한 미저장 경고는 실제 사용자 입력과 구분했다.

합성 증거: `artifacts/audit/inspector-mobile-ux/`의 before.json·results.json 및 전후/출처/긴급·기한 안내 PNG, 기존 각 browser QA artifact. 증거에는 실데이터가 없으며 Git에는 자동검사·이 문서만 포함한다.

## 미확인·제한

- 실제 Android/iOS 카메라·키보드·스크린리더·장갑 터치·외부 메신저 전달은 미확인이다.
- 입력 보호는 이탈 경고·이동 취소·저장 실패 후 화면 유지다. 모바일 OS 강제 종료·브라우저 충돌 전의 미저장 사진/텍스트 자동 복구를 보장하지 않는다. 민감 자료를 기기 영구 저장하는 경로는 추가하지 않았다.
- 선행 #117의 자료 검토 상태(23 legacy, 1 pending, 1 reviewed), 미확인 시행본과 기존 moderate 의존성 권고는 그대로다. 자료가 검증 완료로 승격된 것은 아니다.
- 운영 반영은 선행 PR 통합, 동일 SHA 원격 CI·Preview 및 기존 안전·보안·Vercel 플랜 적합성 게이트 후 판단한다. 합성 API 테스트를 실제 운영 DB 검증으로 보고하지 않는다.
