# 보고서 마감·현장 인계 고도화

## 문제와 사용자 흐름

안전 전문가는 사진 여러 장을 모은 뒤 미검토 사진을 찾고, 담당자별 요청문이나 사진별 내용을 다시 조합해야 한다. 사진 목록이 접히면 보고서 제목/완성 동작도 함께 숨겨진다. 이를 ‘사진 검토 → 마감 상태 확인 → 검토용 보고서 또는 전체 인계문’으로 줄인다.

사진 사이 화면에 마감 영역을 항상 표시한다. 미검토 AI 사진 수와 첫 사진 바로 열기, 현재 저장본의 보고서 포함 사진 수/미결 조치 수를 제시한다. 사진 목록의 분류·페이지와 독립적이다. 제목 입력은 선택 펼치기로 유지하며 작성 버튼을 목록 밖으로 옮긴다. 미검토 AI가 있으면 영역의 작성 버튼을 비활성화하고 바로 검토 경로를 제공한다. 하단 고정 버튼도 대기 사진이 있으면 작성 대신 해당 사진을 바로 연다. 내부 작성 경로는 검토 누락을 재확인하며 누락 때문에 제목만 먼저 저장하지 않는다. 작성 중인 조치가 있으면 보고서 생성 전에 저장/정리를 안내한다.

설명 자료·AI 미수용 의견·개선 증빙은 AI 검토 누락으로 세지 않는다. 미결 조치나 설명 자료가 있는 상태에서도 검토용 보고서를 만들 수 있으나 안전 승인/정식 발행으로 표시하지 않는다. 포함 사진 수는 서버와 같은 자료 선택+조치 근거/개선사진 합집합이다. 제목 등 수정으로 자료 선택이 해제되면 생성 결과는 새 저장본을 따른다.

## 전체 인계문

현재 저장된 점검번호/버전/기록시각, 현장 정보, 모든 사진의 설명/검토 상태/전문가 기록, 전체 등록 조치의 제목/담당/기한/상태/연결 사진 번호를 텍스트로 모은다. 미검토·미수용 AI 원문은 전달 지시로 재사용하지 않는다. 법령/금액을 새로 생성하지 않는다. 사진 번호는 모은 사진 전체 목록 기준이다. 고정 보고서의 부분 선택 번호와 혼동하지 않도록 명시한다.

복사, 기존 기기 공유 미리보기, UTF-8 txt 저장을 제공한다. 사진 파일·입력 중인 제목/조치는 제외한다고 UI와 인계문 모두 밝힌다. 모든 사진/조치를 포함하되 긴 설명/의견/조치 문장은 표시된 요약 범위로 줄여 공유 편집기의 50,000자 한도 이내로 유지한다. 완전한 원문은 저장 기록/검토용 보고서에서 대조한다. 기기 공유는 앱/상대 선택과 실제 전송을 사용자가 수행하며 수신 완료를 보증하지 않는다. 문구 전용 공유에는 사진을 보낸다는 안내를 표시하지 않는다.

## 저장·비용·검증

신규 저장소/DB/API/의존성/환경변수/유료 AI 요청이 없다. 인계문은 메모리에서 계산하며 사진을 내려받거나 복제하지 않는다. txt/공유 사본은 사용자 기기/수신처에 남아 앱 삭제 대상으로 주장하지 않는다. 기존 삭제, 원본 불변 최적화, 보고서 스냅샷/해시 경계를 유지한다.

단위 검증은 미검토 차단·수동 자료 허용·거절/미검토 AI 배제·전체 조치 포함·최대 문서 길이·원문 불변·부분 보고서 사진 선택 경계를 확인한다. production 번들 브라우저에서는 다수 사진/조치 fixture로 미리보기/복사/txt/모바일/다크 모드와 추가 AI/업무 변이 없음, 기존 보고서 경로를 확인한다. 실제 운영 인증/저장 기록 읽기는 fixture 결과와 구분한다. 최종 CI/main/배포와 실제 검증 결과는 연결 PR에 기록한다.
