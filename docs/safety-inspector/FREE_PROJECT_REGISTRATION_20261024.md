# 무료 프로젝트 운영자 등록

기존 엄격한 자동 조회 전용 정책을 보완한다. Google 청구 조회 권한이 없는 운영자는 Google AI Studio에서 현재 서버 키 소유 프로젝트의 Free Tier·청구 미연결을 직접 확인하고 프로젝트 ID와 명시적 체크로 등록한다. 프로그램은 확인되지 않은 프로젝트를 대신 무료라고 인증하지 않는다.

등록은 관리자 인증·기존 요청 제한을 거친다. 10분 서명 challenge를 현재 공급자·키·모델에 결합하고, ADMIN_SESSION_SECRET으로 서명한 30일 프로필을 Secure/HttpOnly/SameSite=Strict, /api/admin/inspector 전용 쿠키에 저장한다. 데이터베이스·localStorage에 키나 등록 자료를 쓰지 않는다. 서명·키·모델 변경·만료는 무효화한다. 이 브라우저에 한정하며 다른 기기에는 별도 등록이 필요하다. 운영자가 등록을 해제할 수 있다.

실행 때 실제 청구 조회가 성공하면 그 결과가 우선한다. 청구 연결 감지는 등록이 있어도 차단하고 쿠키를 삭제한다. 조회 권한이 없거나 일시 실패한 경우에만 유효한 운영자 등록을 사용한다. 무료 지원 모델·요금 검토 유효기간·기존 점검당 호출 제한·429 처리·명시 요청·재시도 규칙은 유지한다. 유료 승인 경로는 추가하지 않는다.

UI는 '운영자 확인'과 '청구 미연결 자동 조회'를 구분한다. 실제 무료 잔량·청구액을 계산한 것으로 표시하지 않는다. 외부 Google 설정 변경을 자동 조회 없이 즉시 감지하거나 무과금을 보증할 수는 없다. 전용 무료 프로젝트 사용, 외부 청구 설정 변경 권한 제한을 권장한다. 요금표 검토 만료도 운영자 등록으로 우회하지 않는다.

## 사용 순서
1. 사진점검의 '무료 프로젝트 최초 등록 · 운영자'를 펼친다.
2. Google 프로젝트 상태 링크에서 현재 서버 키의 프로젝트가 Free Tier이고 청구 미연결인지 확인한다. 결제 설정을 활성화하지 않는다.
3. 프로젝트 ID를 입력하고 확인 체크 후 등록한다. 이것은 결제 승인이 아니다.
4. 비용 안내가 '운영자 확인'으로 갱신되면 사진 분석을 사용할 수 있다. 이후 사진마다 등록을 반복하지 않는다.

운영자 확인이 실제로 수행되기 전에는 자동 등록하지 않는다. 검증은 합성 키·프로젝트로만 수행하고 실제 고객 사진의 새 AI 전송은 하지 않는다.
