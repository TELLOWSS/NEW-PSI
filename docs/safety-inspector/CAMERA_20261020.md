# 직접 촬영과 즉시 확인

## 동작

사진 보관 동의 → **카메라로 바로 촬영** → 실시간 화면 → **지금 촬영** → 촬영 사진 미리보기 → **다시 촬영** 또는 **이 사진 사용**.

- 촬영·미리보기·취소는 로컬 임시 메모리만 사용하며 서버 저장/API 분석을 요청하지 않는다.
- **이 사진 사용**에서 기존 JPEG 최적화·3MiB 제한·SHA-256 증빙·사진별 설명 흐름을 사용한다.
- **촬영 사진 기기에 저장**은 카메라가 제공한 프레임을 다운로드한다. 기기 사진 앱 자동 저장이나 센서 원본 해상도를 보장하지 않는다.
- 전면·후면 전환을 지원하며, 권한 거부/미지원 시 기기 카메라 capture 입력과 기존 사진 선택을 제공한다. 네이티브 촬영창 제공 여부는 브라우저에 따라 다르다.
- 닫기·재촬영·카메라 전환·화면 숨김·늦게 도착한 카메라 요청 결과에서 트랙을 중지한다. 미리보기 URL은 교체/닫기 시 해제한다.
- HTTPS와 사용자 카메라 권한이 필요하다. Permissions-Policy는 camera=(self)이며 마이크·위치 접근 금지는 유지한다. 오디오는 요청하지 않는다.

## 검증

`PSI_CHROMIUM_PATH=... node scripts/verify-inspector-simple.mjs`가 실제 Chromium의 가상 영상 장치로 촬영/확인/재촬영/사용, Escape와 포커스 복귀, 늦은 권한 응답 정리, 거부 시 대체 입력, 사용 전 업로드 0회, 업로드 최적화 영수증 서버 검증, 390/768/1440px 화면을 확인한다.

실제 휴대폰·웹캠 하드웨어 및 운영체제의 네이티브 촬영창은 이 시험으로 검증되지 않는다.
