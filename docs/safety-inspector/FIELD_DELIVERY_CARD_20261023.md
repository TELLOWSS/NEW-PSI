# 사진과 요청 조치를 한 장으로 전달

## 사용자 흐름과 문제

사진에서 단서를 찾은 뒤 현장에 요청할 때 사진과 문구를 별도로 공유하면 수신 앱에서 일부만 남거나 문구가 다른 사진과 섞일 수 있다. 핵심 답변에서 선택한 위험 → ‘이 사진·조치 한 장으로 보내기’ → 문제/요청 조치 확인·편집 → 이미지 미리보기 → 공유창/다운로드로 연결한다. 위치·관찰 편집은 접힌 선택 항목이다. 기존 사진·문구 별도 공유도 유지한다.

## 구현 경계

- 현재 선택한 위험과 그 관찰 한 개만 카드 초안에 연결한다. 판독 확신을 안전 점수나 위반·사고 확정으로 바꾸지 않는다. 자동으로 선택된 ‘수용’ 라디오를 현장 검증 증명으로 쓰지 않고 ‘AI 제안 기반·현장 대조 필요’를 이미지에 포함한다.
- 구체적 점검자 의견이 있으면 이를 우선하고 조치 문구는 직접 적게 한다. 미수용 AI의 위치·문제·관찰·조치는 자동 전달하지 않는다. 단서 없음/이전 형식/잘못된 연결/AI OFF는 수동 조치 입력을 요구하며 일반 조치를 임의 승격하지 않는다.
- Canvas로 사진 전체를 자르지 않고 담고 문제/위치/관찰/요청 조치를 이미지 안에 넣는다. 없는 좌표나 위험 표시를 꾸며 넣지 않는다. JPEG 3MB 이하로 제한하고, 최대 입력 길이/전체 줄바꿈/높이 초과 검증으로 조용한 잘림을 막는다. 긴 초안이 줄어들면 별도 알림을 준다.
- 편집하면 기존 미리보기를 즉시 폐기한다. 다시 생성한 파일을 명시적 클릭에서 공유하므로 파일과 문구/사용자 활성화를 유지한다. 미지원·취소·실패 시 기존 공유 결과 안내와 다운로드/문구 복사를 제공한다. 수신/조치 완료로 기록하지 않는다.
- 이미지 생성은 기기 내 처리이고 추가 AI 호출·업로드·DB/schema·의존성·환경변수 변경이 없다. 카드 생성 도구와 편집기는 사용자 진입 때만 불러온다. 닫기/교체 시 Object URL을 해제한다. 생성 파일은 자동 영구 저장하지 않으며 다운로드·공유한 사본은 앱 삭제로 회수되지 않는다.
- 전달 카드 편집은 원래 점검·전문가 검토·등록 조치·고정 보고서를 변경하지 않는다. 법령·금액·감독 사례의 조건과 기준일은 기존 탭에서 확인한다. 조건 없는 처벌액을 카드에 자동 기재하지 않는다.

## 검증 범위

내용 경계 단위 테스트, 기존 분석/보고서 회귀 및 실제 브라우저에서 선택 위험 연결·전문가 수정/미수용·API OFF/불명확·편집 후 재생성·가로/세로 사진 전체 담기·긴 문구·3MB·네 해상도·다크·다운로드·OS 공유 취소/미지원·사용자 활성화·추가 분석/업로드 없음·원기록 불변을 검증한다. OS 공유는 fixture이며 실제 수신자에게 발송하지 않는다. CI/main/운영 배포 결과는 연결 PR에 기록한다.
