# 공개 체험: 완성 보고서 미리보기와 인쇄/PDF

샘플에서 얻는 결과를 실제로 확인하도록 정적인 문서 도해 다음에 보고서 미리보기를 제공한다. 검토→담당/기한→보고서의 명시적 다음 버튼을 추가하되 모든 탭의 자유 탐색을 유지한다. 기본 담당/기한도 명시 적용할 수 있게 하며 달력 날짜를 검증한다.

보고서를 여는 순간 선택 장면, 도해, 확인 한계, 저장한 검토/전문가 의견, 적용한 담당·기한을 값으로 복사한다. 저장 전 의견과 적용 전 담당 변경은 제외한다. 검토가 없다면 미검토 예시로, 담당 적용 전이면 기본 가상 값으로 표시한다. AI 미수용 저장 시 전문가 의견만 조치로 출력하고 원래 AI 조치 예시는 제외한다. 실제 완료·승인·전자서명·법적 판정이나 법령 부과액을 생성하지 않는다. 법령 적용은 실제 점검의 기존 관련 기준에서 조건과 원문을 대조하도록 안내한다.

native dialog를 body 포털로 열고 배경 스크롤 차단·Escape/닫기·이전 포커스 복원을 제공한다. 긴 모바일 화면에서도 닫기 바를 고정한다. 보고서 모듈/CSS는 명시 열기 때 지연 로딩한다. 인쇄 중에는 공개 소개/폼/도구 대신 보고서 본문만 A4로 표시하고, 닫으면 원래 페이지로 돌아간다. 기기 인쇄창의 PDF 저장을 사용하며 완료를 확정하지 않는다. 실패는 재시도 안내로 처리한다. 인쇄한 사본은 사용자가 기기에서 관리한다.

실제 사진·Storage·DB·인증·유료 AI 호출 및 브라우저 영구 저장이 없다. 기존 실제 보고서/업무 기록을 변경하지 않는다. 샘플 본문·화면·출력 모두 가상 자료와 안전 승인 아님을 명시한다.

검증: 스냅샷 독립/저장 전 제외/미수용 우선/날짜 판정 순수 테스트. production CSP에서 안내 버튼·미리보기·저장 전/미적용 제외·인쇄 요청/실패·Escape/포커스·320/390/844 모바일 닫기·실제 PDF의 텍스트/페이지/렌더 확인. 기존 공개 체험/법령/CSV/도입안/공유/인증 경계·API0/자산 예산을 회귀 검증한다. 실제 OS 인쇄 대화상자/실기기는 별도다. 최종 CI와 main/Vercel 검증 근거는 PR에 기록한다.
