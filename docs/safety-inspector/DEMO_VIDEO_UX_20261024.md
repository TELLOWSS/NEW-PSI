## 동작과 보호 범위

- 진행 시간은 실제 경과시간이며 완료율·예상 완료시간을 꾸며 표시하지 않는다. 기존 네트워크/AI 응답 자체를 빠르게 했다는 의미가 아니다. 상태 표시에 따른 추가 AI·DB 요청은 없다.
- 보고서 기본 버튼은 미저장 입력이 있으면 범위 선택을 안내한다. `미저장 입력 제외 · 저장본으로 보고서`는 사용자가 명시적으로 선택할 때만 실행하며, 조치·담당 변경·개선사진 초안을 저장하거나 삭제하지 않는다.
- 현재 사진이 열려 있으면 저장본 전용 보고서 선택을 막는다. `현재 사진 검토 저장 · 입력으로 돌아가기`로 기존 사진 저장·검토 절차를 거친 후 초안으로 돌아갈 수 있다. 선택만 하고 저장하지 않은 새 사진은 먼저 정리해야 한다.
- 입력 복귀는 작성 중인 조치 또는 현재 페이지의 담당 변경·개선 입력에 초점을 맞춘다. 미저장 입력을 다른 조치·페이지로 옮기거나 버리지 않는다.
- 모바일 텍스트 입력 중에는 작업바를 숨긴다. 입력을 벗어난 뒤 짧게 지연해 다시 표시하여, 버튼을 누르는 중 작업바가 나타나 클릭을 가리는 현상을 방지한다.
- 분석·보관·보고서 요청의 기존 동시 실행 방지, 전문가 검토 조건, 결과 출처, 고정 보고서, 사진 보관·삭제 범위는 유지한다.

## 검증

- 초기 선택 범위와 실제 편집을 구분하는 순수 함수 테스트.
- 실제 빌드 UI + 합성 API로 영상 순서 재현: 초기 조치 진입 후 보고서 가능, 입력한 담당 보존/복귀, 기본 보고서 차단 안내, 명시적 제외 후 보고서에 미저장 담당·조치 미포함, 기존 초안 유지, 분석 1회·업로드 1회 확인.
- 지연된 합성 분석 응답에서 진행 단계 표시/중복 작업바 없음/전역 모바일 메뉴 없음/완료 후 진행 표시 해제 확인.
- 기존 조치 저장·취소, 전문가 검토, 보고서 재시도, 철근/다중 위험 법령 연결, 담당 변경·개선사진 흐름 회귀 검증. 합성 API 검증과 실제 기기 촬영·실제 AI 호출을 구분한다.
