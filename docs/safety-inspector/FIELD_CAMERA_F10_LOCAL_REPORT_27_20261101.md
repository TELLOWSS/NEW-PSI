# NEW-PSI 27차 — F10 지연 조치·재점검 현장 관리 보고서 (2026-11-01)

## 목적 및 기획 근거
- 25차 F06: 기기에 저장된 사진의 실제 파일 재검증 및 공유 안전 경계.
- 26차 F10: 후속 조치/재점검 기록을 기기에서 읽기 전용 우선순위 대장으로 분류. 26차 신규 v17 백업 형식 변경은 없음.
- 27차: 동일한 기록을 *현장 관리자가 직접 확인·정리·인쇄*할 수 있도록 **CSV 대장 및 독립 인쇄용 HTML**을 안전하게 생성. 사용자가 요구한 현실적 지연 조치·임시 통제 기록을 유지하고, 근로자 개인평가나 자동 작업 승인으로 확장하지 않음.

## 실제 구현
1. 기기 직접 점검(FIELD LOCAL)의 기존 "F10 기한별 재점검 관리 현황" 아래에 "현장 관리 보고서 만들기" 영역 추가.
2. 보고 대상 범위: **현재 필터**(초과/오늘/3일 내/예정/미정/상태 불일치/확인 완료 또는 기존 조회 필터)와 **전체 대상** 중 선택. 대상 수 및 필터 설명 표시.
3. 기본값은 담당자 실명과 자유기입 상세 미포함. 사용자가 각각 체크할 때만 담당자 이름, 임시조치 상세, 지연 사유, 점검·재점검 메모 포함. 현장·동·층·공종은 점검자 입력 그대로 유지하며, 정보가 없으면 '미기록'으로 표시.
4. CSV 다운로드: UTF-8 BOM + 한글 컬럼명, 따옴표 이스케이프, 제어문자 치환, 선행 공백·제로폭 문자 뒤의 \`= + - @\` 수식 시작 문자를 작은따옴표로 무해화. \`SHA256\` 전체값/사진 바이트는 미포함. 카테고리별 수·점검 수·조치 대상 수를 구분.
5. 단독 HTML: 네트워크/API·스크립트·외부 폰트·이미지가 없는 정적 문서로 생성. 사용자 입력은 모두 HTML escape. CSP \`default-src 'none'\`; A4 가로 인쇄 기준 CSS 포함. 사용자는 파일을 기기에 저장한 뒤 브라우저 인쇄 기능으로 종이 인쇄 또는 PDF 저장 가능. **PDF 파일을 직접 생성·실제 인쇄한 것은 아님.**
6. 보고서 생성 버튼은 현재 화면 배열만 믿지 않고 **IndexedDB를 다시 읽은 뒤** 화면의 대상·상태·원본 입력과 동일한지 비교. 변경·삭제·추가 항목이 생기면 조용히 오래된 보고서를 내보내지 않고 "기록 다시 조회" 안내. 최대 500개 조치 대상, 생성 파일 크기 제한.
7. 파일은 사용자 명시적 클릭 시에만 Blob으로 준비하며, **별도의 다운로드 링크 클릭**으로 저장 시도. 모바일에서 비동기 준비 후 자동 다운로드가 거부되는 문제를 피함. 준비된 Blob URL은 상태 변경·컴포넌트 해제 시 해제.
8. 개인정보와 업무 경계: 어떠한 외부 요청·자동 전송·담당자 통보·작업 재개 승인·기준 법규 판정도 하지 않음. 결과물은 암호화되지 않으므로 별도 접근권한·제출 검토 필수.
