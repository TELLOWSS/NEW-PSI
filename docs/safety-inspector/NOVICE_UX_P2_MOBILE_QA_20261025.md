# PSI 사진점검 초보자 UX — 3차 모바일 검증 고도화

기준: 2026-10-25 · 2차 PR #72 병합 다음 단계

## 개선된 사용자 화면

- 사진 카메라: 초보자에게 촬영 순서(카메라 허용 → 사진 촬영 → 사진 확인)를 안내한다.
- 권한 거부 또는 장치 연결 문제: 기기 기본 카메라 또는 사진첩 선택으로 안전하게 진행하도록 간단히 설명한다.
- 촬영 전에는 업로드·점검 생성·유료 AI 분석이 절대 자동 실행되지 않는다. 기존 방향 선택, 영상 스트림 종료, 사진 복사·해시·보관 동의 경계는 변경하지 않는다.

## 자동검증의 실제 범위

`.github/workflows/inspector-mobile-browser.yml`을 통해 Vite **빌드된 화면**을 실제 Chromium에서 열고 **합성 카메라·API 응답과 합성 현장 이미지**로 다음을 검사한다.

- 카메라: 320/390/844px, 가로/세로 촬영, 지원하지 않는 기기 방향, 지연 스트림 중단, 기기 카메라로 대체, 브라우저 저장 차단, 영상 트랙 종료, 추가 사진 저장·AI 호출 없음.
- 외부 회신: 관리자 세션과 구분된 수신자 탭, 링크 생성·외부 공유 호출·조치 예정/개선사진 회신, 회신 실패 후 같은 요청 ID의 안전한 재시도, 개선 전후 사진 비교, 명시적 관리자 반영, 링크 만료·차단·잘못된 토큰, 320/390/844/1440px 가로 넘침, 관리 화면에 유료 AI 호출 없음.
- 테스트 증빙은 **합성 데이터 전용**이며 짧은 기간만 보관한다. 실제 사용자의 업무 사진·이름·토큰·API 키를 조회하거나 수정하지 않는다.

## 실제 기기 검증에서만 확인 가능한 사항

Playwright의 Chromium 및 합성 카메라는 **실제 Samsung/Android 카메라 드라이버, OS 권한 팝업, 카카오톡 앱 설치/전송 여부를 입증하지 못한다**. 운영 앱에서 실제 송수신·사진 노이즈·기기별 발열/프레임·오프라인 복귀를 실측하는 것은 별도 현장 QA다.

현장 실기기 5분 점검 순서:

1. 실제 Android로 사진점검 진입 → 카메라 허용/거부 각각 정상 동작 → 한 번만 촬영/미리보기/재촬영, 사진첩 대체 확인.
2. AI를 사용하지 않은 직접 점검에서 보관 동의 전 전송 없음, 동의 후 저장과 기록 이어보기를 확인.
3. 합성된 내부 시험 기록으로 조치 요청 링크를 생성, 카카오톡 실제 채팅창에서 사용자가 직접 전송을 눌렀는지 확인. 수신자 계정 로그인 없이 3종 회신 가능한지 확인.
4. 동일한 개선사진을 담당 관리자가 전후 비교·현장 재점검 후에만 완료로 변경하는지 확인.
5. 보고서 사진 준비 중 인쇄 불가, 사진 누락 시 경고와 명시적 선택, 인쇄된 PDF의 사진·법령 내용/범위를 확인.
