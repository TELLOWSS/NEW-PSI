# 사진점검 간편모드 구현 · 2026-10-20

기준: 보강 기획서 v1.1, 기존 main 84911efe. 전용 설치의 관리자 인증 경계를 유지한다.

## 제공하는 흐름

기본은 간편모드다. 사진 선택/PC 붙여넣기 → 사진별 부연설명(선택) → 설명 저장 → 수동 ChatGPT 또는 선택한 서버 API 분석 → 전문가 확인 → 다음 사진 또는 보고서 작성자료 완료 → 별도 보고서 작성 순서로 진행한다. 질문별 현장확인은 기본 접힘이며 미응답은 미확인으로 남는다. 상세모드의 법령·개선·재점검 기능은 유지한다.

- 파일은 기기에서 JPEG 사본으로 변환한다. 기본 긴 변 2,048px, 선택 3,072px, 품질 .82에서 시작하며 3MiB를 초과할 때만 제한적으로 낮춘다. 작은 사진을 확대하지 않는다. 기기 원본을 수정하지 않는다. 웹 촬영의 갤러리 자동 저장은 보장하지 않는다.
- 기기 측 원본 크기·해상도, 업로드 크기·해상도·품질·SHA-256·변환 버전을 영수증으로 제공한다. 서버는 실제 JPEG SOF 해상도·바이트·해시 및 EXIF 제외를 검사한다. 표준 ICC 색상 프로필은 허용한다. 원본 수치는 기기 측 진술이며 원본 백업/진본성 인증이 아니다.
- 기존 사진은 재압축·해시 교체하지 않는다. `optimization_receipt=null`은 기존 업로드다. 기존 `source_photo_sha256` 계약은 선택한 등록 파일을 대조하며 새 자료는 별도 `uploaded_asset_sha256`와 `source_kind=optimized`로 명확히 구분한다.
- 사진 영역의 Ctrl+V/⌘V는 이미지 파일만 취급한다. 설명·JSON 텍스트 붙여넣기를 가로채지 않는다. 복수 이미지 클립보드는 첫 사진만 첨부한다. 사진 복사는 실제 `image/png` ClipboardItem을 사용한다. ChatGPT에 이미지를 먼저 붙여넣고 프롬프트를 복사해야 한다. PNG 변환 파일은 JPEG와 바이트/해시가 같지 않다.
- 사진 설명 수정은 해당 분석·검토·답변을 해제한다. 공통 현장 정보 변경은 모든 분석·검토를 해제한다. 확인은 서버 시각·전용 관리자 주체로 기록한다. 개인 전자서명은 아니다.
- 자료 완료는 수용한 사진 ID와 점검 버전을 고정한다. 미검토 사진 제외는 사용자에게 확인한다. 완료 이후 편집은 완료 표시를 해제한다. 기존 고정 보고서는 변경하지 않는다.
- 보고서는 고정된 사진 해시와 현재 비공개 자산의 해시를 대조한다. 최대 두 장씩 불러오며 이미지 디코딩 완료 전 인쇄를 막는다. 누락 시 명시적으로 표시하고 누락 인쇄에 확인을 받는다. 만료 URL을 보고서 식별자로 보관하지 않는다.

## 저장 공간과 삭제

사진은 Supabase 비공개 Storage, 설명·분석·이력은 Postgres에 저장한다. 앱 소스/브라우저 영구 저장소에 사진 Base64를 저장하지 않는다. 썸네일·서버 PDF·클립보드 PNG를 클라우드에 추가 저장하지 않는다.

현재 프로젝트 Storage 합계를 표시한다. 700MB 주의 / 800MB 정리 권장 / 900MB 업로드 차단을 안내하며 서버는 진행 중 예약 용량까지 함께 검사한다. 무료 조직 전체 잔여량·월 전송량을 확인한 것처럼 표시하지 않는다. 삭제해도 이미 사용한 전송량은 복구되지 않는다. 자동 과금 전환·무통보 삭제가 없다.

삭제 단위는 **해당 점검 전체**다. 개별 사진 선별 삭제는 제공하지 않는다. 화면에 전체 사진·고정 보고서·저장 이력 영향 범위를 표시하고 전체 점검번호 입력과 최종 확인을 요구한다.

1. 사진 파일만 삭제: 모든 보관 파일과 미연결 업로드를 Storage API로 제거한다. 설명·분석·기존 보고서 스냅샷은 남으며 사진 삭제 상태로 편집/업로드를 잠근다. 이후 별도의 전체 삭제가 가능하다.
2. 사진·관련 기록 전체 삭제: 파일 제거 확인 후 evidence·reports·events·inspection을 좁은 서버 전용 RPC로 정리한다. 일반 service_role DELETE 권한은 계속 없다. 최소 영수증과 재생성 방지 tombstone만 남긴다.

삭제 시작 후 신규 업로드 예약·DB 수정·새 사진 링크 발급을 차단한다. 진행 중 작업이 끝나지 않으면 완료로 표시하지 않는다. Storage 목록·새 다운로드·삭제 전 서명 링크·DB 잔존을 검사한다. 링크 검증 실패는 약 2분의 유효기간 대기 후 재검증할 수 있다. 삭제 전용 요청은 서버의 90초 상한보다 긴 95초까지 기다려 여러 사진 처리 중 화면이 9초에 먼저 중단되지 않게 한다. 중간 실패 시 미완료로 남고 남은 파일만 재시도한다. 삭제에 바이트 산정을 위한 사진 전체 다운로드를 추가하지 않는다.

완료 영수증은 관리 경로 잔여 0건의 범위를 뜻한다. 기기 원본·다운로드한 PDF·외부 ChatGPT 대화·OS 클립보드·외부 캐시/제공자 내부 물리 저장을 지웠다는 뜻은 아니다. 서버가 강제 종료되어 미완료 작업 예약이 남으면 자동 만료를 성공으로 간주하지 않으며 운영 확인이 필요하다.

## 사진점검 API

기존 OCR 유료 모드와 별개인 점검별 스위치다. OFF에서는 사진 분석을 전송하지 않고 ON 후에도 '이 사진 분석'을 명시적으로 눌러야 한다. 업로드·새로고침은 공급자 호출을 만들지 않는다. 외부 전송 동의를 별도로 확인한다. 준비 중 설정 변경/OFF/삭제도 다시 검사하며 이미 전송된 요청의 취소·환급은 보장하지 않는다.

- 기본 제공자/모델은 기존 프로그램의 Gemini / `gemini-3.5-flash-lite`. 서버 Gemini 키가 있을 때만 준비됨으로 표시한다. 브라우저 localStorage의 기존 키를 자동 전송하지 않는다.
- `PSI_INSPECTOR_AI_PROVIDER=gemini|openai`, `PSI_INSPECTOR_AI_MODEL`로 명시적으로 바꿀 수 있다. Gemini는 `GEMINI_API_KEY`/`GOOGLE_GEMINI_API_KEY`/`GOOGLE_API_KEY`, OpenAI는 `OPENAI_API_KEY`를 서버에서만 읽는다. OpenAI에는 모델 설정이 필수다.
- 점검당 최대 20회 시도, 요청당 최대 출력 4,096토큰. 자산·설명·모델·프롬프트 버전 지문으로 중복 요청을 차단한다. 실패/시간 초과도 자동 재시도하지 않는다. 이는 호출·토큰 상한이며 화폐 기준 청구 상한은 아니다. 공급자 예산 설정은 별도다. 다른 유료 모델로 자동 대체하지 않는다.
- 공급자 결과는 엄격한 표준 계약으로 검사하고 `PAID_API_APPROVED` 출처는 서버만 기록한다. 자동 승인·법령 위반 확정은 없다. 키/공급자 원문 오류를 클라이언트에 반환하지 않는다.

## 검증과 적용 범위

- PostgreSQL(PGlite): 브라우저 역할 RPC/데이터 접근 거절, 일반 삭제 권한 거절, 삭제 중 신규 쓰기 차단, 진행 중 작업·Storage 잔존 시 완료 거절, 전체 스냅샷 정리, tombstone 재생성 방지, 사진만 삭제 후 전체 삭제, 중복/20회 제한.
- API: 전문가 확인 시 선택 질문 미응답 허용, 자료 완료 위조 차단, 미확인 자료 완료 거절, 삭제 상태 링크 발급 차단, 삭제 범위 확인, 키 비노출, 공급자 호출 지연 재확인.
- Chromium 실제 사진 처리: 합성 JPEG 14,468,675B(4,032×3,024) → 1,496,741B(2,048×1,536), 약 89.65% 감소. 원본 해시 동일. 업로드 영수증은 서버 검사 함수를 통과했다. 합성 진단 사진의 측정값이며 일반 사진에 같은 절감률을 보장하지 않는다.
- 실제 PNG 클립보드 기록과 읽기, 사진 영역 붙여넣기, 사진별 설명 프롬프트 반영, 선택 질문 접힘, 미확인 사진 제외, 이미지 포함 PDF, 390/768/1440px 가로 넘침 검사를 수행한다. API 네트워크는 격리 fixture이며 실제 사용자 자료를 만들거나 삭제하지 않는다.
- 운영 DB 확장은 기존 데이터 수정을 포함하지 않는다. 적용 후 사진 2개·280,187B가 유지되고 삭제 작업 0건임을 재확인했다. 신규 표에는 의도적으로 브라우저 RLS 정책이 없으며 service_role/좁은 RPC만 사용한다. 신규 보안 WARN은 없다.

현재 점검당 **20장** 제한과 Base64 서버 경유 업로드를 유지한다. 기획서의 후속 50장 일괄 선택·사진별 DB 분리·다량 대기열·Storage 직접 업로드는 이 릴리스에 포함하지 않는다. 실제 Windows Edge·휴대폰 기기 시험 및 과금 공급자 실요청은 별도 확인 대상이다. 법령 검증·개선조치 완료·최종 승인은 사진 검토와 별개다.
