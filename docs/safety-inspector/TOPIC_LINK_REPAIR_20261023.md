# 선택 위험과 법령·사례·동향 연결 복구

## 실제 재현과 원인

최근 저장된 설명 없는 사진 분석을 읽기 전용으로 대조했다. 핵심 위험은 돌출 철근과 사람의 접촉에 따른 찔림이었다. 이전 연결기는 `철근 단부`의 `단부`만으로 `opening`(개구부·단부 추락)을 골랐고, 사례·동향도 그 주제를 사용했다. 전체 사진의 배경 거푸집·통로 및 AI 검색어로 먼저 만든 후보 목록에 선택 위험을 다시 교집합하는 구조도 있었다. 이 때문에 실제 위험의 기준이 후보에 없으면 연결되지 않거나 배경 주제로 흘렀다. 이전 테스트는 전선/개구부처럼 명확한 검색어를 썼고 이 동음·문맥 사례를 포함하지 못했다.

## 수정

1. 현재 선택 위험의 문제 설명 → 사고 경로 → 그 위험에 연결된 이상 관찰 순으로 기준 후보를 찾는다. 가설·일반 조치·다른 관찰·힌트·AI 전체 검색어로 대체하지 않는다. 예전 후보 목록에 없는 실제 주제도 현재 검증 자료에서 찾는다. 연결 관찰이 없거나 지원하지 않는 위험은 빈 연결로 남긴다.
2. 철근·전선·배관 등 부재의 끝과 슬래브·통로의 끝을 구분하고 전기 외함 덮개를 개구부 덮개로 해석하지 않는다. 철근 노출·돌출·끝단·찔림은 대상과 문맥을 함께 확인한다. 이 규칙이 모든 자연어를 완전히 이해하는 것으로 주장하지 않는다.
3. 모든 탭에 현재 위험과 연결 기준을 표시하고 동일한 참조 집합을 사용한다. 직접 고르는 기준은 별도 접힌 항목과 ‘자동 연결 아님’ 표시를 둔다. 위험을 바꾸면 수동 선택도 초기화한다.
4. 사례·관련 동향은 현재 주제만 필터링한다. 공통 연간 감독 방침은 선택 펼치기로 분리하고, 주제가 없으면 다른 위험의 사례·공통 동향으로 대신하지 않는다. 같은 위험 주제도 동일 사건·설비·조문이라는 뜻이 아님을 표시한다. 건설현장 자료를 제조업 참고보다 우선 배치한다.
5. 저장 결과 다시 열기·결과 복사·새 보고서의 분석 자료 기준 선택도 공통 함수로 처리한다. 점검자가 직접 쓴 상황 설명은 보고서의 별도 자료 범위에 유지하며 이를 AI가 사진에서 확인한 사실로 바꾸지 않는다. 저장된 분석은 재호출하지 않는다. 이미 생성된 고정 보고서의 snapshot/해시는 변경하지 않는다. 새 연결을 담으려면 새 보고서를 작성한다.

## 돌출 철근 근거 보강

- 국가법령정보센터: [콘크리트공사 표준안전 작업지침](https://www.law.go.kr/LSW/admRulLsInfoP.do?admRulSeq=2100000268994), 고용노동부고시 제2025-78호, 2025-12-01 시행. 제16조제3호는 조립 철근 접촉에 따른 찔림·화상 등의 위험 방지를 다룬다. 제1조와 고용노동부 개정 발표는 법 제13조에 따른 지도·권고 기술 지침임을 명시한다. 원문 대조 2026-10-23.
- [고용노동부 개정 발표 및 전문 PDF](https://www.moel.go.kr/common/downloadFile.do?bbs_id=12&bbs_seq=18672&file_ext=pdf&file_seq=20251200155): 전문 PDF의 제16조제3호 및 지도·권고 성격을 직접 대조했다. 이를 근거로 개구부 추락 벌금이나 철근캡 건별 과태료를 자동 부여하지 않는다. 새 카드의 sanctions는 빈 배열이며 실제 적용 법령·위반 요건 별도 확인 문구를 제공한다.
- [고용노동부 2023-07-05 사고·감독 예고 발표](https://www.moel.go.kr/news/enews/report/enewsView.do?news_seq=15224): 슬래브 파손·타설 장비 전도와 함께 철근 찔림이 발생한 사례다. 단순 통행 접촉과 사고 경로가 다르다고 표시한다. 발표 당시 작업중지·수사·일제감독 계획이며 감독 결과·확정 판결·개별 처벌액으로 표시하지 않는다.
- 관련 동향에는 위 2025-12-01 기준 개정 자료를 연결한다. 2026년의 다른 화재·폭발 동향을 돌출 철근의 최근 사례로 바꾸지 않는다. 기존 다른 법령 자료의 전체 원문 검토일을 일괄 최신화하지 않는다.

## 호환·검증

DB/schema·저장소·환경변수·공급자/모델·분석 fingerprint/requestId를 변경하지 않는다. 새 법령 카드의 선택적 검토일/금액 설명 및 사례 분류는 기존 JSON 참고자료에 추가하는 필드다. 이전 고정 보고서는 그대로 읽는다. 현재 사용자 기록에 쓰기·삭제·재분석은 하지 않는다.

철근 끝/슬래브 끝, 전기 덮개/개구부 덮개, 배경 주제 혼입, 이전 후보 누락, 미지원 위험, 위험 전환·수동 선택 초기화, API OFF/기존 저장 결과 이어보기·새 보고서 및 4해상도/다크를 단위·브라우저에서 검증한다. 운영에선 저장된 실제 문제 사진의 세 탭을 읽기 전용으로 열어 원기록 불변과 유료 분석 호출 0을 확인한다. 실행 결과와 main/배포 정보는 연결 PR에 구분해 기록한다.
