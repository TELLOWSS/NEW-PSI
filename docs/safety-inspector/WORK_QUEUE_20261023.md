# 사진점검 다음 할 일·사진 분류·조치 전달 고도화

## 문제와 목표

현장 전문가는 여러 사진을 모은 뒤 남은 검토와 미결 조치를 빠르게 찾아야 한다. 기존 사진 목록은 최대 20장을 한 번에 펼치며, 등록 조치는 세 건씩 보지만 상태·담당·기한으로 좁힐 수 없었다. AI 분석 없는 개선사진까지 일반 설명 자료로 표시되어 사진마다 다시 확인해야 할 일처럼 보일 수 있었다.

이번 범위는 **현재 열어 둔 점검 한 건**의 저장된 자료를 정리하는 것이다. 전체 현장·조직의 작업함이나 새 업무 승인 체계를 만들지 않는다. 사진·조치 원문·진행 상태·작성 당시 보고서를 바꾸지 않는다.

## 구현

- 사진 사이 화면에 AI 검토 대기, 완료 검토 요청, 기한 지난 미결을 표시한다. 완료 검토 요청과 기한 지남은 겹칠 수 있으며 합산 완료율을 만들지 않는다.
- 첫 AI 검토 대기 사진을 한 번 눌러 저장된 이미지·분석으로 이어간다. 자동 분석·검토 수용·조치 완료를 실행하지 않는다.
- 사진 목록은 전체/AI 검토 대기/설명 자료/전문가 의견/개선 증빙으로 분류하고 다섯 장씩 보여준다. 여섯 장 이상이면 사진 목록은 기본 접어 두고 다음 할 일을 먼저 보여준다. 현재 사진 작업 중에는 이전 사진 열기를 계속 제한한다.
- 조치에 연결된 개선사진에 AI 분석이 없으면 AI 검토 대기로 세지 않는다. 해당 사진에 실제 미검토 분석이 있으면 검토 대기가 우선한다. 수용 거절은 전문가 의견으로 표시한다.
- 등록 조치는 전체/미조치/완료 검토 요청/기한 지남/재점검 확인 분류와 조치명·담당 검색, 등록순/기한순을 제공한다. 기본 등록순과 세 건 단위 페이지는 유지한다. 조치가 세 건 이하면 분류 도구를 접어 두어 첫 사용 화면을 단순하게 유지한다.
- 기한순은 미결 우선, 유효한 빠른 날짜 우선이며 같은 날짜의 등록 순서를 유지한다. 이미 재점검 확인한 조치를 미결·지연으로 보내지 않는다.
- 분류·검색에 맞는 미결 조치 전체를 요청문 복사·공유 미리보기로 전달한다. 현재 세 행만이 아닌 다른 페이지의 일치 조치도 포함함을 표시한다. 기존 전체 미결 전달은 유지한다.
- 결과가 없으면 전체로 돌아갈 수 있다. 분류·검색·정렬로 작성 중인 개선사진/재점검 행이 사라질 때는 확인 후 이동하며 취소하면 입력과 선택을 유지한다.

## 날짜·정보 경계

기한 비교는 한국 달력 날짜와 기기 시계 기준이다. 오늘 기한은 지연으로 세지 않는다. 유효하지 않은 날짜·이미 확인한 조치는 지연에서 제외한다. 이는 법정 기한·서버 승인 시각 판정이 아니다. 날짜를 표시하고 기기 내 분 단위/화면 복귀 때 갱신하며 서버 polling은 하지 않는다.

개선 입력 중에는 조치 목록의 기준일을 잠시 고정한다. 자정 변경으로 행이 들어오며 편집 중인 행이 다른 페이지로 밀려 사라지는 것을 막는다. 저장·명시적 이탈 후 최신 날짜를 적용한다.

사진 분류는 화면 표시만 바꾼다. 보고서 포함 여부·저장된 검토·법적 판단·사진 보관/삭제 범위를 바꾸지 않는다. AI 미검토 사진이 없다는 것은 개선 완료나 안전 승인이 아니다. 사진·기록을 다른 곳에 복제하지 않고 현재 받은 메타데이터만 계산한다.

## 검증

- 순수 로직: 한국/UTC 날짜 경계, 오늘/지연/잘못된 날짜, 완료 검토 요청과 확인 완료 구분, 설명·개선 증빙·미검토 분석·수용 거절 구분, 검색·정렬·원문 불변.
- production 번들+CSP: 합성 사진 16장·조치 8건의 분류/페이지, 대기 사진 열기, 조치 검색·정렬, 빈 결과 복구, 분류한 요청문/공유 미리보기, 입력 소실 확인의 취소/수락, 자정 중 목록 보호, 320/390/768/1440 및 다크 모드.
- 기존 간편·상세·보고서·삭제·전후 사진 흐름 회귀 및 전체 CI. 실제 배포 결과는 연결 PR에 기록한다.
- UI 시뮬레이션은 fixture이고 실제 현장 판단·실기기 카카오톡 수신 검증으로 주장하지 않는다. 이번 범위에는 신규 API·DB schema·유료 AI 호출·의존성·환경변수 변경이 없다.

오프라인 보관·50장 이상 대용량·다중 현장 권한·실시간 법령 동기화·개인 승인·정식 발행은 이전 후속 목록과 같이 별도 범위다.
