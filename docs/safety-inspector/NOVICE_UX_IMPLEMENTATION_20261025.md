# 사진점검 초보자 UX 개선 구현 (2026-10-25)

기준 기획서: `NEW_PSI_사진점검_초보자UX_고도화_기획서_20261025.md` (사용자 제공).
대상: 사진점검 간편 화면. 기존 저장/검토/조치/보고서/인증/비용·개인정보 계약을 변경하지 않는다.

## 이번 구현 범위

- 사진점검 진입 설명을 쉬운 언어로 바꾸고, 촬영 시작 CTA를 **사진 찍고 점검하기**로 통일. 갤러리/PC 선택은 보조 행동이다.
- 사진 선택 → 위험 확인 → 현장 검토 → 조치·보고의 4단계를 화면에 표시한다. 이 단계는 **안내용**이며 실제 분석·검토·승인 기록을 새로 만들지 않는다.
- 기술·비용·분석 방식 관리를 펼치기 항목으로 이동하고, AI 연결 불능·미확인·사용 중지 시 **AI 없이 직접 점검**이라는 복구 버튼을 제공한다. 사진 보관 동의가 없으면 진행되지 않는다.
- 실제 진행 중인 작업 문구에서만 사진 준비·점검 저장·위험 확인·결과 준비 단계를 파생한다. 가짜 진행률/완료시각/재시도·중복 요청은 없다.
- 사진 목록 상태에서 저장된 전문가 검토·검토 대기·미결 조치 수를 읽기 전용으로 보여 주고, 보고서가 개선 완료를 뜻하지 않음을 안내한다.
- 조치 공유는 공개 범위 → 직접 공유 → 회신 확인 3단계로 안내한다. 공유 링크가 생성됐더라도 전송 완료로 표시하지 않는다. 기기 기준 만료 링크는 발송 버튼을 감춘다. 서버측 권한 및 만료 판정이 최종이다.

## 의도적으로 변경하지 않은 계약

- 외부 AI 호출 동의·명시적 실행·무료 보호 및 서버 공급자 상태
- 기존 사진 최적화/저장 3MiB·점검당 20장, 원본 보존, SHA 무결성
- 분석 결과와 점검자 의견·현장 검토의 구분, 불수용 의견, 미저장 보호
- 승인 없는 개선 완료/정식 발행/전자서명 금지
- 조치 공유의 접근 권한/토큰/수신 응답 계약, 보고서 스냅샷
- SMART TBM과 NEW-PSI는 별개 프로그램

- 기존 `inspectorResultJourney`, `inspectorFriendlyRecovery`, `inspectorActionShare` 및 320/390/844/1440px 브라우저 회귀는 CI 후 확인할 것.
