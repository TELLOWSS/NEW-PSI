# NEW-PSI 28차 — F10 지연 조치 현장 인계 초안 (2026-11-01)

## 기획 목표
27차 CSV·A4 보고 기능을 현장에서 실제 전달 전에 읽고 확인할 짧은 인계문으로 확장한다. 즉시 조치가 어려운 경우 임시 접근통제·일정·담당 미기록 등 확인할 사항을 놓치지 않되, 프로그램이 실제 작업중지·해제, 지연 사유 사실확정 또는 안전 승인·통보를 수행했다고 오해하지 않도록 한다.

기존 F10은 점검자 기기 IndexedDB 기록이 기준이고, 조치별 재점검 이력·예정일·임시조치 메모가 이미 있다. 새 저장 스키마와 서버 전달 경로는 만들지 않는다. 26차 기한 우선순위 + 27차 관리 보고서 데이터 구조를 재사용한다.

## 구현: 인계 대상의 포함 기준
- 26차 우선순위 분류 중 **상태 불일치, 기한 초과, 오늘 확인, 3일 내 확인, 일정 미정**을 인계 대상으로 포함.
- **이후 예정**이라도 담당자 *기록이 없는* 항목은 별도로 포함. 이후 예정이며 담당자 기록이 있는 항목, 사람이 확인 완료로 기록했고 최신 미완료 재점검과 상충하지 않는 항목은 제외.
- 최신 미완료 재점검과 수동 완료 기록의 시간 순서 판단은 26차 로직 그대로 적용. 급박한 위험을 자동 예측한 목록이 아니라 *업무상 확인 대장*이다.
- **담당 미기록/임시조치 미기록**을 각각 건수와 표시 문구로 분리한다. 실제 담당자가 없거나 실제 조치가 미실시됐다고 단정하지 않는다.
- 최대 40개 인계 대상을 허용. 초과 시 조용히 앞 40개만 내보내지 않고 필터를 사용해 나눠 인계하라고 안내. "전체 대상"/"현재 상태 필터" 선택.
- 확인일은 기기 로컬 날짜 기준이며 자동 현장 위치나 촬영 시각을 확정하지 않는다.

## 실제 사용 흐름
1. 현장 점검의 F10 관리 영역에서 **인계 대상 1/N**과 누락된 기록 건수를 먼저 확인.
2. **인계 문구·A4 인계표 준비**를 누르면 최신 기기 IndexedDB를 다시 읽어, 현재 목록의 관련 점검내용·조치계획·상태·재점검 이력·현장정보와 대조. 다른 탭의 수정이 있으면 저장 대신 다시 조회 안내.
3. 인계 문구(작업 항목, 분류, 확인일, 상태, 확인할 기록)를 확인한다.
4. 복사 버튼은 사용자 탭으로만 동작하며, 브라우저 클립보드가 제한되면 문구를 직접 선택·복사한다. **담당자에게 자동 전송하지 않는다.**
5. A4 가로 HTML 인계표는 사용자 별도 링크 탭으로 기기에 저장한다. 외부 이미지/스크립트/네트워크 호출 없는 HTML/CSP, 모든 입력 HTML escape.
6. 기본 출력에는 담당자 실명, 연락처, 자유기입 상세·지연 사유, 사진 바이트 및 전체 SHA-256을 포함하지 않는다. 현장명·동·층·공종·조치 제목은 점검자가 입력한 값이므로 대외 공유 전에 확인한다.
7. 기기 기록/필터/조회 범위가 바뀌면 준비된 인계문·Blob URL은 해제하여 오래된 인계 내용을 복사하거나 저장하지 못하게 한다.
8. 한 점검에 여러 개별 조치가 있다면 대상 수와 실제 점검 기록 수를 구분. 기존 27차의 전체 CSV·A4 보고서는 그대로 유지한다.

## 안전·개인정보 경계
- 인계 초안은 **전달 확인서·수신 기록·현장 안전상태 인증서·공사 재개 승인서가 아님**. 사용자 동의 없이 외부 API 호출/AI 분석/메시지 발송/근로자 개인평가 금지.
- 임시 안전조치가 미기록이라고 곧바로 미조치 현장 또는 법 위반으로 판정하지 않음. 급박한 추락·무너짐·낙하 위험은 예정일까지 기다리지 않고 현장 접근통제·작업중지 필요성을 검토하도록 안내.
- 보안 기능: 복사 문구는 수식 시작기호를 이스케이프하며, A4 HTML은 외부 리소스를 허용하지 않는 CSP와 HTML escape를 적용한다. Android/Excel/PDF/카카오톡 외부 공유 동작은 실제 기기 후속 검증 사항으로 남긴다.
