# 분석 오류 복구와 무료 상태 동기화

사진 분석 오류의 다음 동작을 구분한다. 공급자가 명시적으로 재시도 가능하다고 응답한 경우에만 직접 재시도 버튼을 제공한다. 인증·권한·요청 오류는 입력·연결 설정 확인으로 안내한다. 통신 응답 유실이나 중복 요청 차단은 먼저 저장 결과를 조회한다. 결과 조회는 AI를 호출하거나 사진을 재업로드하지 않는다.

저장 결과를 가져올 때 선택 사진의 ID·해시와 설명을 대조한다. 삭제 중이면 작업을 잠그고, 다른 기기에서 설명이 바뀌었다면 로컬 입력과 서버 기록을 덮어쓰지 않는다. 서버에 결과가 아직 없으면 그 사실을 안내하며 자동 재분석하지 않는다. API 호출 여부가 불명확한 요청의 기존 중복 방지 ID도 유지한다.

작동 시험의 오류 응답은 구조화된 code/cost를 유지하여 청구 연결·무료 상태 차단을 메인 화면에도 즉시 반영한다. 이 변경은 실시간 청구 조회 권한을 새로 연결하지 않는다.

검증은 합성 API를 사용하며 고객 사진을 추가로 외부 전송하거나 업무 데이터를 수정하지 않는다. 검증 결과와 운영 배포 정보는 연결된 PR에 기록한다.
