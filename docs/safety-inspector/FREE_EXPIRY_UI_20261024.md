# 오래 열린 화면의 무료 확인 기한

서버는 실제 AI 요청마다 무료 보호를 재검증하지만, 이전 화면은 최초 조회 당시의 allowed 상태를 유지할 수 있었다. 간편모드와 상세모드에 로컬 기한 확인을 적용한다. 등록 및 모델 요금 검토 기한 중 먼저 도달하는 시각을 따르며, 3일 전에 갱신 경고를 표시하고 만료 시 사진 분석 버튼을 차단한다. 운영자 등록의 기한이 없거나 잘못된 경우도 사용 가능으로 표시하지 않는다. 유료 연결 등 기존 차단 사유는 만료 메시지로 덮지 않는다.

긴 setTimeout 한계를 넘는 기한은 나눠 예약한다. 화면 복귀·포커스 때도 기한을 다시 계산한다. 이 동작은 네트워크 상태 조회, 등록 갱신, 사진 전송, AI 호출, 서버 쓰기를 하지 않는다. 실제 API 허용 여부는 여전히 서버의 검증이 최종 기준이다. 로컬 기한 표시는 기기 시각을 사용한다.

상태 다시 확인은 최신 서버 상태를 가져올 뿐 등록·요금 검토 기한을 연장하지 않는다. 만료한 등록의 이전 challenge는 클라이언트에서 재사용하지 않는다. 서버 범위 등록의 만료를 계속 '연결된 무료 프로젝트'로 안내하지 않으며 기한 표시는 한국 시간과 시각을 포함한다. 잘못된 날짜는 화면 예외 대신 확인 필요로 표시한다.

합성 브라우저 시계로 등록·요금 검토 만료, 사전 경고, 분석 버튼 차단, 갱신된 서버 응답의 명시적 재조회와 320/390/844/1440 너비를 확인한다. 만료 전후 자동 요청이 없고 실제 등록·추론·업무 쓰기가 없음을 대조한다. 서버 등록과 AI 모델 설정은 바꾸지 않는다.
