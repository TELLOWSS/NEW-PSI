# 사진점검 실제 작동 확인 개선

실행 경로는 사진 선택·최적화 → 보관·설명 저장 → 무료 보호 확인 → 외부 이미지 분석 → 위험별 법령 연결 → 점검자 검토 → 보고서이다.

운영 프런트엔드의 합성 시나리오 6개(MSDS와 작업 상태, 사진·설명 충돌, 판독 한계, 촬영, 붙여넣기, 보고서 저장 재시도)를 확인했다. 이 검증은 공급자 응답을 대체하므로 실제 AI 추론 성공을 입증하지 않는다. 기존 비공개 사진의 외부 전송·시험 레코드 생성은 자동 승인 검토에서 거부되어 중단했다.

기존 연결 표시는 설정 존재만 확인한다. 이를 보완해 관리자에게 합성 이미지 작동 시험을 제공한다. 서버에 고정된 64×64 빨강·파랑 카드만 보낸다. 실제 사진 분석과 동일한 공급자 요청·구조화 응답 경로를 사용하며 관찰의 두 색상과 응답 스키마를 검증한다. 고객 사진·점검자료 조회 및 업무 기록 생성은 없다. 무료 보호 확인이 먼저 통과해야 하며 서버 전체에서 60초당 1회로 제한한다. 자동 실행·자동 재시도·유료 모델 대체는 없다. UI는 API 안내를 펼쳤을 때만 나타나고 API OFF 또는 무료 보호 차단 시 실행할 수 없다.

400 요청 형식, 401 인증, 403 권한, 404 모델, 429 공급자 한도를 구분한다. 공급자 원문이나 키는 노출하지 않는다. 합성 시험 성공은 이미지 입력과 구조화 응답 작동의 증거이며 현장 위험 판독 정확성, 실시간 법령 갱신, 잔여 무료량을 보장하지 않는다.

검증 결과와 운영 배포 정보는 연결된 PR에 기록한다. 기존 법령·사례는 검토된 정적 자료이며 이 변경으로 실시간 검색이 추가되지는 않는다.
