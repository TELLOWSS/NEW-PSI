## 5. 현장용 수동 점검 시나리오 (개인정보 없는 합성 사진으로)
1. Android Chrome 및 Samsung Internet의 새 사용자 브라우저에서 준비된 기기 점검 진입 → 사진 촬영·권한 취소/거부 → 촬영 대체 기능 확인.
2. 가상의 발판 이격 지적을 저장 → 임시 출입통제 기록 → 담당자 및 목표 기한 설정. 즉시 시정 불가와 임시조치는 각각 구별되도록 확인.
3. 재점검에서 '조치 지연'과 다음 확인 예정일 기록. 목표 기한을 바꾸고 사유 입력을 누락하면 저장이 막히는지 확인.
4. 조치후 사진을 연결한 뒤 조치 완료가 자동으로 선택되거나 작업 재개가 자동 승인되지 않는지 확인.
5. 기기에서 보고서 내보내기 → 기본값에서 담당자 이름·사유·사진 바이트가 안 나오는지 확인 → 명시적으로 경과 이력 포함 → CSV/HTML의 기한·재점검 일자 확인.
6. v17 백업을 다른 테스트 프로필/기기에서 복원하고 이력·사진 비교값 확인. 통신 연결 없이 앱 재진입 후 기록 유지 확인. Android 기기 저장소 자동 정리/권한 취소도 별도 시험.
7. 배포 후 **공식 주소**에서 이전 데이터의 열기·사진 저장·기록 복원·계도 문구를 재시험하고, Vercel 실제 연결 커밋과 대상 릴리스 커밋 일치 확인.
