# 사진 맥락·MSDS·무료 사용 보호 — 2026-10-24

## 사용자 문제와 변경

1.mp4: 개봉 시멘트 포대/분진 해석에 관련 기준 없음. 제품 단서에서 MSDS 확인으로 이어지지 않음.
2.mp4: 맥락 미입력 상태의 방호 불명확을 지적사항처럼 표현. API 연결 표시는 실제 무료·청구 상태와 무관.

- 작업 전/중/정리/보관/사용 중지/모르겠음 선택을 기존 사진 설명에 점검자 진술로 저장. 위험 진단 입력은 요구하지 않음. 변경 시 기존 분석·전문가 검토 무효화 규칙 유지.
- API·수동 공통 프롬프트: 사진 부재≠현장 부재, 분진 비산·성분·MSDS·교육 미이행 추정 금지. 작업 단계가 조치를 바꾸면 선택형 확인 한 가지만. 확신 낮음/불명확 결과는 맥락 확인 후보로 표시.
- 선택 위험의 관찰·문제·사고경로에 제품 단서가 있는 경우에만 MSDS 추가 확인. 다른 위험으로 이동 시 혼합 금지. 제품명/공급자/경고표시/자료 접근/관리요령/교육 각각 대조.
- MSDS 패널에서 기기 내 OCR·수기 정정 후 명시 버튼으로 사진 설명에 반영. OCR은 같은 사진에서만 실행, 외부 AI 호출 없음. 제품 MSDS 자동 일치 판정·자동 저장·자동 재분석 없음. OCR 결과는 임시 상태이며 설명 반영·저장 전 서버에 보관하지 않음.
- 분진 주제 추가: 규칙 제4조의2 검토 원문, 실제 심한 비산 등 적용 조건 표시. 포대 존재만으로 위반 확정/다른 위험 벌금 차용 없음. 기존 보고서 불변.
- 법령·사례·동향에 수록/검토일과 실시간 갱신 아님 표시. 관련 자료가 없으면 다른 주제로 대체하지 않음. 공식 자료 자동 수집·법령 시행일별 갱신 파이프라인은 이번 릴리스에 포함하지 않으며 후속 연결이 필요.

## 과금 보호 정책

**현재 릴리스에는 유료 허용 경로가 없다.** API 키 연결 성공, 사용자 ON, 사진 전송 동의만으로 비용 검증을 우회할 수 없다. 무료 잔여 횟수·실제 청구액은 null/확인 불가. 앱의 점검당 20회 제한은 공급자 무료 한도로 표시하지 않는다.

서버는 매 명시 분석 요청에서:

1. 설정된 공급자/정확한 모델이 검토한 무료 지원 모델인지 확인. 현재 허용 `gemini-3.5-flash-lite`만, 요금표 검토 2026-10-24, 2026-11-24 00:00 KST부터 재검토 전 차단. 별칭/유료 모델/OpenAI/검색 도구/모델 폴백 불허.
2. 전용 읽기 계정으로 짧은 OAuth 토큰 발급. 고정된 Google URL만 사용, redirect 거부, 전체 조회 6초 제한, 원시 오류·키·토큰을 응답/로그에 출력하지 않음.
3. 실제 inference API 키를 API Keys `lookupKey`로 조회하여 소유 프로젝트를 결합. 임의 프로젝트 입력/클라이언트 주장으로 무료 판정하지 않음.
4. 해당 프로젝트의 Cloud Billing `getBillingInfo`에서 `billingEnabled === false`이고 청구 계정 연결명도 없는 상태만 허용. 연결 계정이 정지되어 있어도 무료로 간주하지 않음.
5. 조회 실패/권한 없음/설정 없음/요금 검토 만료면 `AI_COST_BLOCKED`, 추론 예약·사진 다운로드·외부 AI 전송 이전 차단. 저장 및 수동 조회는 유지.
6. 공급자 429는 한도 안내 후 중단. 사용자 다음 클릭만 재시도 가능, 자동 재시도·유료 모델 전환 없음.

상태 조회는 inference를 실행하지 않는다. UI 초기 조회와 다시 확인 버튼만 있으며 백그라운드 폴링 없음. 실제 실행은 서버에서 다시 조회한다. 외부 관리자가 조회와 호출 사이에 청구 설정을 변경하는 경합/공급자 요금 변경까지 영구 무과금을 보증하는 기능은 아니다. 청구 미연결 전용 프로젝트/키 분리 및 공급자 콘솔 관리가 필요. Supabase/Vercel 요금은 별도.

## 운영 설정과 미연결 상태

서버 전용 `PSI_INSPECTOR_GOOGLE_BILLING_READER_JSON`에 읽기용 서비스 계정 JSON을 안전하게 설정해야 한다. 브라우저/VITE_ 변수/저장소/채팅에 비밀을 넣지 않는다. 기존 inference 키 변경·청구 활성화·과금 계정 생성은 하지 않는다.

같은 프로젝트에 최소 IAM `apikeys.keys.lookup`, `resourcemanager.projects.get` 필요. API Keys API와 Cloud Billing API가 조회 가능한 상태여야 한다. OAuth scopes: `cloud-platform.read-only`, `cloud-billing.readonly`. 쓰기·결제·프로젝트 청구 연결 권한을 부여하지 않는다. production/preview 자격 정보는 각각 관리한다.

이번 환경의 Vercel 변수 목록 조회는 403, CLI에도 인증이 없어 운영 계정 권한을 자동 연결하지 못했다. 그러므로 실제 무료 계정 판정 성공/무료 잔량 확인을 완료했다고 주장하지 않는다. 배포 후 상태 API로 미연결 차단 여부를 확인한다. 준비 전에는 외부 분석이 차단되며 앱의 AI OFF 저장·설명 조회·수동 분석 가져오기는 사용 가능.

## 검증

- 서버: 비용 미확인 상태의 추론/예약 0, 실제 키와 프로젝트 결합, 청구 연결/정지 계정/잘못된 응답/실패/만료 모두 차단, 비밀 비노출, 429 단일 호출.
- 분석: 작업 상태 덮어쓰기와 기존 힌트 보존, 선택 위험별 제품 후보 격리, 시멘트 분진→dust 연결·과태료 비차용, 저확신 표시, 공통 프롬프트 규칙.
- 브라우저: 비용 미확인/청구 연결 시 버튼 차단, 상태 재조회가 분석 호출하지 않음, OFF로 저장 가능. 제품 맥락→분진 기준→MSDS 추가 확인, 위험 전환 시 분리, 제품 설명 명시 반영 시 자동 호출/저장 없음. 320/390/844/1440 가로 넘침 확인.
- 합성 데이터/응답으로 검증. 실제 고객 사진 신규 전송·유료 추론은 검증에 사용하지 않는다.
