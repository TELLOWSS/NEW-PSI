# 공개 사진점검 체험 UI·UX 동기화

초기 3장면·정적 결과 소개를 현재 본기능의 흐름으로 맞춘다. 크림·숲색·남색과 코드 기반 SVG를 유지하면서 그래픽 깊이, 제목, 간격, 선택 상태, 모바일 원본/결과 비율을 개선한다. PSI 로그인 화면은 로그인 없는 체험과 얻을 결과를 보여주는 진입 카드로 바꾼다. 기존 관리자 인증과 별도 SMART TBM 관계를 유지한다.

철근 돌출부/개구부/비계/임시 전선 4장면을 제공하며 장면 전환 시 이전 입력·검토·관련 자료 펼침을 초기화한다. 핵심 답→검토 저장→조치·증빙→보고서를 자유롭게 탐색한다. 키보드 화살표/Home/End와 roving focus 탭을 지원한다. 모바일은 도해를 작게 배치하고 결과를 우선한다.

검토 기본 선택은 저장 상태가 아니다. 명시 저장 후 상태를 표시하며 재수정하면 저장 전이 된다. AI 미수용 또는 입력 의견은 최소 5자를 확인한다. 미수용 의견을 저장하면 요약/CSV/보고서도 전문가 의견을 우선하고 원래 AI 조치를 전달하지 않는다. 담당·기한 적용은 메모리에만 반영한다. 전후/재점검 상태 버튼은 화면 예시이며 실제 개선 승인·업무 기록을 만들지 않는다.

샘플 CSV는 기존 안전한 내보내기 유틸리티를 사용하고 가상 UUID·샘플 제목/설명·미조치 상태를 담는다. 재점검 화면 예시를 봐도 실제 확인 기록을 만들지 않는다. 복사·다운로드는 명시 클릭 때만 실행하고 실패를 안내하며 Blob URL은 30초 후 해제한다. 입력은 새로고침/장면 변경 시 초기화한다. 공개 인증·Storage·DB·AI 요청 및 브라우저 영구 저장이 없다.

법령·금액·사례는 선택 장면 주제의 기존 날짜 고정 자료를 필요할 때 불러온다. 철근 찔림에 다른 위험의 제재액을 붙이지 않는다. 실시간 개정 동기화·실제 부과액·정식 발행·개인/현장 권한·전자서명·자동 결제/상담 접수는 제공 기능으로 소개하지 않는다. 도입 검토안·용량 가정·파일/복사/기기 공유는 유지하고 촬영 방향·선택 힌트·검토 저장/이어보기·담당기한 변경·조치대장·공유 카드 등 최신 제공 범위를 반영한다.

검증: production CSP/번들, 320/390/768/1440 및 가로844px, reduced motion, 키보드, 장면 초기화, 검토 상태·미수용 전달, 담당/기한, CSV 바이트, 전후/재점검 경계, 주제별 기준/사례, 도입안/용량/복사/다운로드/공유 fixture/미지원 안내, /product/ 경로와 관리자 인증 경계·기존 계정 CSS. 공개 API/업무 쓰기/유료 분석 0과 초기 JS 350KB/gzip125KB 예산을 확인한다. 새 1200×630 공유 미리보기는 구현한 화면에서 렌더했다. 최종 CI·main·운영 근거는 PR에 기록한다.
