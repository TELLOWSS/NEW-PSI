## 보류 대상 핵심 요구

1. 현장 위치 모름 허용: UNKNOWN/SELF/QR/GPS 후보 상태, 확인/출처 구분, 현장·동·층·공종 미기재여도 사진·위험·임시조치 기록. QR 스캔 확인, GPS는 후보에 불과. 위치 수정은 사유·시각·이전/변경 정보 보존.
2. 완전 오프라인 설치형 FIELD LOCAL: PWA 오프라인 준비와 달리 모바일 패키지에 핵심 HTML/JS/CSS·업무 규칙·참고자료를 포함하여 최초 실행부터 서버 없이 동작. Capacitor 후보, Android 우선 후 iOS. 서버 호출·업데이트·백업 수단은 별도 명시적 승인.
3. 모바일 A–Z: 언어 선택 → 위치/미확인 → 사진 → 사용자 관찰·위험기록 → 긴급 통제/작업중지 검토 → 조치 할당·기한/임시조치 → 조치 후 사진 → 재점검 → 로컬 PDF·대장 → 백업/복원. AI 비활성에서도 사용 가능.
4. 기기 내부 데이터: 원본과 파생본 분리·SHA-256, IndexedDB→네이티브 SQLite/기기파일 마이그레이션 시 사용자 데이터 백업·충돌 보존, 선택적 PIN/암호화, Android Keystore / iOS Keychain. 암호화 미적용 기존 백업 경고.
5. 관찰 사실 / 점검자 진술 / 시스템 추정 / 확인 불가를 구분. 자동 판정·안전확인/완료 승인 금지. 실기기 OCR·AI는 검증 후 선택 단계로.
6. 운영자 클라우드(현재 /inspector 및 기존 NEW-PSI 관리자 기능) 유지. SMART TBM 별개. 근로자 설치 앱에 관리자 토큰·서버 자격정보·유료 AI 키 내장 금지.
7. 출시 시험: 실제 Android/iOS, 비행기 모드·최초 시작·저장 실패·백업 복원·QR 잘못된 표지·현장 실무자/외국어 사용자 검토·네트워크 패킷 0 조건 등 분리 검증.
