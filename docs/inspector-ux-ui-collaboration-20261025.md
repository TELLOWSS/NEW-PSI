# NEW-PSI 사진점검 · UX/UI 공동 고도화 (2026-10-25)

## 운영 원칙
본 작업은 서로 독립적인 소스 변경과 교차 검증을 통해 협업을 재현한다. 현재 대화에서 별도의 자율 코딩 에이전트 두 개가 동시에 실행된 것으로 주장하지 않는다.

## UX 편의성 역할
- 책임: 첫 촬영 → 사진 선택 → 개인정보/보관 확인 → AI 또는 직접 점검 → 검토 → 조치 → 보고서의 **행동 흐름**
- 산출물: `InspectorQuickWorkspace.tsx`, `verify-inspector-result-journey.mjs`
- 수용조건: 사진 선택 후 동의 checkbox로 포커스/스크롤; 동의 전 버튼 차단과 이유 안내; 업로드/AI 자동실행 없음; 모바일과 키보드 사용성 보존
- 안전 기준: AI 판독을 사실로 확정하거나 현장 재점검을 자동 승인하지 않음

## UI 디자인 역할
- 책임: PSI 아이덴티티, 정보 위계, 대비, 카드/CTA, 여백, 320~1440px 반응형, 다크 모드
- 산출물: `inspector-collab.css`, `SafetyInspector.tsx` 스타일 import
- 수용조건: 기존 기능·법령·서버 로직 무변경, 최소 터치 44px, 포커스 가시성, 모션 감소 설정, 보고서 인쇄 방해 금지

## 통합 검증 역할
- UX 브랜치와 UI 브랜치는 각각 독립 PR로 검사한 뒤 통합 브랜치에 병합한다.
- 통합 브랜치에서 실제 Chromium 카메라 6, 공유 10, 결과·검토 6, 다중사진 작업목록 1, 장애·수동 복구 9 시나리오를 재검증한다.
- GitHub full release checks + browser checks + Vercel preview **동일 커밋** 성공 후에만 main 병합한다.
- Production alias가 main 병합 SHA 배포와 일치하는지 확인한다.

## 검사 범위와 한계
브라우저 시뮬레이션은 합성사진/모의 API로 인터페이스 동작을 확인한다. 실제 Android 실기기 촬영·카카오톡 전달·현장사진 AI 판독 정확도 검증으로 오인하지 않는다. 보고서 작성은 법 위반 확정이나 조치 완료 승인이 아니다.
