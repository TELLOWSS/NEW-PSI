# 02 · UI·디자인본부 제안서 (LUMI 관점)
성격: 2026-10-26 저장소 기반 ATLAS 가상 역할 검토. 실제 독립 디자이너·실기기 사용자 검증은 아직 수행하지 않음.

## 확인된 기존 기능
- components/IntegratedWorkBoard.tsx, components/inspector/, components/tbm/에서 다양한 카드·버튼·상태 메시지 사용.
- 과거 320/390/768/1440px 및 다크모드 합성 QA 증빙 존재. 실제 저사양 Android의 손가락 조작과 시각적 위계 독립 심사는 미완료.
- PSI 핵심 위험판정 메시지와 Inspector 증거 수준을 보기 쉬운 UI로 만들되 위험 알림을 장식 아래 숨겨서는 안 됨.

## 제안
| 우선 | 코드 | 개선·설명 | 수용 기준 |
|---|---|---|---|
| P0 | DS-01 | 통합 디자인 토큰: 위험·미확인·진행·관리자 확인 상태별 색상뿐 아니라 아이콘·문장·우선순위 통일 | 색에 의존하지 않는 상태 구분, 다크모드 대비 및 고위험 정보 숨김 없음 |
| P0 | DS-02 | 모바일 1화면: 사진점검 입력·핵심 관찰·다음 행동·저장 상태를 위에서 바로 이해 | 360/390/768/1440px 가로넘침 및 CTA 누락 없음, 44px 터치 표적 |
| P1 | DS-03 | 사실/점검자 진술/추정/확인불가 네 종류의 근거 표시 | 출력·공유에도 증거 수준 구분 유지, 불확실성을 확정으로 표시하지 않음 |
| P1 | DS-04 | A4 보고서·교육문서·사진 전후 비교용 인쇄 시스템 | 화면·PDF 내용 일치, 원본/검토/서명 상태 구분, 자동 서명·승인 금지 |
| P2 | DS-05 | 고급 로딩·전환 애니메이션은 접근성·저사양 성능·reduced-motion 보장 후 도입 | WebGPU 없어도 정적 폴백, 긴급 신호 항상 먼저 노출 |

## 필수 교차검토
제품기획: 초보자 1화면. 안전지능: 작업중지·경보 가독성. 품질검증: 화면 합성 + 실제 Android 별도.
