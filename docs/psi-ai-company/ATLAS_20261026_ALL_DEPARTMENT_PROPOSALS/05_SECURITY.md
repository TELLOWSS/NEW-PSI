# 05 · 데이터·보안본부 제안서 (KEEPER 관점)
**성격:** 기존 보안감리 문서·코드 경계 기반의 가상 책임 역할 보고. 공격 성공/운영 DB 취약함 확정 아님.

## 근거
- 2026-10-25 저장된 읽기전용 Supabase Advisors 결과에는 SECURITY DEFINER 함수·뷰, mutable search_path, RLS 정책 관련 점검 권고가 있었음. **어느 프로젝트가 운영 데이터베이스인지 먼저 확정해야** 안전하게 작업 가능.
- `components/LocalBackupArchivePanel.tsx` 및 암호화 아카이브는 PC 로컬 월별 복원 범위를 다룸. Inspector DB/사진 Storage의 실제 전재해 복원은 별도로 검증되지 않음.
- 별도 /inspector는 사용자 진입 경계이며 실제 인증·저장을 공유. 근로자 QR 응답은 전체 관리자 앱 접근권한과 다름.
- 협력사 산업안전보건관리비·안전시설·신호수 원장은 별도 제품; SMART TBM·ZERO DAY도 자동 통합 금지.
