# 04 · 안전지능본부 제안서 (SAFI 관점)
**성격:** 안전업무 책임 관점의 저장소 검토 기획. 실제 모델 실험/현장 위험성평가 법적 승인 문서 아님.

## 근거
- `utils/coreMetrics.ts`와 `utils/operatorNextTask.ts`에 최신 유효 6대 지표, 결측 점수 보호, 기록된 작업중지 신호 검토 분기가 있음.
- `lib/inspector/actionEvidenceAudit.ts`, `educationHandoff.ts`, `replyInbox.ts` 등은 전후 사진 차이·회신·교육 인계 근거를 표현하지만 실제 조치 완료/작업재개를 자동 입증하지 않음.
- 오프라인 Laya 11언어 132건 테스트와 33건 v1은 **평가기 합성 시험**이며 실제 체크포인트의 사고위험 검출 능력에 대한 증거가 아님.

## 제안
| 우선 | 코드 | 개선 설명 | 수용 기준 |
|---|---|---|---|
| P0 | SA-01 | **6대 지표 신뢰성 인증표:** 위험인지도/교육이해도/실천참여도/보호구·수칙준수/소통·보고성/작업중지 감수성의 원자료·분모·작성주기·유효·미확인 상태 가시화 | null/빈문자열/0 구별, 오래된 값 제외, 근거 없는 '현장 안전' 판단 불가 |
| P0 | SA-02 | **중대 위험 우선 안전 게이트:** CRITICAL_STOP/긴급 징후는 개선 약속기한과 별개로 사람의 통제 검토를 우선 표시 | 작업중지·재개·법 위반/처벌 자동확정 없음. 필수 안전 문구는 간편화 모드에도 유지 |
| P0 | SA-03 | **확인 가능한 사고 전 신호 환류:** 자가 위험성평가→Inspector 발견→담당 조치→개선사진→현장 재점검→다음달 TBM 보강 **읽기전용 연결** | 증거 ID 및 검사 범위 표시. 자동으로 '조치완료/교육 이해' 반영하지 않음 |
| P1 | SA-04 | **모델 오류의 안전 우선 연구표:** 실제 Laya 로컬 추론·현지어 사람 검수·모델 체크포인트/재현성을 분리, 위험 미탐(false negative)을 첫 지표로 표시 | 10개 외국어 사람 번역 완료 전 '미평가'. 고위험 미탐 발생 시 shadow 유지; 실근로자/현장사진 외부 업로드 금지 |
| P1 | SA-05 | **사진 관찰 4분류·법규 출처 검증:** 보이는 사실/진술/추정/확인불가 구분, 기준·법규는 일자·적용조건·근거를 보여줌 | 사진 한 장으로 위법·처벌·근로자 신원·위험등급 단정 금지 |
| P1 | SA-06 | **예측 시그널의 불확실성 공개:** 반복 위험은 공종·언어·월별 모집단 변화를 통제하며 예측 구간과 비표본 경고를 표시 | 위험 높아짐/낮아짐을 점수 변화만으로 단정하지 않음. 현장 운영 의사결정은 관리자 |

## 교차검토 요청
- NAVI: 근로자 설명 이해도; PROOF: 결측·희귀 사건·다국어 오분류; KEEPER: 현장자료 비식별·접근권한.
