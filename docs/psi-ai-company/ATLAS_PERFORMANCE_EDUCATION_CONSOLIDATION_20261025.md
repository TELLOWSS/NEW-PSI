# ATLAS · PSI 2차 기능 고도화 — 성과분석 지표 기준 / 교육 리포트 연결 (2026-10-25)

## 1. 정확히 재현 가능한 중복 계산
현재 `PerformanceAnalysis.tsx`는 `calculateCoreMetricSnapshot`를 일부 호출하면서도, 변동성·최우수 공종·팀별 습관 신호 계산에서는 `Number(safetyScore)`, raw 점수 배열, 중복된 인원 및 최근/과거 기록을 서로 다르게 취급한다. 이 결과 동일 데이터로 화면마다 다른 값이 나올 수 있다.

- 결측 null/빈 문자열은 0점이 아님.
- 실제 숫자 0/100은 유효.
- 같은 근로자의 여러 기록은 최신 유효 자료가 아니라 **최신 기록이 유효할 때만** 지표에 포함 (과거 점수 되살리지 않음).
- 현재 주기의 유효 지표가 0건이면 `평균 0`으로 표시하지 않음.
- 월×공종 매트릭스도 유효 표본이 없으면 0이 아니라 '없음' 처리.
- 팀 표본은 '서로 다른 유효점수 근로자 3명 이상'이어야 진단 참고값에 포함, 사람 평가/징계 순위로 자동 전환하지 않음.

## 2. 교육·리포트 중복 제거는 삭제가 아니라 업무 이동 연결
`EducationReturn`은 이미 A4/Reports/MonthlyGuidance로 연결하는 공통 입구다. MonthlyGuidance의 기존 '현재 화면 인쇄'는 A4 스튜디오의 '5단계 교육자료 제작/번역'과 서로 **다른 산출물**이다. 고유 기능/기록은 그대로 유지하며 월간 계도자료 화면에서 EducationReturn → A4 → Reports의 후속 이동을 명확히 제공한다.

개인 보호 보고서는 관리자용이고, 근로자에게 NEW-PSI/Inspector 전체 프로그램을 배포하지 않는다. 실제 QR·교육 응답은 별도 제한 입력 채널이며, 다른 제품 SMART TBM 또는 협력사 안전시설비/신호수 임금 관리 프로그램과 자동 동기화하지 않는다.
