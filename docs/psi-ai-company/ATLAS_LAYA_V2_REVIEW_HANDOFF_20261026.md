# ATLAS 9차 — 다국어 132건 검수표 이어하기·이동 검증 (2026-10-26)

## 목표
이전 8차의 모바일 한 건씩 검수 기능이 JSON 다운로드 후 다른 기기에서 복원될 때, **132건 기록은 유지하지만 마지막 언어/문장/필터 위치가 소실**되는 문제를 해결한다. 검수자는 코딩/파일 구조를 몰라도 같은 파일로 업무를 이어갈 수 있어야 한다.

## 변경
- `utils/layaReviewHandoff.ts`: 132개 시험 세트의 기존 `psi.laya.offline-hazard-benchmark.v2` 원본 구조에 호환 가능한 선택형 `reviewSession` 표시 위치(버전 1, 선택 언어/문장, 집중모드, 미검수필터) 추가.
- 이전 132건 JSON 검수표 파일처럼 `reviewSession`이 없는 파일도 그대로 연다. 부적절하거나 다른 언어의 문장 ID를 지정한 위치 정보는 무시하고 초기 상태로 안전하게 연다.
- `components/tbm/LayaExtendedReviewPanel.tsx`: 저장/불러오기 후 마지막 위치 자동 복원, 남아 있는 다음 외국어 검수로 이동 버튼 추가.
- 사용자가 검수 기록을 수정한 후 JSON 다운로드를 요청하는 것과 **실제 로컬 파일 저장 성공은 구분**한다. 다운로드 요청 상태에서는 여전히 미저장 경고가 유지되며, 사용자가 폴더의 파일을 확인한 뒤 `다운로드 파일 확인 완료`를 눌러야 해당 경고를 해제한다.
- JSON 결과와 현재 검수표 132건 비교 및 위험 유형 분류·언어별 통계는 변경하지 않는다.
- UI 상태의 검수자 코드/신원은 인증 대상이 아니며 이 기능은 작업 중 상태를 이어가는 보조 기능일 뿐이다.

## 검증
- 새 10개 자동 테스트: 구버전 파일 하위호환, JSON 왕복, 다른 언어 문장 ID 변조, 부적절한 UI 메타정보 안전 무시, 모든 언어 이동, 완료 언어 건너뛰기, 1,000회 결정적 랜덤 복원, 파일 확인 전 저장성공 오인 차단, Hobby API 불변.
- `npm run verify:ci`: 전체 TypeScript/정적 보안·무료정책 점검/단위테스트/Production 빌드.
- 7개 제품 Playwright 브라우저 통합검사 및 Vercel Preview 정확 SHA READY 확인 전 main 병합하지 않는다.

## 비용·정보보호
- Vercel Hobby 유지. 신규 API 함수, cron, DB, AI 추론/음성/영상 함수 0건.
- 이 기능은 서버 전송·브라우저 영구 저장 없이 사용자가 직접 받는 로컬 JSON으로만 이동한다.
- 공유장비에서 실명/연락처/현장 개인정보를 넣지 않는다. 로컬 다운로드 파일의 보관·삭제는 사용자 책임.
- 모바일 손가락 조작 실기기 확인, 통역자 전문가 의미 검토, 실제 Laya 체크포인트 모델 정확도는 미완료 항목으로 별도 보고한다.
- 개발자 연구 실험용 화면이며 PSI의 위험성평가 등급·작업중지·근로자 교육합격과 자동 연계하지 않는다.
