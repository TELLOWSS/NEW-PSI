# ATLAS · Hobby 무료 함수 한도 보호 / 30초 교육 미리보기 (2026-10-26)

## 운영 정책
- 현재 Vercel Hobby 유지. 유료 요금제 변경/결제 추가/외부 렌더 서버 설치 없음.
- Vercel Functions의 **Fluid Compute 명시** (`vercel.json fluid:true`). 현재 함수별 최대 설정 30s/90s/240s 유지, 모두 Hobby Fluid 300s 상한 이내.
- Vercel 공식 Hobby 포함량 (2026-10 조회): Active CPU 4h, Provisioned Memory 360 GB-h, Function Invocations 1,000,000. 포함량은 실제 남은 잔액이 아니다. 월간 CPU/메모리/호출량은 Vercel Usage UI에서 별도 확인한다.
- 신규 API 함수·cron·외부 서버 호출·FFmpeg·모델 설치·데이터 업로드 **0건**. 단일 변경 커밋으로 배포 수/빌드 분산 낭비 최소화.
- 개발 단계 개인 비상업적 이용 조건을 준수한다. 향후 **실제 사업·유료 사용자·상업적 운영** 시작 전에 Vercel 이용조건에 맞는 서비스 플랜 검토.

## 신규 사용자 기능
- 위험성평가 교육자료 스튜디오 → 3. 5단계 검수 → **30초 핵심 흐름 미리보기**.
- 기존 300초 영상 장면표를 10:1 압축해 제목·내레이션·화면 구성 가이드를 자동 전환하여 재생.
- 재생·일시정지·이어 보기·다시 보기·진행률 표시와 모바일 접근성 제공.
- 순수 React 브라우저 UI이며 영상파일·음성파일은 만들지 않는다. 음성 자동생성이나 업스트림 HyperFrames 런타임 통합으로 표시하지 않는다.
- 영상 300초의 제목/내레이션/화면 지시 누락 시 재생 거부. 내용 변경 시 미리보기 초기화.
- 기존 5분 영상 장면표 JSON 및 SVG 흐름도 로컬 내보내기 유지.

## 확인 가능 범위
자동검사: 300→30초 장면 매핑/결함 차단/함수 duration·Fluid 설정/새 HTTP 호출 없음/기존 제품 회귀 CI.
이 검증은 **실제 월간 사용량 보증, 실 Android 성능, 유튜브 링크의 오픈소스 10개 식별을 대신하지 않는다**.

## 추가 개발 게이트
1. Playwright 합성 사용성 + 모바일 축소 화면 검증.
2. 실 Android 저사양 기기에서 30초 재생·브라우저 백그라운드/절전·성능 점검.
3. 전문 렌더링은 무료 호스팅 함수에 넣지 않는다. 오프라인 PC 배치 렌더 시험 후 상업화 소스/자산 고지 검증.
4. Laya 11개 언어 벤치마크는 개인식별 정보 없는 합성데이터로 별도 파일럿, 데이터 외부 전송·기존 PSI 점수 연결 전 별도 승인.
