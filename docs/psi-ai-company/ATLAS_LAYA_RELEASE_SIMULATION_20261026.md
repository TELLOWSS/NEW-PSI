## 총괄 책임 원칙
**PSI 운영 위험등급, 작업중지 판단, 6대 지표, 근로자 교육합격에 이 검증결과를 연결하지 않는다.**
아래 수치는 Laya 언어모델 정확도 실험이 아니라 *오프라인 평가기 계산의 정확성·강건성*을 확인하는 가상/교란 시뮬레이션이다. 외국어 10개 언어는 통역자 검증 전 실제 모델 성능 자료가 아니며, 결과 JSON은 실행 진위/체크포인트 리비전/검토자 서명을 암호학적으로 보장하지 않는다.

## 발견한 계산상의 위험과 조치
1. 이전 코드에서는 33건 중 일부를 삭제해도 현재 들어온 목록만으로 부분 집계 → 고정 fixture **33건 전부 필요**, 누락/초과 입력 거절.
2. 거짓 \`reviewed\`로 외국어 문장에 한국어 원문을 복사해도 점수가 나올 수 있음 → **한국어 원문 그대로 복사한 외국어 검토완료 값 거절**. 다른 형태의 번역 진위 판별은 사람 검토 필요.
3. 한국어 기준 문장 자체를 바꿔도 레이블만 같으면 점수를 낼 수 있음 → **한국어 원문 고정**.
4. 사고위험 \`fall\`을 \`none\`으로 잘못 판정하는 위험 누락과 \`none\`을 \`fall\`로 잘못 판정하는 오경보를 구분하지 않았음 → **False Negative / False Positive / 사고유형 오류 / 무응답 별도 집계**.
5. 한국어 3건만 예측해도 평가 대상 대비 coverage 100%로 보일 수 있음 → **고정 33건 대비 실제 검토율/예측률과 완성된 언어 수를 별도 표시**, 기존 eligible 대비 coverage와 혼동 방지.
6. 검증된 것처럼 보이는 허위 JSON 파일은 자체적으로 판별할 수 없으므로 결과의 \`safetyApproved\`/\`provenanceVerified\`는 반드시 false 유지.

## 결정적 시뮬레이션 시나리오
- 33건 × 11언어/3상황 단일 클래스 정상 모형: 예상 33 정답 / 사고 누락 0. **가상 모형이며 실제 Laya 실행 아님**.
- 사고위험 22건을 모두 \`none\`으로 예측: 예상 **false negative 22**, 정답 11.
- 모든 33건을 \`fall\`이라고 예측: 예상 **false positive 11**, 사고유형 오류 11, 정답 11.
- 예측 1건 누락: 완전 예측 언어 **10/11**, 고정 33건 예측률 **32/33**.
- 33개 각 사례를 1건씩 개별 오염: 매회 정답 32, 오류 1.
- 난수 시드가 고정된 **1,000회 교란 시험**(매회 33건 무응답/6가지 선택지 혼합): 33,000개 가상 사례에 대해 점수 항목 분할 합계 불변성 검증.
- 250회 입력/예측 순서 이동: 동일 결과 불변성 검증.
- 실험 샘플 삭제·추가·ID 중복·원본 위험 등급 조작·외국어 한국어 복사·한국어 원문 변조·허위 신뢰도·잘못된 레이블/ID → 거절 검증.
- **실제 모델 예측 0회**: 언어별 안전성, 오분류율, 심각한 사고 누락률의 실제 통계치는 산출하지 않음.

## 추후 실제 도입 의사결정
실제 Laya 체크포인트가 명확한 버전으로 고정되고, 각 언어 현장 통역자가 검수한 가상 안전문장셋(6개 위험 분류를 모두 대표하며 다양한 부정형/복합상황 포함)이 마련되기 전에는 전면 운영 도입 금지. 각 언어·위험유형별 미탐/오탐·신뢰도 보정·낮은 확신 시 기권 검증 후 **Shadow Mode → 제한적 보조 → 관리자 최종 판단** 순으로만 전환.
