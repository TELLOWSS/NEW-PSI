# PSI AI STUDIO · 아틀라스 검토 및 구현 의사결정 · 2026-10-25 · 후속 4차

> 이 기록은 독립된 7개의 AI가 동시에 회의한 회의록이 아니라, 아틀라스 총괄 하에 한 작업 세션에서 책임 영역별 관점과 충돌을 검토한 **제안/판정 기록**이다. 실제 독립 사용자 평가, 보안 담당자 승인과 실현장 재점검 기록을 대신하지 않는다.

## 문제와 역할별 검토
| 역할 | 검토 내용 | 결정/구현 책임 |
|---|---|---|
| ATLAS 아틀라스 | PR #84 공유·PR #85 조치 관제 후 반드시 다음 평가로 환류되어야 함 | **증거 연결 신뢰성 + 수동 교육/다음 위험평가 인계**에 범위를 한정 |

| LUMI 루미 | 긴 인계 내용을 좁은 모바일에 모두 노출하면 스크롤 과다 | 기존 관제 하단 접기/펴기, 복사 버튼, 명확한 상태 색상과 다크모드 |
| CORE 코어 | 기존 저장/수정 API와 서버 검증을 중복 개편하지 않는다 | 기존 evidence.sha256을 이용하는 순수 메타데이터 판단 함수; 별도 API 없이 렌더링 및 복사 |
| SAFI 세이프 | 사진 hash가 다른 것과 같은 현장·실제 개선은 다르다 | 사진이 다르다고 작업 재개/조치 완료 선언 금지, 보고서/교육 내용은 **초안**만 출력 |
| KEEPER 키퍼 | 외부 서비스로 민감정보 자동 전송 또는 저장되지 않아야 함 | 텍스트는 화면에서 편집 전 검토, 수동 복사에만 사용; 외부 AI·SMART TBM 자동 연계·DB 변경 없음 |
| PROOF 프루프 | 이전 사진과 동일 ID/해시, 누락된 사진, 레거시 조치 및 과도하게 긴 전달문 검증 | Vitest 및 합성 Playwright 동작 검증; 실제 사진/타국어 사용자 수동 검토는 별도 |

## 상충 결론
1. **자동으로 교육·SMART TBM 기록을 생성할지** → 하지 않는다. PSI와 SMART TBM은 독립 제품이며 교육 참여·이해 여부를 자동 추정하면 신뢰성 하락.
2. **사진 전후가 다른 해시면 조치 승인할지** → 아니다. 다른 바이트일 뿐 동일 위치와 안전조치 이행의 증거가 아니며, 실제 현장 재점검은 관리자 몫.
3. **전후 사진 연결이 없는 오래된 기록은 자동 수정할지** → 하지 않는다. 기존 기록의 출처를 임의로 생성하지 않고 연결 상태 안내만.
4. **30개 조치를 한꺼번에 교육 공유할지** → 전체를 내보내면 개인정보·긴 텍스트 혼합 위험. 이번 초안은 우선순위 12건으로 제한하고, 나머지는 별도 조회해야 함을 명시.
