# PSI AI STUDIO · 무료 운영 자원 청사진 및 1차 예방 적용 (2026-10-25)

## 사실 확인과 한계
- Vercel 팀 `tellowss-projects`의 실제 플랜은 **Hobby** (연결된 Vercel 팀 정보 확인).
- Git 연동된 7개 Vercel 프로젝트는 동일 Hobby 팀에 속하며 일일 신규 배포 100회/동시 빌드 1개 등의 **계정/팀 수준** 제한 영향을 받을 수 있다.
- Hobby는 Vercel 이용약관상 **개인·비상업적 용도로 제한**. 따라서 현재 개발·검증용 도구를 협력사에 유상 제공하는 **상업 서비스로 전환하기 전에 요금제와 약관 검토가 필수**. 무조건 상용 허용 또는 무료로 무제한 운영 가능이라고 표시하지 않는다.
- Vercel 청구내역 API는 팀 Hobby 플랜에 대해 `Plan not found`(404)를 반환하여 **실제 월간 CPU/함수 호출/전송량 사용량은 여기서 취득하지 못함**. UI는 실시간 사용량이 아니라 **수동 가정 시뮬레이터**.
- NEW-PSI Supabase `PSI-Database`는 `ACTIVE_HEALTHY`. 2026-10-25 비식별 총량 SQL: DB 약 22,039,699 bytes (DB 파일 총량), storage.objects 161개, `metadata.size` 합 약 8,491,603 bytes. 이 수치는 Storage 내부 메타데이터의 추정이며 실제 청구량/egress가 아니다. **Supabase 구독 등급은 검증하지 않음**.
- Vercel 최근 runtime errors 조회 범위(24h)에는 집계 오류가 없었으나 오류가 없음을 보장하거나 서버 사용량이 낮음을 뜻하지 않는다.
- `vercel.json`은 `buildCommand:npm run build:verified`로 **매 배포마다 verify:ci를 다시 실행**한다. 회귀 보호 장점은 있지만 빌드 시간·하루 배포 횟수·동시빌드 대기에 주의. GitHub CI 강제/Deployment Checks 설정이 조회 검증되지 않은 상태에서 이 보호 장치를 제거하지 않는다.
- `api/admin.ts maxDuration 90s`, `api/gateway.ts maxDuration 240s`: **Fluid compute가 활성화되어야 Hobby의 60s 비-Fluid 제한을 넘는 구성이 가능**하다. 프로젝트 API에서 Fluid 설정 필드를 확인할 수 없었으므로 계정의 Functions 설정에서 반드시 확인. 배포가 READY라는 사실만으로 모든 함수 실행이 허용되는 것은 아니다.
- Supabase Free 일반 참고 한도: DB 500 MB/프로젝트, Storage 1 GB, 비캐시 egress 5 GB, 캐시 egress 5 GB, 7일 저활동 자동 중지 가능. 이 계정이 Free인지 확인되지 않았으므로 **남은 실제 한도로 표기하지 않음**.

## 이번 구현
- `components/management/FreeTierCapacityPlanner.tsx`: 설정 상단의 **계획용** 시뮬레이터, 모든 입력은 화면 상태에서만 계산, 서버·외부 API 호출/저장 없음.
- `utils/freeTierCapacity.ts`: 숫자 범위 정규화, 사진 데이터량·재조회 트래픽·배포 예상 비교. 다른 기능의 호출은 미포함, 병목이 없다거나 실제 남은 한도 주장하지 않는다.
- `scripts/check-free-tier-capacity.mjs`: 비용관리 독립 제품 경계, 인스펙터 독립 진입/기존 인증 경계, Vercel 릴리즈 빌드검증 유지, 기본 함수 최대실행시간 계약(300s 상한)을 CI 진입 전에 검사.
- `tests/freeTierCapacity.test.tsx`: 초보자 기본/0/극단·잘못된 값, 집계 누락 고지, 읽기전용 페이지 렌더링, 제품 경계 보존.
- **없는 기능**: Vercel의 월간 정확한 자원사용량 자동 조회·과금 예측·선결제·유료 플랜 전환·새 DB/RLS·호출 자동 중단. 이를 약속하지 않는다.

## 실제 사용자 안내
1. 설정 → **무료 운영 용량 계획**을 열어 사진 개수, 저장 사본 크기, 다운로드 횟수, 전체 팀의 하루 배포 횟수를 입력한다.
2. 결과는 **새로 저장될 사진만** 대략 추정하므로 기존 DB/Storage, 원본 보관, 로그, 백업, AI 공급자 비용과 실 다운로드 캐시 비율은 포함되지 않는다.
3. 기준치 근접 경고가 나면 관리자·프로젝트 소유자가 Vercel/Supabase 각각 공식 Usage 화면의 실제 수치를 먼저 확인한다.
4. 상용 도입 시 플랜/법률/개인정보 영향 및 비용 예산 승인을 별도 진행한다. 협력사 안전관리비는 독립 유지.
