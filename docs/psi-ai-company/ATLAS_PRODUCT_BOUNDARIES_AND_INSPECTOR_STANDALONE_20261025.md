# ATLAS · NEW-PSI / 협력사 안전관리비 / 독립 Inspector 경계 결정 — 2026-10-25

> 사용자 최종 원칙: 산업안전보건관리비는 **협력사에서 독립 관리하는 기존 최적화 제품**이다. PSI/Inspector/안전관리자일지에 금융·인건비 데이터를 무단으로 합치지 않는다. Inspector는 PSI 내부 진입과 **별도 제품형 진입**을 모두 제공한다.
>
> 이 문서는 책임 관점별 검토 결정을 기록한 것이며 독립 AI 일곱 명이 실제 자율 회의한 회의록이 아니다.

## 실구현 vs 미구현 범위
- **이번 코드 적용:** `/inspector` 전용 SPA 진입, 전용 관리자 잠금, Inspector 빠른/상세 기능 재사용, 기존 `/product` 현장시작 링크 변경, 최소 메뉴·로그아웃, QA.
- **기존 PSI 유지:** `/?mode=photo-inspector` 주소 계속 지원. 기존 NEW-PSI 화면과 기록·인증도 유지.
- **현재 공유하는 것:** 관리자 세션, `/api/admin/inspector` 서비스, 점검 사진 보관 및 보고서/조치 기록.
- **이번에 주장하지 않는 것:** 완전히 독립된 Vercel 프로젝트·다른 도메인·독립 고객 계정·테넌트 격리·개별 청구·별도 DB. 이는 명시적 사업·보안 설계 및 실제 운영 인프라 구축이 필요한 차기 제품화 범위.
- **협력사 산업안전보건관리비:** 기존 제품 수정·대체·재설계·비용 데이터를 PSI 수집/분석/자동 전송하는 작업 전부 제외. 해당 제품 저장소는 이번 대화에서 확인되지 않았으므로 임의로 특정 제품과 동일시하지 않음.
- **안전관리자일지:** 향후 해당 업무가 필요해도 비용관리와 자동 혼합하지 않음. 업무 일지에서 비용 승인·노무비 자동 산정으로 넘어가지 않음.

## 수용/출시 조건
1. `/inspector` 호출 시 PSI 전체 App 로딩 없이 전용 화면이 뜨되, 서버 인증 전에는 기록 API를 호출하지 않는다.
2. 인증 거부/연결 실패는 잠금. 정상 인증 후 사진점검으로 이동, 로그아웃 후 다시 잠금.
3. `/product`에서 직접 점검 링크는 `/inspector`, `/?mode=photo-inspector`는 기존 PSI 내부 임베디드 진입으로 유지.
4. 금전·시설비·신호수 인건비·정산/승인 자동 연동은 어떤 경로에도 추가하지 않는다.
5. GitHub CI/Chromium QA, Preview READY, main/운영 배포 SHA는 각각 분리 검증. 실제 Android/타기업 독립 테넌트는 별도 검증.
