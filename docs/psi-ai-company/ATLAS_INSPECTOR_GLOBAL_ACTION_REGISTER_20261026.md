# ATLAS · 인스펙터 통합 조치대장 (2026-10-26)

## 기능
컨설팅·정기점검 등 여러 저장 점검의 약정 완료기한, 지연, 재점검 대기, 이행 확인 결과를 관리자 전용 화면에서 모아 보여줍니다. PR #97의 개별 점검 조치기한 관리 및 점검별 CSV는 유지합니다.

## 설계 원칙
- 관리자 인증과 서버 속도 제한을 재사용. 화면을 명시적으로 열 때만 관리자 API를 호출하고, 매회 **점검 최대 20건**을 조회합니다. 이전 기록은 '더 보기'로 조회하며 전체 점검의 완전한 통계로 주장하지 않습니다.
- Supabase 원본 JSON을 서버에서 조회하지만 브라우저에는 **저장된 조치 메타데이터만** 전달합니다. AI 분석 원문, 사진 원본, 서명 링크, 민감한 회신 토큰, 보고서 전체는 조회/전달하지 않습니다. DB에서 JSON을 읽는 비용은 실제 사용량 측정 후 최적화 필요.
- 삭제 중/사진 삭제/완전 삭제 통제상태의 점검은 목록에서 제외. 각 조치를 열 때 원점검 최신 상세를 다시 확인하고 actionId가 일치할 때만 해당 페이지로 이동합니다.
- 한 점검의 기한 변경 이력은 기존 note에 보존, 최초 설정 근거 scheduleContext를 표시합니다. 자동 승인·완료 변경, 근로자에게 전체 본프로그램 공유, 유료 AI 호출은 하지 않습니다.
- 긴급 위험은 약정기한과 별개로 현장 통제 판단. D-2는 조치가 안전하게 완료됐다는 증명이 아니며, 임시 보호조치 실제 이행 여부는 현장 관리자가 확인합니다.
- 검색·필터 및 **현재 불러온 결과의 CSV** 지원. CSV 수식 삽입 방어. 기존 화면에서 작성 중인 사진/조치/재점검은 자동 이동으로 소실시키지 않습니다.
- 협력사 안전시설·신호수 인건비/산업안전보건관리비 별도 제품, SMART TBM, ZERO DAY 별개. 신규 DB 마이그레이션 없음.
