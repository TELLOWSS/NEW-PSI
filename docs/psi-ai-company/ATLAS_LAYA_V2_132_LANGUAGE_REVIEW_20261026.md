# ATLAS 6차 — 11개 언어 × 6개 위험유형 확장 검수판 (2026-10-26)

## 결정 사항 및 책임 범위
- 기존 33건 `psi.laya.offline-hazard-benchmark.v1`은 호환성을 위해 수정하지 않는다.
- 새 `psi.laya.offline-hazard-benchmark.v2` 실험 세트는 **11개 언어 × 12문장 = 132건**으로 고정한다.
- 위험 유형은 `fall`, `struck_by`, `caught_in`, `electrical`, `fire`, `none` 6가지, 각 언어당 유형별 2문장이다.
- 형틀 개구부 추락, 비계 추락, 자재 낙하/양중물 충돌, 회전공구 말림/굴착기 협착, 분전함 누전/손상 전선, 용접 불티/인화성 용제, 문서 정리/보호구 재고 확인을 구분한다. 이 문장은 가상 학습·시험 자료이며 사실관계나 현장 관찰 기록이 아니다.

## 작업자 친화적 개발자 검수 흐름
1. PSI 개발자 모드 → 위험성평가 교육자료 스튜디오 → **3. 5단계 검수** → `ATLAS LAB RESEARCH V2`.
2. 언어별 12개 한국어 기준문장과 기대 위험유형을 나란히 본다.
3. 현장 통역자가 **실제 외국어 표현으로** 입력한 후 한국어 의미, 부정형, 위험 수준, 작업중지 명령 강도를 별도 확인한다.
4. 연락처/실명 대신 검수자 코드만 입력하여 `현지어 대조 완료 기록`을 누른다. 입력/수정은 서버 전송 없이 브라우저 메모리에서 처리되므로 **132건 JSON 저장**이 필요하다.
5. 이 코드는 검수자 본인 여부나 자격을 인증하지 않는다. 통역자 확인 기록은 별도 현장 관리대장으로 교차 확인해야 한다.
6. 오프라인 PC에서 현장자료 없는 실험값만 `scripts/laya_safety_offline_runner_v2.py`로 실행. 필요 모델은 허가된 PC의 로컬 캐시에 준비하되 Vercel/PSI 서버에 설치하지 않는다.
7. 결과 파일을 이 화면에 다시 불러와 위험 누락(False Negative), 위험 오경보(False Positive), 위험유형 오류, 무응답과 언어별 검토/예측 범위를 확인한다.

## 기술적 경계
- HTML/React 화면에 AI/모델/영상 렌더링 API 및 새 Vercel 함수가 없다.
- 입력 자료 검증 시 **132개 고정 ID 전체**를 확인하고, 한국어 기준 텍스트·기대 위험유형의 변조를 차단한다.
- 번역 검수 완료 시 현지어 텍스트 10자 이상, 원문과 비동일, 검수자 식별 코드 3자 이상, 검토 일시 필수. 단, 데이터 입력자가 이를 위조할 수 있으므로 **신원·번역 의미·실제 모델 실행 출처는 독립적으로 인증하지 않는다**.
- 다른 파일에서 임의로 제출한 모델 리비전 문자열만으로 실제 체크포인트의 원본/가중치/저작권을 보증하지 않는다.
- 입력값과 평가 결과는 로컬 JSON 파일로만 보관. 자동 전송·자동 안전등급 변경·PSI 6대 지표 수정 없음.
- Model runner는 `HF_HUB_OFFLINE=1`, `TRANSFORMERS_OFFLINE=1`을 설정하나, 실제 네트워크 차단이 필요하면 **물리적 또는 OS 수준 에어갭**을 사용해야 한다.

## 실험실 정밀 시뮬레이션
- 완전 정답 모의 결과 132/132, 전부 위험 없음 입력 시 실제 위험 110건 누락.
- 모든 위험을 추락으로 잘못 판정하면 정상 문장 22건에 대한 가짜 위험 경보 + 다른 사고유형 88건의 오분류.
- 1건 예측 누락 시 131/132로 표시하고 완전 평가 언어는 10/11만 인정.
- 통역자 미검수 10개 외국어의 완벽한 가짜 예측이 있어도 한국어 12건만 분모에 포함하며 전체 132건 중 예측 범위 12/132를 분리 보고.
- 2,000회 결정적 교란 시험 × 132건 = 264,000개 평가 사례 및 250회 입력 순서 변환 불변성 시험.
- 시험 결과 JSON 위조/미검증 검수자 코드/모델 리비전 임의표시 가능성은 별도로 고지. 가짜 결과는 **실제 Laya 모델 성능으로 기록 금지**.
- 6개 위험 분류를 도입할 근거를 만들기 위한 데이터·검수 체계이며 산업안전 작업중지·위법성·출입통제 최종 자동판정 기능이 아니다.
