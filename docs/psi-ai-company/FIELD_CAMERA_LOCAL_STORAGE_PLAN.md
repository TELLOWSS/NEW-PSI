# 현장 카메라 브라우저 저장 영향과 복구 계획

## 범위
무가입 `/camera` 전용 IndexedDB `psi-field-camera`에 사용자가 촬영하거나 선택한 파일을 보관한다. 기존 Inspector의 서버 데이터베이스·사진 저장소·인증·보고서·공유 토큰은 변경하지 않는다. 기존 브라우저나 사용자 사진을 자동 삭제하거나 이전하지 않는다.

## 실패와 복구
사진은 개별 트랜잭션 완료 후에만 브라우저 보관 완료로 표시한다. 저장 실패 시 새 파일은 현재 화면의 임시 메모리에 유지하고 재시도 또는 다운로드할 수 있다. 이전 사진은 삭제하지 않는다. 브라우저 저장을 열 수 없는 경우 기존 사진이 없는 것으로 단정하지 않는다. 삭제는 사용자 확인 후 트랜잭션 단위로 적용한다.

브라우저 데이터 삭제, 비공개 세션 종료, 저장소 축출이나 기기 손상은 복구할 수 없으므로 중요한 파일의 별도 기기 저장을 안내한다. 브라우저 저장은 휴대전화 사진첩 저장이 아니다. 저장공간 추정치는 사이트 전체에 대한 브라우저 추정치이며 보장된 여유 용량이 아니다. 자동 서버 전송이나 AI 요청은 하지 않는다.

## 배포·롤백
신규 독립 경로와 전용 IndexedDB만 사용한다. 배포를 롤백해도 기존 서버 데이터는 영향을 받지 않지만, 이전 버전은 새 로컬 사진함에 접근하지 못할 수 있다. 롤백 전 사용자가 필요한 사진을 각 파일로 내려받아야 한다. 사진함 삭제나 DB 초기화는 배포·롤백 과정에서 자동 실행하지 않는다. 합성 브라우저 복원·실패 테스트와 별도로 실제 Android/iOS에서 저장·재접속·내보내기를 확인해야 한다.
