# ATLAS 8차 · Laya 132건 모바일 집중 검수 UX — 2026-10-26

## 기존 문제
- 11개 언어별 12개 가상 안전문장을 모두 렌더링하는 긴 개발자 화면이 모바일 관리자에게 스크롤 과부하를 유발했다.
- 언어별 미검수만 모아 선택하거나, 다음 검수 문장으로 이어가는 동선이 없어 검토 누락 가능성이 있었다.
- 브라우저에서만 유지하는 검수 기록을 파일로 다운로드하지 않으면 사라질 수 있었으나 진행 중 경고가 충분히 눈에 띄지 않았다.

## 구현
1. 기본으로 **한 건씩 집중 검수** 모드. 이전/다음 문장, 12개 항목 바로가기 제공. 필요하면 기존 12건 전체 화면으로 전환.
2. **미검수만 보기** 버튼을 통해 진행대상 선별. 검토 완료 버튼을 누르면 자동으로 같은 언어의 다음 미검수로 이동. 언어가 완료되면 완료 상태 안내.
3. 언어별 12건·전체 외국어 120건 검수 현황을 계속 보여주며, 기존 미검수·문구 반복 경고를 유지.
4. 변경 사항이 생기면 **JSON 저장 필요**를 표시하고, 브라우저 종료 시 저장 여부를 확인하는 beforeunload 경고 추가. 저장 버튼은 다운로드 동작을 요청하며 다운로드 완료 여부는 사용자가 기기에서 확인해야 한다.
5. 기존 JSON v1/v2 데이터·실험결과 비교 규칙·6대 PSI 지표, 위험성평가, TBM 및 근로자 포털은 변경 없음.

## 자동검증
- 11개 언어 각각 12건 순서·커서 범위, 미검수만 선택, 완료 다음 단계, 마지막 항목 래핑, 빈 목록, 132건 원자료 불변성 확인.
- 기존 `verify:ci` (타입/릴리즈/무료한도/보안/모든 Vitest 테스트), 7개 제품 통합 Playwright, SHA 일치 Preview READY 이후 main 병합.
- 실제 Android 실기기·시각/터치 사용성 시험은 별도 실기기 검증 필요. 자동 Browser QA만으로 실기기 검증을 주장하지 않는다.

## 보안·비용·책임
- 검수자료 브라우저 상태만 사용, 저장 선택 시 JSON 다운로드. `localStorage`나 외부 서버로 자동 저장하지 않는다(공유 기기 개인정보 잔존 방지).
- 검수자 실명·근로자 개인식별정보 입력 금지. 검수자 코드의 신원·번역 의미는 실제 현장 관리자 검토가 별도 필요.
- Vercel Hobby 요금제 유지; 신규 서버 함수·cron·AI/모델 호출·DB 마이그레이션 0.
- 이번 변경으로 함수 호출을 추가하지 않는다는 뜻이지 계정 전체 무료 잔량과 정식 상업화 가능성을 보증하지 않는다.
- Laya 분류 성능은 여전히 연구 미검증이며 안전 자동판정·작업중지 승인·산업안전 위법성 자동 확정에 적용하지 않는다.
