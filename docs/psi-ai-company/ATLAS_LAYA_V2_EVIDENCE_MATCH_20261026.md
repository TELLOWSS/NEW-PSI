# ATLAS 7차 — 132건 Laya 검수본·예측파일 일치 게이트

## 발견한 현장 판단 위험
v2는 132건의 기준 데이터·레이블·검토 상태를 검증하지만, 사용자가 **현재 열어둔 검수표와 다른 시점의 시험 결과 JSON**을 가져오는 상황을 막지 않았다. 파일 단독 평가에는 유효해도 화면의 현지어 검수와 관계없는 점수가 표시될 수 있었다.

## 이번 실제 수정
1. 평가파일의 132건 사례와 현재 브라우저의 검수표 132건을 ID별로 비교한다. 언어/한국어 기준/기대 레이블뿐 아니라 **현지어 문장·검토 상태·검수자 코드·검수 시각** 중 하나라도 다르면 평가 파일을 차단한다.
2. 사용자에게 "불러온 결과가 현재 검수표와 N건 다릅니다. 시험에 사용한 검수표를 다시 열어주세요"라고 안내한다.
3. 한국어 12건 기본, 외국어 120건을 기준으로 언어별 검수/미검수/전 언어 준비 범위를 표시한다.
4. 동일 언어의 서로 다른 안전상황에 동일한 번역문이 반복되면 수동 대조 경고를 표시한다. 공통 단어 반복이나 현장어 관용구 때문에 **반복 자체를 틀린 번역으로 단정하지 않으며** 자료 제출을 강제로 막지 않는다.
5. 위 기능은 Vercel API, AI 모델, DB, 원격 폰트 호출 없이 React 메모리에서 동작한다.

## 담당별 검증
- 안전관리: 실제 위험을 `none`이라고 잘못 분류한 False Negative를 반드시 별도 유지. 6대 PSI 지표 변경 금지.
- 다국어: 통역자 코드/시간은 본인 확인·의미 정확성 인증이 아니며 실제 확인서와 교차 확인이 필요하다.
- QA: 132개 항목별 개별 변형, 1,000회 결정적 무작위 결과파일 불일치 시험, 순서 재배열 동일자료 허용.
- 엔지니어링: 결과파일에서 이전 시점 문장 한 글자만 달라도 점수 표시에 앞서 불일치 차단.
- 비용/배포: Hobby 유지, 함수/cron/model/AI 호출 추가 0건. 현재 Vercel 실제 Usage 잔여량은 조회하지 않았음.

## 지원 범위/한계
- v1 33건과 v2 132건 스키마 및 이미 작성된 결과는 보존.
- 변경 전 저장했던 결과도 열 수 있지만 **그 파일과 동일한 당시의 검수표가 현재 화면에 열려 있어야** 평가에 사용 가능.
- 단순 JSON 비교는 파일이 실제 Laya 모델에서 만들어졌는지·검수자가 누구인지 증명하지 않는다. 보고서에서는 항상 `safetyApproved: false`, `provenanceVerified: false`, `reviewerIdentityVerified: false`.
- 정식 상업화 시 데이터 출처 증빙·현장 검증·숙련 통역자 서명/기록·모델 체크포인트 라이선스 별도 필수.
