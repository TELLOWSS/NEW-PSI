# ATLAS · 11개 현장 언어 교육자료 검수 (2026-10-26)

## 실제 구현
- 기존 위험성평가 교육자료 스튜디오 > 5. 출력 확인 화면에 11개 언어 점검 패널 추가.
- 현장언어 코드는 기존 CURRENT_SITE_TRAINING_LANGUAGE_CODES의 한국어 1 + 외국어 10을 그대로 재사용.
- 언어별 상태: 한국어 원문 / 번역 필요 / 원문 변경 후 재번역 / 형식 대조 필요 / 형식 확인.
- 구조화된 번역에서 영상 장면 수와 필수 내용, 사고사례 수, 회의자료 근거 상등급 위험 및 조치, 중점관리·공지·질문 수를 한국어 초안과 비교.
- 기존 텍스트 번역은 자동 합격 처리하지 않고 대조 필요 표시. 원문 변경 후 기존 번역은 구버전 표시.
- 언어 카드 클릭으로 번역 좌우 대조 이동. 누락 언어 클릭 시 기존 다국어 생성 단계로 안내.
- 관리자·통역자에 의한 위험명/작업중지/금지/보호구 착용의 의미·명령 강도 검수 필요. **형식 확인은 번역의 언어적 정확도, 안전교육 이해도, 실제 작업의 안전승인을 뜻하지 않는다.**

## Vercel Hobby 비용/상업화 경계
- 이번에는 Laya 모델 및 ONNX/AI API를 설치하지 않았다. 이는 기존 번역에 대한 정적 형식 진단이며 모델 평가나 의역 검증 아님.
- 브라우저 로컬 연산만 추가. 신규 API 함수, 예약 실행, 유료 호출, DB 마이그레이션, 외부 서버 전송 0.
- vercel.json에서 Fluid true와 기존 30/90/240초 함수 설정 유지.
- 이 기능이 신규 함수 사용량을 증가시키지 않는 것은 코드 경계에 대한 설명이며, **기존 앱의 실제 월간 CPU·메모리·함수 호출 남은 무료 한도를 보증하지 않는다**.
- 현재는 개발단계로 유료 Vercel 전환하지 않음. 정식 상업운영 확정 시 별도 이용약관/라이선스 확인.
