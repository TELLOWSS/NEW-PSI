# ATLAS — NEW-PSI 오픈소스 검증 기반 고도화 로드맵 (2026-10-26)

## 결정된 운영 원칙
- **상업화 가능한 제품 아키텍처**를 전제로 설계하되 현재는 개발·시험 단계이므로 **Vercel 유료 플랜 전환·결제 설정 변경을 하지 않는다**.
- NEW-PSI 메인, Inspector, 별도 협력사 안전관리비 서비스, SMART TBM, PSI ZERO DAY의 인증·저장·과금 경계를 유지한다.
- 민감한 현장 사진·근로자 신원·서명·음성 데이터는 외부 OSS 도구로 자동 전송하지 않는다.
- AI의 안전등급 판정/작업중지/개선완료 자동 승인은 금지하며 관리자의 검토를 유지한다.
- 유튜브 제공 영상에서 언급된 **정확한 10개 프로젝트는 자막·목록 미확보**. 검증된 별도 7개 후보를 영상의 10개로 둔갑시키지 않는다.

## 1단계: 교육 시각화 로컬 내보내기 (PR #101)
**상태:** GitHub 기능 구현 및 릴리즈 검증 진행 중. 검증 및 Vercel Ready 전에는 완료라고 표시하지 않는다.

- 기존 `pages/A4EducationMaterial.tsx` 3단계 검수에서 300초 영상 장면표 JSON을 직접 저장한다.
- 장면 합계·장면별 최소 5초·제목·내레이션·화면지시가 모두 갖춰져야 한다.
- 기존 5단계 교육내용을 외부 폰트/스크립트/원격 이미지 없는 standalone SVG로 저장한다.
- 회의자료에 명시된 상등급 위험만 사용하고, 관리자 미확인 상태를 그대로 표시한다.
- 다운로드는 브라우저 로컬 Blob을 사용한다. FFmpeg, 외부 AI, DB, 배치 서버는 사용하지 않는다.
- **HyperFrames/Diagram Design의 코드를 설치한 것이 아니며** 상용 교육영상·도식 제작을 위한 내부 산출물 생산 단계다.

## 2단계 후보: HyperFrames 교육영상 오프라인 파일럿
- 합법적 라이선스·NOTICE·코덱/음원/폰트/이미지·원본 provenance 고정.
- 민감자료 없는 합성 안전교육 장면 30초 오프라인 샘플 렌더. 300초 영상으로 확장 전에 CPU/시간/파일용량/재생 검증.
- 서버리스 Vercel Hobby에서 영상 렌더링 미실행. 관리자 기기 또는 별도 권한 격리된 배치작업만 검토.
- 자동 배포 연결 전 관리자 음성·영상 품질 승인과 화면 전환/자막/접근성 확인.

## 3단계 후보: Laya 11개 언어 사전 분류 벤치마크
- ko, vi, cmn, km, mn, th, my, id, ru, uz, kk별 **위험 요인 텍스트만** 개인식별자 제거 후 합성 평가.
- 원본 모델 체크포인트의 이용권·규모·가중치 확인 및 클라이언트/서버 비용 검토.
- 위험 미탐과 부정확 번역은 사용자에게 보이지 않는 Shadow Mode에서 측정. 안전조치 자동 승인 금지.
- 오분류 분석·언어별 성능 표준/관리자 최종 승인 없이 운영 API나 기존 PSI 점수에 연결하지 않는다.

## 4단계 후보: Shaders UI 성능 검증
- 테스트 영역: 메인 헤더 또는 로딩 장식 한정. 관리자 판정 카드·고위험 경보의 판독성은 그대로 유지.
- 360px 모바일 + WebGPU 미지원 기기에서 정적 폴백, reduced-motion, 접근성, 렌더 FPS/배터리 기준 확보.
- GitHub MIT 엔진과 웹 프리셋의 별도 권리 범위 구분. Pro 프리셋 무단 복제 금지.
- 환경 성능 제약을 넘으면 기획을 폐기하고 현재 정적 그래픽 유지.

## 검증 및 상용화 게이트
1. CI 통과(단위·타입·릴리즈) + 7개 제품 합성경로 회귀 검증.
2. 실제 운영 리소스 비용과 Android 파일 저장 동작 별도 검증.
3. 원본 라이선스 원문/NOTICE/폰트·모델·이미지·음악·특허 검토.
4. 기능별 feature flag, 테스트 롤백/회귀, 실사용자 관리자 확인.
5. **유료 호스팅 및 서비스 이용조건 전환은 정식 상업 서비스 출시가 확정된 시점에 별도 결정**. 현재 시점 유료 변경 금지.

## 사용자 사용법
PSI 관리자 로그인 → 위험성평가 교육자료 스튜디오 → 3. 5단계 검수 → 교육영상 장면 300초 확인 → `5분 영상 장면표 저장(JSON)` 또는 `5단계 교육 흐름도 저장(SVG)`.

주의: 두 파일은 브라우저 다운로드로 생성하는 **제작 초안**이며 AI가 최종 영상·법정 교육기록을 완성한 것으로 오인하지 않는다.
