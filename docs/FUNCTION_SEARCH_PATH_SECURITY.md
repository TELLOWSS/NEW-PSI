# 기존 함수 검색 경로 고정

2026-09-30. 운영 DB의 함수 6개를 문자열 값을 가린 상태로 점검했다. `psi_is_admin_request()`는 설정값과 요청 헤더를 비교하고, 나머지 5개 트리거 함수는 `new.updated_at=now()` 또는 동등한 대입만 수행한다. 모두 공개 스키마의 테이블이나 사용자 정의 함수에 의존하지 않는다.

`20260930003000_function_search_path.sql`은 이 6개의 검색 경로를 `pg_catalog,pg_temp`로 고정한다. 호출자의 스키마에 있는 동일 이름 함수가 관리자 확인이나 수정 시각 계산을 가로채지 못하도록 한다. 함수 본문·실행 권한·보안 모드·트리거 연결·기존 기록은 변경하지 않는다.

PostgreSQL 회귀 검사는 악의적인 호출자 검색 경로와 위조 `now()`/`current_setting()` 함수가 있어도 잘못된 관리자 헤더가 거부되고 정상 헤더가 통과하는지, 5개 수정 시각 트리거가 실제 시간을 기록하는지 확인한다. 적용 전후 본문·권한·보안 모드가 동일하고 재적용이 가능한지도 확인한다.

지정된 호스팅 DB에 적용했고 `supabase/tests/function_search_path.sql`의 실제 함수 검증이 통과했다. 합성 설정값과 임시 테이블만 사용하며 전부 롤백했다. Security Advisor는 Errors 0건, Warnings 7→1건이며 남은 항목은 public 스키마의 vector 확장이다. Node 22 단일 worker 전체 테스트는 89개 파일/691개 통과했다.

## 교육 음성 비공개 전환 준비

현재 `WorkerTraining`은 버튼 동작으로 `training_sessions`를 직접 조회하며 응답의 `audio_urls`를 재생한다. 관리자 음성 업로드 역시 공개 URL을 기록한다. 기존 버킷만 비공개로 바꾸면 이 재생 경로가 끊긴다.

다음 구현에는 기존 gateway 함수 안의 서명 교육 링크와 근로자 인증을 확인하는 세션 조회/재생 URL 발급 경로가 필요하다. 클라이언트가 보낸 파일 URL은 서명하지 않고, 검증된 세션의 언어별 저장 경로만 서버에서 정한다. 유효기간은 교육 링크·근로자 인증 만료를 넘기지 않으며 재발급은 사용자 재생 동작에 한정한다. 직접 세션 조회와 공개 URL 노출을 제거하고 관리자 미리보기도 새 경로를 사용해야 한다.

이 경로의 실제 근로자·관리자 흐름을 검증한 뒤 버킷 공개 설정과 기존 자료 경로를 전환한다. 이번 검색 경로 보완은 그 전환 완료를 뜻하지 않으며 전체 공용 SaaS 출시 차단을 유지한다. vector 확장의 스키마 이동 역시 기존 임베딩/RPC 의존성 조사 후 별도로 처리한다.
