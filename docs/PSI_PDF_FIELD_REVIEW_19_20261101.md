# NEW-PSI 19차 · PDF 현장형 개인정보 가림 후속 개선 (2026-11-01)

## 기준선
- 18차 PR #194, main `8a05c9d2`의 PDF 출력물 재렌더링·9점 표본 검증을 기반으로 개선한다.
- 18차 변경은 당시 GitHub에 병합되었으나 Vercel build-rate-limit 때문에 운영 배포가 별도 미완료였다.
- 이 문서는 코드 범위와 운영 검증을 구분한다. 테스트가 완료되기 전 운영 사용을 완료로 표기하지 않는다.

## 19차 변경 범위
1. **PDF 페이지 검토 상한 5 → 10**: 사용자가 제공한 언어별 종합 위험성평가 10페이지 PDF를 1개 파일로 읽을 수 있도록 입력 상한을 확대. 기존 원본 최대 12MB, 개별 렌더 최대 8백만 픽셀, 완성 PDF 최대 40MB 제한은 그대로 유지한다. 페이지마다 별도의 육안 검토 체크가 필수다. 11페이지 이상은 기존처럼 즉시 거부한다.
2. **터치 모드 분리**: 기본 모드는 '화면 이동'. 이때 페이지의 가로·세로 스크롤을 브라우저 기본 터치로 허용하며 드래그해도 검정 영역은 만들어지지 않는다. 사용자가 '개인정보 가림'을 명시적으로 누른 후에만 포인터 드래그가 검정 영역으로 기록된다. 가림을 취소·전환할 때 임시 선택은 폐기된다.
3. **최종 출력 파일 검사 보강**: 출력 PDF를 다시 렌더링한 뒤 지정 가림 영역의 내부 픽셀을 최대 32행 단위로 읽어 검은 불투명 픽셀인지 검사한다. 전체 이미지 한 번에 복사하지 않고 청크로 검사한다. 경계에서 PDF 스케일 보간이 발생할 수 있어 최대 1픽셀 가장자리는 제외한다. 이전의 내부 9점 표본 검사보다 촘촘하나, 가림 범위 바깥 개인정보를 검출하는 기능은 아니다.
4. **회귀 테스트**: 10페이지 허용·11페이지 차단, 출력 PDF의 내부 1픽셀 가림 누락 검출, PDF 텍스트·주석·첨부파일·양식 필드 거부.

## 사용자 사용 절차
1. 12MB 이하/10페이지 이하 로컬 PDF를 불러온다. 원본 SHA-256을 확인한다.
2. 화면 이동 모드로 페이지를 확인한다. 100%·150%·200% 확대 및 스크롤을 사용한다.
3. 가릴 곳이 있으면 '개인정보 가림'을 눌러 문서 안의 이름·전화번호·서명·식별번호 등에 검정 영역을 지정한다. 이동할 때는 화면 이동 모드로 돌아온다.
4. 모든 페이지를 빠짐없이 검토한 후 검토 체크한다.
5. 로컬 검토 PDF와 SHA-256 manifest JSON을 생성한다. 저장한 PDF를 별도 뷰어에서 다시 열어 육안 확인한다.

## 허위 완료 판정 금지
- 개인정보가 검정 영역 밖에도 남을 수 있다. PDF 이미지 자체에 포함된 글씨·작은 식별정보·문맥 정보는 별도 육안 검토 대상이다.
- 출력물의 텍스트 추출/주석/첨부/폼 부재와 가림 내부 검정 픽셀 여부를 확인하는 것은 모든 개인정보의 제거를 보증하지 않는다.
- 원본의 작성시각·서명 진정성·수정 이력, 관리자의 독립 승인, 실제 서버 반출 로그와 현장별 RLS DB 적용은 이번 변경에 포함되지 않는다.
- 실제 Android 기기(세로·가로) 및 PC에서 10페이지 문서를 불러와 가림·되돌리기·재열람·PDF 저장·추출 재검사를 실시하기 전에는 실기기 통과로 판정하지 않는다.
- GitHub `main` SHA와 Vercel Production READY의 SHA가 같지 않으면 운영 배포 완료가 아니다.
