# 2025년 최초 자기규율 위험성평가 기록지 OCR 병행 지원 확인

기준: 2026-11-22 / Draft PR #237 / NEW-PSI만 적용

## 사용자 첨부 원본
- 2025-02-13 갱폼 스캔 PDF: 3쪽, 각 이미지 스캔(텍스트 레이어 없음). 상단 교육일·이름·근무 공종, 본문 Q1~Q5, 하단 이름·서명.
- 편집용 PPTX 6장: 한국어 1장, 중국어 2장, 러시아어 1장, 미얀마어 1장, 베트남어 1장. 5문항 구조 동일.
- 주의: PPTX의 6번째 중국어 슬라이드 Q3 예시 '顶部/中等/负载'는 높은/중간/낮은 위험 등급의 올바른 번역이 아니며 중국어 원어민 수정 검토 필요. 다른 언어도 실출력·원어민 확인 전 승인 불가.

## 기존 코드/보강
- 기존 Q1~Q5 모델·OCR 서버·기존 호환 OCR·관리자 검토 및 점수 환류 소스는 저장소에 존재. 2025년 전용 정밀 좌표 OCR 엔진이 남아 있는 것은 확인되지 않음.
- 현재 최신 양식의 하단 이름·공종 위치 고정 프롬프트는 초기 양식의 상단 인적사항을 잘못 읽을 수 있어 양식별 위치 지시로 보강.
- 한국어/중국어/러시아어/미얀마어/베트남어 초기 위험성평가 제목과 공종 레이블 + Q1~Q5 구조를 추가하되 일반 체크리스트는 차단.
- Q1은 실제 위험작업이지 jobField가 아니며, 상단 이름과 하단 서명은 동일 인물로 자동 추정하지 않음. 국적·이름·공종 불분명 시 관리자 검토.
- tests/ocrLegacySelfRegulationForm.test.ts는 개인정보 없는 합성 7개 서식과 오문서/누락문항/신원불확실성을 점검. 실제 손글씨 인식 정확도 보증이 아님.

## 기존 업로드 제약 및 실제 검수
- 현재 PDF는 파일당 1페이지만, 2.85 MiB 이하로 업로드 가능. 첨부 3쪽 PDF 원본은 그대로 분석 불가. 각 페이지별 PDF 또는 JPG로 분리해 별도 업로드.
- PPTX 자체 직접 OCR 불가. 언어별 양식 출력 후 수기 작성해서 1쪽 PDF/사진으로 수집.
- 사용자의 실제 스캔, 이름, 서명 등 개인정보를 GitHub 소스·테스트에 올리지 않음. 실제 OCR API 호출/유료 승인 미실시.
- 미검증: 3장 실OCR Q1~Q5·날짜/이름·공종 일치율, 최신 2026 양식 회귀, 원어민 문구·A4 폰트/가독성, 현장 기기.
- CI는 최신 HEAD에 따라 별도 판정. 사용자 승인 전 main/Production 병합·배포 보류.

다음: CI 3종 확인·실패 수정 → 승인된 환경의 2025 수기 3장 실제 OCR → 다국어 6장 모의 필기 OCR 및 원어민 검수 → 기존 L06 근로자 직접 제출 병행 설계.

- 추가 확인: 구형 Q3 위험등급 ‘상/중/하’는 한 글자로 정상 작성되지만 기존 OCR 응답 커버리지 검사는 2글자 이상만 인정했음. `utils/ocrRoutingQuality.ts`에서 실제 Q3 원문인 상/중/하/高/中/低 1글자만 유효하게 세고, Q1/Q2/Q4/Q5는 기존 최소 조건을 유지. 누락·국적·이름 불확실은 여전히 관리자 검토 대상.

## 2026-11-22 후속: Q1~Q5 필기 원문 커버리지 일원화
- 서버 `api/gateway.ts`, 기존 `services/geminiService.ts`, 관리자 화면 `pages/OcrAnalysis.tsx`의 2글자/번역 포함 판정을 공통 `utils/ocrQuestionCoverage.ts`로 통합했다.
- 근로자 원문 `answerText`만 작성 증거. 번역만 존재하면 미작성 및 관리자 대조 대상. Q3 단일 '상/중/하' 및 중국어 '高/中/低'만 예외; Q1·Q2·Q4·Q5의 한글자 기입과 잘못된 문항/중복은 자동 완료 처리 금지.
- 기존 원본이미지, 데이터 기록/승인, OCR 과금 경로는 변경하지 않음. 합성 테스트/CI 증거는 실제 수기 인식률과 다름.

## 2026-11-22: 여러 장 PDF의 기기 내 분리 기능
- 관리자가 '여러 장 PDF 페이지별 나누기'를 직접 눌러 파일을 선택하면 기존 pdfjs-dist를 브라우저에서만 실행해 PDF 각 페이지를 개별 JPEG 파일로 만든다. 파일 선택으로 유료 OCR이나 서버 전송/기록 저장을 실행하지 않는다.
- 최대 12페이지, 20MB 입력, 각 이미지 2.85MiB 출력 제한. 모든 페이지 성공 후만 선택 목록에 추가하며 중간 변환 실패 시 기존 목록 유지. 원본 PDF는 기기에 남아 있고 변환 이미지는 OCR 전에 육안 대조가 필요하다.
- 기존 1페이지 PDF 전송 정책은 변경하지 않고, 다쪽·용량초과·열기 실패 PDF의 '분석 가능' 표시 오류를 수정한다. 페이지별 출력은 사진 픽셀 기반 복제이며 원본 필압·글씨 유지 보증은 아니다.
- 실제 2025년 3장 스캔 및 Android 기기 렌더링, 수기 OCR 정확도 실측은 아직 미검증.
