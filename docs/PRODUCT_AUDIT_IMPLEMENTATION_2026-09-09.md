- 합성 기록의 개인 리포트 연결, 교육환류 PC·모바일 화면 확인.
- 브라우저 검사에서 포착된 페이지 오류 및 가로 넘침 없음.
- API는 검증용 응답 또는 차단 상태. 실제 서버 저장·실제 OCR·모국어 자연스러움을 증명하는 검사가 아님.

## 2차 — 분석 화면과 차트 개선

- 대시보드 상단을 간결하게 정리하고, 분석 패널 제목·집계 단위 버튼을 확대했습니다.
- 상세 분석의 12개 이동 카드는 기본 접힘으로 변경했습니다. 키보드로 펼칠 수 있으며 기능은 삭제하지 않았습니다.
- 세션 없이 진입해 안내에 막히던 교육 진단 링크는 교육환류의 자료 준비 화면으로 연결했습니다.
- 레이더는 5개 역량을 각각의 만점 대비 0–100%로 정규화합니다. 실제 원점수는 툴팁과 점수표에 유지합니다.
- 반복위반 감점은 레이더·취약 순위에서 분리했습니다. 감점 0점이 취약 항목으로 표시되지 않으며, 낮을수록 좋은 지표임을 설명합니다.
- 차트에 전달된 비정상·누락 점수는 0점으로 변환하지 않습니다. 단, 상위 집계에서 이미 0으로 보정된 구버전 자료를 판별하는 문제는 별도 개선 대상으로 남습니다.
- 위험 배지는 공통 설정의 점수 기준을 사용합니다.
- 추이 그래프는 최초 표시·집계 단위 변경·화면 크기 변경 시 최신 구간을 보여줍니다. 이전 구간은 가로 이동으로 확인합니다.
- 검증: 71개 테스트 파일 / 566개 테스트 통과. 타입 검사·빌드 및 기존 계약 검사 통과. 격리 브라우저에서 메뉴 키보드 조작, 교육 연결, 네 가지 기간의 최신 막대 표시를 확인합니다.
- 실제 기록 수정·유료 AI 호출·서버 저장구조 변경은 없습니다. 근로자 식별과 집계 모집단 통일, 백업·권한·원어민 검수는 잔여 과제입니다.

## 3차 — 식별 기준과 백업 회귀 검증

- 핵심 지표에 공통 근로자 식별 정책을 적용했습니다. 서로 다른 확인 ID는 동명이인이라도 합치지 않습니다. 확인된 동일 ID는 공종이 바뀌어도 동일 인원으로 처리합니다.
- 미확인 기록은 이름만으로 합치지 않습니다. 대시보드에 미확인 건수와 실제 인원과의 차이 가능성을 안내합니다. 기존 기록의 ID는 변경하지 않습니다.
- 국적 분포도 이름별 집계 대신 공통 최신 기록 선택을 사용합니다.
- 상세 공종·국적 평균은 현재 범위의 최신 기록 1건만 사용하며, 개인 이력은 유지합니다. 최신 점수가 누락·비정상이면 과거 점수 또는 0점으로 대신 표시하지 않고 점수 비교 집계에서 제외합니다.
- 개선 신호는 0~20 범위를 벗어난 값을 제외합니다. 핵심 집계 규칙 버전은 `psi-core-metrics-2026-09-09-v2`입니다.
- 백업 변환 → v2 내보내기/읽기 → 사전 검증 → 안전 병합의 통합 테스트를 추가했습니다. 반복 복원 시 추가 기록 없음, 원문·점수 보존, 최신 PC 수정 보호를 확인합니다.
- 12개월·5,000개 합성 레코드의 백업 검증을 추가했습니다. 이는 278MB 실제 이미지 백업을 브라우저 저장소에 복원한 실측 검증이 아닙니다.
- 테스트 73파일 / 572개 통과. 실제 개인정보·기록 삭제·유료 OCR 호출 없이 수행했습니다.
- 잔여: 다른 레거시 화면의 독립 집계, 누락 세부점수의 상위 보정, 실제 대용량 이미지 복원 및 저장공간 한계, 회사/현장 권한·이전 동의, 원어민 검수.

## 4차 — 실제 백업의 격리 복원 검증

- 원본을 변경하지 않고 PC의 저장소 외부에 월별 호환 사본을 생성했습니다. 개인정보 파일·상세 결과는 저장소에 포함하지 않습니다.
- 격리된 브라우저의 실제 백업 불러오기와 재접속 후 저장 데이터를 대조했습니다. 외부 API는 차단하고 운영 저장소는 사용하지 않았습니다.
- 첫 대조에서 원문 양끝 공백 손실을 발견했습니다. 원문은 표시용 이름 정리와 분리하여 문자열 그대로 보존하도록 수정했습니다.
- 수정 후 월별 복원 및 이미지·원문·점수·등급 대조가 통과했습니다. 상세 수치·사본·사용 안내는 사용자의 비공개 PC 폴더에만 저장했습니다.
- 빈 임시 저장소 검증이며 실제 운영 PC의 기존 기록과의 충돌 검증은 아닙니다. 기존 자료를 먼저 백업하고 사전검증 안내를 확인해야 합니다. 전체 재OCR는 수행하지 않았습니다.
