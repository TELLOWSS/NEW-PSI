# NEW-PSI 16차 — 현장 사진의 실제 픽셀 가림 및 내부 검토 사본

## 운영 목적
사고 조사·위험성평가 교육·현장조치 사진의 증빙 가치를 훼손하지 않도록 **원본 ZIP은 그대로 보관**하고, 외부 공개 여부를 검토하기 위한 별도 사본에서 인적 식별정보를 선택한 영역만 가린다.

## 구현한 동작
1. OCR 관리자 기록 상세 → 증빙 제출 전 검토 → 원본 ZIP 해시 대조 및 근로자 기록 ID 확인.
2. 사진 개인정보 가림 영역에서 ZIP에 포함된 JPEG/PNG/WebP 원본을 선택한다. 생성 직전에는 ZIP 전체 SHA-256과 이미지별 SHA-256을 **다시 검증**한다.
3. PC 마우스·모바일 손가락으로 사진 위를 드래그해 직접 가릴 영역(최대 40개)을 지정한다. 표시 크기에서 전체 이미지의 정규화 좌표로 변환해 원래 해상도에 적용한다. 잘못된 크기·범위·2천만 픽셀 초과 자료는 차단한다.
4. 원본 이미지 바이트는 **새 파일에 복사하지 않는다**. 브라우저 캔버스에서 원래 크기로 이미지를 다시 그리고 사각형의 실제 픽셀을 완전 불투명한 검정색으로 덮어쓴다. 흐림/오버레이만 하는 방식이 아니다.
5. 캔버스에서 새 PNG를 렌더링한 뒤 eXIf/tEXt/iTXt 등 부가 메타데이터 청크를 제거한다. 선택한 영역의 RGBA가 모두 (0,0,0,255)인지 확인한다.
6. 새 내부 검토 ZIP에는 `MASKED_IMAGE.png`, `REVIEW_MANIFEST.json`, `SHA256SUMS.txt`만 포함한다. 원본 이미지/원본 ZIP/EXIF/GPS 복사 없음.
7. 새 PNG의 SHA-256과 ZIP 전체 SHA-256을 구분한다. 해당 SHA는 **사본 무결성 비교용**이지 과거 사진의 존재시점이나 현장 안전관리 적합성을 소급 인증하지 않는다.
8. 사진을 바꾸면 이전 가림 영역과 개인정보 확인 상태를 초기화한다.

## 안전·법적 제약
- **자동 얼굴·명찰·전화번호·차량번호 탐지는 구현하지 않았다.** 가림 영역을 사람이 직접 지정한다.
- 가리지 않은 영역에 사람, 이름, 차량번호, 배경 인쇄물, 화면, 다른 식별 단서가 남을 수 있다. 사진 전체를 확대해 육안 검토해야 한다.
- PNG 가림을 수행했어도 별도 결재 없이 외부에 제출할 수 없다. 사용자 체크는 서버 권한승인·외부 반출 승인·감사 이력이 아니다.
- 사진 원본은 수정하거나 사후 자료를 사고 전 사진처럼 변경하지 않는다. 원본 SHA와 사본 SHA는 각각 보관한다.
- PDF 페이지 가림, 다국어 자유서술 및 이미지 OCR 기반 탐지, 자동 사진 개인정보 식별, 수동 사본 검수 이력/로그는 별도 후속 기능이다.
- 브라우저/장치 메모리, 이미지 회전·EXIF 방향, touch/pointer 좌표, 고해상도 가림 정확성은 실제 Android/태블릿/PC 장치에서 추가 시험해야 한다.
- P03/P04 원본 수신 서버 원장, P05 기업/현장 RLS, P12 제출 승인·발송 이력은 **운영 Supabase 미적용** 상태이다.

## 검증 기준
- 입력: 원본 ZIP 해시·근로자 기록 ID와 이미지 해시가 일치하지 않으면 실패.
- 출력: 마스킹된 PNG의 실제 검정 픽셀, 원본 사진 제외, PNG 메타데이터 청크 제거, ZIP 파일 구성, 파일별·ZIP 전체 SHA를 자동검증.
- UI: 가림 사각 영역을 원본 픽셀로 변환, 1~40개 제한, 미선택 사진 복사 금지.
- 전체 릴리스/브라우저 회귀 및 GitHub main 병합 뒤에도 Vercel READY와 실제 장치 실사용 검증은 별도다.

**16차 완료 판정: 사용자가 직접 지정한 사진 영역의 픽셀 가림과 내부 검토 사본 코딩·자동검증. 외부 제출 승인 또는 완전 비식별화 완료가 아님.**
