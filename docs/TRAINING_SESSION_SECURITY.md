# 교육 자료 서버 접근 경계

2026-09-30. 운영 training_sessions에는 익명·일반 계정의 SELECT 정책 `training_sessions_select_public using(true)`와 테이블 권한이 남아 있었다. 근로자 화면은 PR #17부터 교육 링크와 근로자 인증을 확인하는 training.material 경로를 사용하므로 직접 읽기 권한을 제거할 수 있다. 화면·컴포넌트·서비스 코드에 직접 조회가 없는 것을 확인했다. DB 메타데이터 조사에서 이 테이블을 참조하는 뷰와 등록된 함수 의존성 및 함수 본문의 직접 테이블 참조는 발견되지 않았다. 동적 SQL의 모든 우회 경로를 완전히 감사했다는 뜻은 아니다.

`20260930004000_training_session_server_boundary.sql`을 지정된 운영 DB에 적용했다. PUBLIC·anon·authenticated의 테이블 및 열 권한을 회수하고 RLS를 강제한다. 기존 정책 객체와 표현식은 보존하며 일반 계정에 항상 false인 restrictive 정책을 추가한다. 이후 넓은 permissive 행 정책을 추가하더라도 이 제한 정책을 그대로 유지하는 한 일반 계정의 행 조회·삽입·수정·삭제는 허용되지 않는다. 기존 service_role의 BYPASSRLS 및 CRUD 권한을 확인하고 유지한다. 상속된 브라우저 권한이 남거나 서버 권한이 없으면 트랜잭션이 실패한다.

교육 내용·번역·음성 위치·교육 기록과 파일은 변경하거나 삭제하지 않았다. 스토리지 공개 설정과 관리자 API 계약도 그대로 유지한다. 관리자 서버의 기존 목록·등록·수정·삭제 경로와 인증된 근로자 자료 경로가 이 테이블을 사용한다. 다른 앱이 브라우저에서 training_sessions를 직접 읽던 연동은 인증된 서버 경로로 전환해야 한다.

회귀 검사는 마이그레이션 재적용, 테이블/열 권한 차단, 기존 정책과 자료 보존, 서버 CRUD, 미래의 넓은 정책·행 권한 재부여에도 restrictive 정책이 작동하는지 확인한다. 91개 파일/703개 테스트, verify:fast·타입 검사·빌드 통과. 호스팅 DB의 읽기 전용 검사도 PASS이며 실제 교육 내용이나 파일 위치는 반환하지 않았다.

음성 버킷은 아직 공개다. 사용자가 테스트 교육·등록 테스트 근로자가 없다고 확인했으므로 실제 본인 확인·재생·만료 갱신·서명 제출 검증과 버킷 비공개 전환은 남아 있다. 이번 변경은 기업별 기존 교육 소속 매핑을 완료하지 않으며 공용 SaaS 출시 차단을 유지한다.
