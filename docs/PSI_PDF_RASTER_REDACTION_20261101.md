# PSI 17차: PDF 이미지 가림 검토본

기존 PSI 증빙 ZIP에는 PDF가 포함되지 않으므로 이 기능은 **직접 선택한 로컬 PDF**에만 작동한다. 기존 근로자 기록에 자동 귀속되거나 원본의 작성일이 확인되는 것은 아니다.

## 절차
1. 최대 12MB·5페이지인 로컬 PDF를 선택하고 SHA-256 계산.
2. PDF.js로 페이지를 브라우저 화면에 렌더링한다. PC·모바일 드래그로 검은 가림 영역을 선택한다.
3. 각 페이지마다 개인정보 포함 여부를 수동 확인한다. 영역을 바꾸면 해당 페이지 확인 상태를 해제한다.
4. 출력 시 원본 해시·페이지수·모든 페이지의 확인 완료를 재검증한다.
5. 각 페이지를 이미지로 다시 렌더링하고 검정 불투명 픽셀을 적용·검증한다. 페이지 이미지의 PNG 부가 메타데이터를 제거한다.
6. 새 PDF에는 원본 PDF 텍스트, 주석, 폼 필드, 첨부파일을 넣지 않는다. 출력 후 PDF.js로 텍스트·주석·첨부·폼 필드가 없는지 검사한다.
7. 새 이미지 기반 PDF와 별도 검토 이력 JSON을 로컬 다운로드한다. 원본 파일은 그대로 유지한다.

## 남은 제약
자동 얼굴·문자·개인정보 탐지는 없다. 가리지 않은 영역 또는 사건의 맥락에서 사람을 재식별할 수 있다. 실제 개인정보 검토와 외부 제출 승인은 별도다. 이미지화 출력으로 텍스트 검색·복사 기능은 사라진다. 암호화·복잡한 PDF·회전 화면은 실제 장치의 추가 검증이 필요하다.

PDF는 기존 PSI ZIP에 연결된 증빙이나 공인 시점 원장이 아니다. P03/P04 서버 원장, P05 기업별 현장 권한, P12 최종 결재 및 반출 감사는 여전히 운영 미구현이다. 실기기 PC/Android/태블릿의 PDF 열람·픽셀 가림 정확성과 재열람 및 Vercel 배포 커밋의 일치는 별도로 확인해야 한다.

**판정 기준:** 로컬 PDF 가림·검증 코드와 테스트를 완성하더라도 법적으로 승인된 외부 제출본으로 표시하지 않는다.
